# Harness Chat Companion

为 ChatGPT **普通聊天**提供可开关的开发接续。ChatGPT 继续负责推理和原生生图，Harness 在本机执行及保存事实；扩展在当前聊天空闲后请求下一轮。

## 使用

1. 先连接 Harness MCP，在普通聊天中打开对应的开发对话。
2. 在 Harness MCP 页面启动服务，在下方独立功能块点击“启用接续”。使用按钮分别管理 MCP 和接续，停用接续不会停止 MCP；启用状态保存后，接续桥随 MCP 启停。页面显示实际地址、配对码和项目内扩展目录，无需单独运行 CMD。源码扩展目录就是本 README 所在目录；交付 ZIP 放在项目 `output/`，不依赖项目外的独立安装目录。
3. 源码可直接加载本文件所在的文件夹。使用交付 ZIP 时，先解压并打开 `INSTALL.html`；在 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions` 开启开发者模式，加载直接包含 `manifest.json` 的文件夹。固定扩展，首次安装或更新后刷新目标聊天页。
4. 点击扩展，填写 MCP 页面显示的回环地址和配对码，点击“连接并读取项目”。选择开发项目并核对开启目标，开启时绑定该项目最新会话，运行中保持固定。任务切换后先停止，重新连接读取最新会话，再开启。连接步骤、限制和检查间隔可在“连接与使用帮助”中查看。
5. 点击“停止自动接续”可停止发起新消息。它不会撤销已受理的模型回复或本机命令。

配对码只填写在扩展中，不发送到聊天。不要把本机接续桥加入公网隧道。扩展仅支持 `https://chatgpt.com` 的已有聊天，当前浏览器标签页和本机执行器必须可用。

弹窗先分别核对接续桥配对、执行器和开发对话，再检查当前网页。MCP 在另一台电脑时，本机地址不能直接访问远端，需要另行配置安全的本地端口转发。关闭再打开弹窗会只读检查保存的连接，不自动开启已停止的接续。

工具栏弹窗使用加宽的两栏布局；需要更大空间时，点击右上角“在标签页打开”。标签页保留未提交的地址、配对码和语言，开启接续仍指向原 ChatGPT 标签；窄窗口自动改为单栏，长项目目标完整显示。

每次开启最多 8 小时，每个绑定最多 100 条发送意图。保护草稿、附件和输入法组合；消息结果未知时停止，不自动重发。工具权限确认、登录、验证码和额度不足需用户处理。

接续只发送“继续”两个字，不附加指令或标记。历史同文消息不用于确认本次发送，结果未知时保留暂停状态。

开启接续后，无需勾选，回复结束、已确认中断或可恢复的回复错误都会在页面持续空闲后发送“继续”，直到任务验收完成。勾选“任务完成后仍继续”后，验收完成也会发送“继续”，让 AI 处理下一个任务；同一回复和同一进展不重复发送。修改勾选只影响下一次开启；手动停止、未知结果和原有用量上限仍然生效。更新扩展后重新加载扩展、刷新目标聊天页并重新开启接续；接续桥须使用当前协议。

## 验证范围

仓库测试覆盖真实 Manifest V3 扩展加载、回环桥、发送确认、草稿及消息防重发；ChatGPT 页面使用受控夹具。用户登录的真实 ChatGPT、站点当前控件和生图文件交付需另行验收。扩展尚未发布到商店，不承诺页面结构变化后继续适配。

打包命令为 `python scripts/package_chat_companion.py --output /absolute/path/Harness-Chat-Companion.zip`。包内清单位于根目录，附离线双语安装说明与文件摘要，不包含接续桥程序、配置或配对码。完整协议、故障恢复和验证入口见仓库 [普通聊天开发方案](../../docs/chatgpt-development.md)。
