# 代码生成与防回归

本页规定修改代码时必须保持的业务边界。稳定协作规则在根目录 `AGENTS.md`；产品接口、存储和验证分别维护在对应页面。

## 先确定事实来源

先读当前实现、调用方、注册入口、动态加载和分发规则，再决定复用、删除或更改。静态扫描的“未使用键”“缺失键”和任意样式值仅是候选，不是删除依据。删除退役页面的资源时，还须确认当前页面替代入口和浏览器生成前缀；同一命名空间中的在用终端状态等资源仍须保留。原文反向翻译、动态前缀、协议生成和安装包资源均可能使静态引用不完整。

同一产品行为只维护一个呈现或执行实现，通过参数和业务适配器表达权限差异。共享对话复用普通对话的 `ConversationPane` 和 `ComposerSurface`，加入后不挂载左右栏；不复制另一套页面来修样式。

## 国际化与原文

产品概念及中英文含义以 [产品约束](project-contract.md#产品概念与术语) 为唯一完整定义。产品自有中文使用“智能体”，英文使用 Agent／Agents；网络代理仍使用“代理”。英文 Hook 表示单个处理器、规则或单次执行，Hooks 表示机制或配置集合，名词修饰语按英语语法使用。中文使用“项目钩子”“插件钩子”“用户钩子”，引号使用“”。资源键、协议字段、用户原文与第三方内容保持原样。

英文中模型对话实体统一使用 Conversation，不混用 Chat、Session 或 Task。任务使用 Task，任务队列使用 Task queue；终端进程使用 Terminal session。`session_id`、`scope=session`、`session/project` 等机器标识及参数值保持原样。按钮动作统一使用 Refresh、Check again、Jump to latest、Retry reading、Choose、New conversation；网页加载失败后的 Reload 保留重新加载的含义。

相同中文、相同语义的英文文案应一致。中文不区分单复数，英文可按实际对象使用 Skill／Skills、Team／Teams；动作 Deny 与状态 Denied、配色 Theme 与记忆 Topic 也应区分，不能只按中文相等机械替换。`tests/test_i18n_terminology.py` 对源和生成资源执行分组检查，只有注明语境的差异可保留；新增差异先核对调用位置，并补充明确的资源或语境依据。

- 自有提示、错误、工具说明、默认示例和模型提示词使用双语资源。中文请求使用中文提示词，英文请求使用英文提示词；工具名、专有名与协议值保持英文或原文。
- 使用显式资源键。完整语句、标点、角色名与列表分隔符由资源控制，相同含义的数量标签优先共用资源，需覆盖 0、1 和多项，不能把数字与名词片段直接相邻拼接；代码块、终端行数、工具调用、待处理消息和分支后代数均使用完整模板，折叠与展开动作分别保留完整文案，不拼接固定中文冒号、括号、句号，也不把用户正文交给产品翻译器。
- 组合指引的句间标点和空格放入外层双语资源；未知操作结果先核实，不能仅因超时就建议直接重放。共享入口说明须与当前角色能力一致。
- 删除确认使用包含对象名称或数量的完整资源；名称、命令和用户已编辑的提示词保留原文。钩子匹配示例及预览说明必须与当前注册工具名及区分大小写的正则匹配规则一致，不能把正则表达式解释为 glob。
- 工具活动分类按当前公开注册名核对，智能体的创建与续跑都应进入协作分组；状态摘要和相对时间使用当前语言，英文数量区分单复数。工具名、目标标识和结果原文保持原样。
- 子智能体新建对话标题使用派工时确定的父语言与完整资源，运行时补建沿用该运行语言；复用现有对话不改写原标题。预览说明不能承诺无条件提供完整终态输出，服务状态不硬编码工具数量。成员恢复、中断、归档和合并错误保留明确资源或有序原因；合并前统一读取根级 `copy` 或异常 `details.copy`，不以发生时译文代替身份；运行卡片、成员详情、内嵌视图和搜索按当前语言解析，语言切换不重放操作。独立智能体活动卡片只接收当前协议状态，不接受 done/error 或大小写转换等旧状态别名；completed 到 done 仅为界面资源映射。成员栏同时接收团队当前协议中的 done、blocked 状态，不将团队合法状态误删为旧别名。 对话活动折叠仅将独立智能体的 completed 视为已完成过程，未知值及旧 done 别名保持独立可见。
- 自行解析产品资源的共享呈现组件须订阅语言变化，不依赖父组件偶然重渲染；语言切换保留当前筛选、选择和用户输入。
- 模块常量保存资源键，实际读取时解析语言；不能在 import、模块初始化或一次组件挂载时固定语言。目录刷新需覆盖模型、工具和技能，并保留当前用户选择。
- 按英文→中文→英文验证同一实例；异步目录用请求代次拒绝旧语言回包。仅比较语言字符串不能拒绝来回切换后的旧请求。
- `harness/i18n/locales/` 为资源源，运行 `scripts/generate_i18n.py` 生成浏览器子集。修改生成文件必须修改生成器或源，不能手改产物。

用户展示原文与附件模型提示分开保存和传递，展示、历史投影、导航与回显核对不解析译文标记。附件引用独立于正文，纯附件消息不能因正文为空而在刷新后消失；共享前缀或换行不证明两条消息相同。队列编辑和恢复同样使用原正文与独立附件引用；编辑后重新装配模型提示，不保留或解析翻译尾块。测试须同时覆盖含标记的原文、纯附件空正文、版本冲突、未知保存回查和单独移除恢复附件。

计划与权限审批按钮按选项的显式动作身份识别，不使用固定英文或译文反向匹配。提问超时不是答案或授权；只能继续独立工作和已有授权范围内的选择，缺少必需用户事实或授权时仍须等待。标签在提问时按运行语言产生，答案保留同一问题的原标签；界面切换语言不能改变待答问题身份、自动提交或将修改意见当作批准。

前端静态目录保存显式资源键，在读取字段或渲染时解析；不使用原文查表代理。产品错误按错误码选择资源，未识别的外部问题选项保持原文。已登记公开错误码的后端和浏览器共用 `ui.collaboration.error.<code>` 资源，缺少浏览器副本须在交付前发现；不能另建仅服务端可见的同义错误文案。后端不提供原文反向映射入口。缺失资源应明确失败，不能用返回键名或静默默认语言掩盖缺失。文件观察拒绝通过 `FS_EXISTS`、`FS_NOT_OBSERVED` 等错误码表达机器身份；普通解释按调用语言完整翻译，不能为匹配旧错误正文保留英文半句。

页面需要在切换语言后继续显示的产品错误，不保存一次 `t(...)` 得到的字符串。逻辑层使用显式 `ResourceError` 或保留 `ApiError.failure.copy`，页面用 `failureText` 保存，再用 `noticeText` 呈现；普通外部异常原样保留。错误子类、状态码、原始请求号和未知结果回查语义必须保持，不能为刷新语言重新执行操作。

原生页面离开/关闭确认区分宿主自有提示和网页原文：自有提示经桌面桥保留 `message_copy`，浏览器按当前界面语言解析，Python 投影按读取语言解析；网页提示仅保留 `message` 原文，不按文本相同推断资源身份。弹窗失效、回应忙碌或结果未确认、参数错误经 IPC 与 HTTP 桥保留错误码和资源键；不能依赖 Electron 的异常序列化保留自定义属性，也不能把已确认的拒绝一概描述为连接断开。切换语言不得重新回应弹窗、导航或关闭标签，回应仍核对原对话、页面和弹窗标识。

桌面网页右键菜单复用当前界面的显式菜单资源，不内嵌另一套双语字典或按系统语言替代用户选择。异步恢复标签页及失败回收使用发起对话身份，不在等待后读取活动对话来归还已关闭页签的恢复结果；原异常保持，不能自动重试加载。关闭对话浏览器或运行时必须使待恢复代次失效，即使后来以同一对话ID重新打开也不能归还旧历史；获取目标和加载后的存活校验不能省略。标签关闭和数量上限的自有错误沿同一资源通道传递，后台快捷键错误同样保留资源及原对话身份。

原生错误沿显式资源回执解析，不能按错误正文猜测语言，也不能把所有 `browser/desktop-page` 都改写成初始化等待；该错误码的有界只读重查与原始原因保持。HTTP 资源回执损坏须明确拒绝，不为缺少当前字段补旧格式兼容。失败页重新加载不能通过空 catch 吞掉非取消错误，失败状态和原 URL 继续保留，每次显式重试仅执行一次加载。

本机系统权限在功能入口申请，拒绝后再次点击仍须引导授权；系统不再弹框时直接打开对应设置，不缓存拒绝以永久阻断功能。能力读取和语言切换不申请权限。未授权前不捕获屏幕、隐藏窗口或打开录音设备；迟到授权继续核对所属实例、对话及页面代次。截图 IPC 失败通过显式资源回执传递，不能依赖 Electron 序列化异常自定义字段，恢复失败仍沿单次收尾与禁止重放规则处理。

桌面服务重连同时观察状态事件和重启回执：已确认运行的回执可以结束启动提示，但旧操作的迟到成功或失败不能覆盖更新的状态事件或新挂载实例。重连期间同步拒绝重复调用；恢复只触发一次工作区重载，语言切换只重新呈现提示，不重新启动后端。

网站权限回应在消费请求前校验布尔值，不能把非法值当作拒绝而清掉待答项。下载控制核对所属对话及当前状态，失败记录保留资源身份和外部原文。取消或启动失败的文件清理须核对创建句柄捕获的身份，不能按旧路径删除已被用户替换的文件；清理失败保留诊断，不能覆盖主错误或重放取消。路径检查不等于原子比较删除，涉及外部并发写入时保持验收限制。

提交受理、拒绝和未知通过显式状态区分，不能用错误正文是否为真值判断成功。草稿结算只有省略错误参数才删除待恢复项；显式空正文仍是拒绝，来源层应补资源型兜底提示，不能清掉未提交请求。

需要嵌套产品提示时使用 `ResourceTemplate` 和资源型参数，由 `noticeText` 在呈现时解析，不能把内层已翻译字符串固定进外层模板。通知标题、说明、按钮及无障碍名称从同一当前语言文本生成；语言变化不能重新执行按钮动作或重置通知寿命。

## 异步与生命周期

协作管理写入准入时撤销旧观察代次并取消其只读请求，写入期间暂停定时轮询；写后回查仍由原写入拥有，不能因观察取消重放写请求。Todo广播失败不撤销已持久提交，回查使用原快照身份，旧版本重试保持冲突而非再次提交。

保留挂载的文件面板必须将active沿延迟加载组件传给文件预览；隐藏后取消所属正文读取，迟到内容不得应用，恢复再读当前引用。同根目录的已确认缓存可保留，但根/path/query错配的分页不得混入原目录。

对话用量累加仅接受非负安全整数，拒绝隐式Number转换及累加溢出；失败保留此前确认总量与模型原文，并使用资源错误提示。ready快照缺少草稿表示当前无临时正文，不能继承旧连接草稿。系统/开发者提示词按当前配置规则呈现，不以旧快照兼容为由生成对话气泡。

后台任务面板历史分页拒绝重复或空身份、空的非末页、停滞游标和终页游标矛盾；失败保持已确认列表与原游标，以当前语言资源报告。停止回执回归等待异步响应真正应用及按钮状态恢复，不以固定推进若干毫秒替代状态断言；等待须有失败上限。

运行结束的投影须沿用turn/start的run_id，历史恢复与实时使用同一身份。run/state派生的done帧同样携原运行身份；明确不匹配的旧终态不能清空当前草稿、生成遥测或关闭新运行，但保留事件序号及重放。会话索引读取必须检查own属性，缺失constructor等名称不能命中原型；订阅器读取旧状态也遵循同一边界。

事件编号、重放缓存、各接收端队列及读取快照须隔离嵌套可变正文，不能原地修改调用方事件或向不同订阅者分发同一可变对象。实时事件若显式携带seq，必须为非负安全整数；布尔、字符串、小数与非有限值不能推进游标或应用正文。省略seq的本地控制事件按原通道处理。

人格草稿写入与清空须重新核对同键原字节；损坏或不可读取时保留原件及内存编辑，不能因为目录读取时跳过坏记录就在后续同键覆盖。读取开始与写入准入使用同步状态，不只依赖React渲染的loading。扩展操作先返回结果，通过原页面/语言/对话作用域核对后再应用编辑器状态；连接器候选变化后只能提交当前有效候选。

插件更新必须保留写入和后续收尾的全部原异常，已提交变更即使刷新失败仍发布变更通知；旧连接停止或能力刷新未确认时不得恢复可能重叠的新连接。调度器关闭共享所属收尾，重复取消不再次取消作业，逐项等待后尝试仅释放自己的租约，清理与租约错误一并保留。

跨HTTP线程共享的有序缓存须把命中读取和移动、插入和淘汰、清空分别作为受同一锁保护的操作；不能以单次dict操作安全推断多步安全。文件扫描保持锁外，回归用命中屏障并发清空，验证没有KeyError且失效后实际重读。

队列与待答问题的只读请求使用所属AbortSignal：页面隐藏或实例退出时取消观察，迟到错误不能重新发布；恢复后沿原单次读取通道继续，不重放写入。工作树环境回执除核销待确认标记外，呈现时也须核对worktree_id，其他工作树回执不得显示为本地完成。

运行预览及展开历史详情同样消费面板和页面可见性，初始隐藏不读取或聚焦；重新显示只读取当前目标，不能让旧结果归还或重新抢焦点。按轮次的单数run端点和按运行标识的runs端点均须进入生成响应契约，完整字段及所属身份缺一不可。错误状态保存资源而非当时译文，真实组件回归核对隐藏、替换、关闭、嵌套详情、双语与只读重试，不用直接设置结果替代共享HTTP调用。

页面、工作台及正文渲染器的延迟模块加载须提供有界等待与可操作的失败出口，失败仍保留原文、草稿和导航。加载超时只结束界面等待，不代表底层任务已取消；迟到成功只能更新原实例和原代次。图表渲染保持串行所有权，不能为显示超时而放行尚未结束的渲染。定时观察和运行事件刷新须合并在途读取，不能持续取消首屏或并发堆积；读取中的新版本在完成后合并刷新，确需拒绝陈旧权限快照的路径仍保留其业务版本校验。关闭、切换与隐藏取消只读观察，已接受写入及其结果核查不随观察取消或自动重放。

| 情形 | 实现要求 | 验证方法 |
|---|---|---|
| 首次启动 | 同一实例共享所属启动任务；目录就绪后才标记成功 | 挂起连接，第二等待者不能提前返回 |
| 取消与关闭 | 等待者取消不遗落已接受任务；关闭等待所属执行与收尾 | 连续取消、并发关闭、创建期间取消及清理失败 |
| 页面/对话切换 | 操作绑定实例、对话、资源身份及代次 | A→B→A、关闭重开、旧成功和旧失败迟到 |
| 隐藏观察 | 停止定时器、布局观察并取消未完成只读请求 | 记录 AbortSignal、确认无新请求、恢复读取 |
| 当前目录 | 旧连接/旧刷新不能覆盖新工具目录或关闭替换连接 | 乱序返回与替换后旧调用失败 |
| 输入法 | 组合输入不提交、创建、执行快捷键或关闭编辑 | `isComposing` 与键码229的 Enter/Escape；普通键仍有效 |

插件源码保存的临时文件须绑定原父目录归属；支持目录句柄的平台通过同一目录句柄独占创建、发布和清理，父路径替换不能将清理导向目录外同名文件。无目录句柄平台清理前至少核对文件身份，仍须明确保留其原生竞态验收限制。版本复核属于乐观冲突检查，不能将其表述成对不遵守锁的外部编辑器提供原子CAS。

浏览器观察句柄释放须逐项尝试并保留失败对象，重复取消等待同一次释放；关闭失败不能丢失其余资源。迟到捕获在所有异步读取结束后复核控制版本、页面与文档身份，不能先注册引用再读取标题。停止加载取消后仍完成连接释放及历史收尾，不保留运行中状态；只读回查不能抹去原动作失败。

项目执行的完成回调关闭仓库租约失败时，原异常及租约必须保留到宿主收尾；单个验收任务失败不能跳过其余租约。收尾从已等待的任务快照移除对应身份，不能依赖完成回调获得调度后才结束循环。准备失败与清理失败同时保留，忙碌范围在其他清理异常时也须释放。

自动化运行记录打开对话时，目录刷新后的导航仍绑定原页面实例；页面已卸载不得选择对话或关闭用户后来打开的设置。目录刷新本身保持原有读取语义。

自动化编辑表单在组合输入期间拒绝提交，并拦截isComposing或键码229的Enter默认提交；组合结束后的正常保存仍沿同一同步准入锁执行，不重复写入。

侧栏同对象删除及同对话的分叉、续跑、归档，在写入与结果回查完成前共享同一在途操作；菜单关闭重开不能绕过准入。未知写入只刷新目录，保留未确认提示与当前草稿，不自动重放或按猜测选择新分叉。

侧栏分组和折叠偏好按当前格式分别校验，损坏或不可读的键不得由挂载保存覆盖。受影响的修改保留在页面内，以显式资源提示未确认持久化；另一合法偏好的保存仍独立执行。

新建对话成功后使创建前的对话列表请求失效；若目录已读到同ID条目，不重复插入或用较早的创建回执覆盖其新字段。启动目录同样核对请求代次，不能覆盖启动期间已确认的对话创建、条目删除或后发目录刷新。

删除成功回执不能清掉请求发起后替换的本地内容。删除前捕获原对话的输入、待恢复提交、队列编辑/撤回和Git草稿；只在原快照未变时清理。发生变化则保留，并给出可操作的保留提示，不把新内容自动转给其他对话。

工作区目录刷新以请求代次拒绝旧回执及旧错误；工作区移除和对话删除成功时使删除前的列表请求失效，不能让旧快照把条目重新带回页面。新请求的加载状态不由旧请求结束。对应状态矩阵见目录刷新归属回归。

语言属于目录读取的版本条件，不能单独使已发起写入的结果归属失效。智能体选择器切换语言时重新加载目录，但保留选择操作和其错误提示；不得通过关闭界面、清空错误或重复提交来刷新文案。

MCP服务面板在已接受启停期间暂停状态轮询，并用同步准入锁防止同事件重复提交；启停回执同时更新状态及工作区目录。启动前的迟到状态不能覆盖启动结果，轮询不能在写入中途读取旧状态再晚应用。

写入与观察请求不能采用同一种取消策略。已经开始的写入由业务拥有到收尾结束；结果不确定先读原状态或原幂等回执，不自动重放。跨循环调用回到实例所属循环；工作线程、子进程和 native 句柄必须有明确所有者。团队工作树的线程写入等待复用共享收尾入口；重复取消仍等待同一次 Git 操作，线程失败保留原异常，不让取消覆盖失败，也不重放创建、导入或交付。`closed`、终态标签和 Promise 返回不能单独证明底层资源已释放。

上下文管理仅在对话上下文面板注册，不在设置导航重复注册。预设依据当前所选模型窗口及手工上限计算，未知容量使用固定回退值，始终单选。模型变化只更新草稿，不自动提交；不匹配旧预算时预选均衡并标为待保存，收到外部通知时不能把派生预算差异误判为用户编辑。上下文设置保存从PATCH开始前捕获同窗通知代次：写入或核实读取期间收到其他保存通知时，旧读回不得广播或呈现已确认保存，也不得覆盖仍保留的草稿。未知提交保留原参数和编辑代次，重新核实只GET，不自动重放PATCH；明确4xx拒绝（408除外）则呈现失败并允许修正。通知没有操作身份时不能被当作自身回执；同值重写也属于新编辑。

写入成功后的本地草稿收尾也需要版本比较：用提交时快照核对当前指令、来源版本和相关核实说明，只清理未被修改的部分。页面关闭后仍完成已接受写入的所属收尾，但不得回调已关闭实例或删除重新打开后新写的草稿；只读分页另用取消与代次隔离。

目标控制先保存主状态，再记录消息、广播和调度。后续失败须报告goal/control-incomplete并保留原异常；取消保持原取消，不回滚或重放已接受操作。浏览器回查仅更新已保存状态，不能凭目标ID、版本、阶段或正文匹配认定整次控制完成，也不能清除原草稿及失败提示。

HTTP成功状态不能单独证明写入结果。成功状态中的非法JSON、结构错误和确认值不匹配仍是未知结果，应回查当前状态或原请求回执，不自动重发；明确拒绝及明确持久化失败按当前协议单独处理，不能把损坏回执当作已拒绝。浏览器通过 `isUnconfirmedWrite` 统一判断传输失败：仅明确4xx拒绝（408除外）排除未知结果，业务持久化失败另按协议判断。源码文件保存的读回确认必须同时匹配目录、文件名、正文和可执行标记；其他目录的相同正文不能确认原写入。

## 当前格式与协议

只接受当前格式，不补造缺失身份、状态或证据。区分文件不存在、合法空值、空集合、格式损坏和读取失败；损坏原件保留并返回明确错误。`bool` 不应作为整数版本、退出码或序号接受。拒绝非法 UTF-8，不用替换字符制造成功输入。
子智能体管理器的并发上限与派生深度必须是正整数；墙钟超时必须是有限正整数或浮点数。`bool`、非有限数及其他类型均明确拒绝，不能静默退化为无限制，否则会绕过资源约束。配置加载还须将超出浮点范围的整数按无效超时处理，不得让 `OverflowError` 中断整个配置初始化。等待接口的超时也须在使用前转换为可表示的有限浮点数；超出浮点范围的整数统一作为非法输入拒绝，不能泄漏数值转换异常。

外部智能体初始化回执同样严格校验版本及能力容器；Python中True等于1不能作为整数版本检查。非法回执不得标记就绪，须保持原进程的所属回收，合法扩展字段原样保留。

协议同时核对真实路由和调用方：请求体的 `required`、枚举、可空性、查询字段以及响应结构都要一致。当前人格使用语义化风格代号和四组偏好，不重新引入旧字母代号。共享回答需要请求号、问题版本和答案；队列编辑需要正文和版本。生成后运行同步校验。

操作系统适配、MCP 标准协商、显式归档恢复及故障回查属于有效能力，不能按“兼容”一词删除。技能 `null` 表示继承、`[]` 表示禁用；空的已有执行清单仍是已有记录。这些不同含义不得折叠为同一个默认值。

## 证据与副作用

工具未知副作用保持 `unknown`，不按名称猜只读。权限既控制目录可见性，也在实际执行前复核。文件写入保留同对话观察与版本比较，精确编辑失配后先重读，不退回整体覆盖。

SDK返回冻结dataclass时也须核对嵌套字典与列表的归属；仅冻结顶层不能防止调用方改写缓存。目标读取、创建、更新及完成回执都须与缓存和持久原件隔离，用量请求身份同时绑定对话与目标。回归包含返回快照修改、真实持久完成证据及不同目标相同请求号，不只检查序列化结果。

直接运行失败须先结算failed/interrupted，再等待一次所属成员清理；重复取消不截断回收。运行错误、清理失败及最终状态保存失败按原对象保留，不能因清理失败落盘running。运行控制器关闭须报告任务收尾失败，正常取消仍保持取消语义。直接提交和编辑的text须在读取对话或运行前验证文本类型；预算limit/input_tokens/max_tokens/tokens须在预留或结算账本修改前严格核对整数范围，不接受bool、浮点和文本，非法结算保留原预留以便显式纠正。

运行和工具证据使用明确身份、事件序号和当前范围。工具结果项只按当前协议的 tool_use_id 配对，不使用结果项或外层的 call_id 补造缺失身份；tool/call 仍按自身 call_id 登记，外层结果身份冲突仍保持未确认。重复调用 ID、缺少开始/结果、截断或失效来源不能用后一次成功、相似正文或时间猜测补齐。成员 `settled` 必须包含执行及交付收尾；后台命令、终端等待、归档作业不能当作已退出的命令。命令通过需要真实完成和整数零退出码；真实工具成功仍不等于业务完成。

## 验证与交付

默认只运行本次新增或修改的针对性用例，优先选择测试方法，无法独立选择时运行最小测试文件；纯文档修改只核对内容和差异。`make verify-plan`、`make verify`、全量常规回归、完整生产构建及桌面／浏览器专项均为显式扩大入口，不因公共基础设施、未知路径、基线缺失或提交而自动扩大范围。协议、资源和生成规则变更仍同步维护源及产物；用户明确要求构建验收时执行完整生产构建。具体范围以根目录 `AGENTS.md` 和 [开发与测试](development.md) 为准。常规门禁通过不代表专项验收。验证期间不改源码、生成资源或 HEAD；等待时可以只读审查并写入忽略的本地记录。

浏览器断言使用真实组件和业务调用，不另写简化界面冒充产品。保留语言、主题、窄宽屏及空态/失败/恢复矩阵。固定睡眠不证明异步已结束；取消路由失败不能无条件吞掉。子进程与浏览器的清理分别尝试，任何一个失败不能跳过另一个。验证服务可按工作进程复用，但夹具路由、转换结果、浏览器上下文与后端数据必须按场景隔离；公共准备故障与业务断言失败分别记录，未运行不得冒充失败或通过。效率结论使用相同完整场景及实际耗时，不能靠删矩阵或扩大业务超时获得。

确认命令终止、退出码和回执 `passed`、`inputs_unchanged`、`build_unchanged` 后才报告通过。运行句柄仍存活时观察超时不等于停止，不启动第二份验证。有代码或文档变更且验证通过后提交；推送、部署及外部账户操作须有对应用户授权，不创建空提交。

## 提示词与工具 schema

提示词注册表只负责片段排序、提供函数和声明的变量插值，不根据名称前缀翻译正文。内置片段在提供函数中读取显式资源键；自定义片段、自定义人格、用户及第三方正文保持原文；全局选择的内置人格按语义code解析当前调用语言。MCP 自有标题在装配时翻译，服务器正文保持字面内容；目标续跑在实际执行时读取资源，不能按排队时的原文补译。

工具 schema 在 `ToolSchema` 上声明资源身份，通过 `resolve_description(language)` 取得本次语言视图：

- `description_key` 与 `description_values` 表达顶层模板及实际构建参数。
- `parameter_keys` 将对象键和数组索引组成的精确路径映射到资源，只能指向已有文本型 `description` 或 `title`；错误路径明确失败。
- `SchemaResource` 表达模板内的产品资源参数；`description_parts` 保存有序说明片段。嵌套资源与外层模板使用同一目标语言。

解析复制参数后仅替换已声明位置，不修改注册原件。参数名、枚举、默认值、示例和第三方说明保持原样；资源元数据不进入模型协议。错误说明中列举的可修改字段也要与当前 schema 和业务校验一致。参数校验拒绝使用完整错误列表与操作提示模板；字段说明通过完整外层资源插入，保留原文花括号，不把描述误称为必填字段列表。运行指引引用实际注册的公开工具名，不能把内部处理方法或旧别名当成可调用工具。不要保存构建时翻译结果作为语言无关模板参数，也不要从已翻译文本反推限制值。

工具的 `write_paths` 和 `execution_cwd` 声明是同步回调；返回异步协程时先关闭协程再拒绝，不执行它来推断文件授权。

工具顶层文本参数的用途通过可信 `ToolDefinition.argument_semantics` 声明，区分路径、普通正文、Shell 命令和可执行源码；声明不进入模型协议，不能由模型参数、工具说明或翻译结果反推。声明复制隔离并纳入授权指纹，未声明及嵌套内容保持保守检查。新增或调整源码载体时同步维护注册入口和消费端，回归须同时证明普通成员访问不误判、敏感访问仍在执行前拒绝，不能只给某个变量名加例外。当前行为与边界见 [权限、审批与继承](security-privacy.md#权限审批与继承)。

模型请求、工具搜索与网页目录使用同一显式解析规则；权限指纹使用注册原件。`harness.i18n` 只提供资源读取和 `tr`，不恢复按原文、路径、模块或名称前缀推断翻译身份的代理。未声明资源身份的内容原样保留，第三方原文碰巧等于产品文案也不能改译。

## 运行时文案与目录

独立执行器在服务创建时解析配置语言，MCP 回调和 HTTP 授权路由按请求绑定；CLI 和托管入口加载配置后绑定运行上下文。管理端启动线程继承调用语言，并将有效语言写入子进程配置；切换界面语言不重写运行中服务，重启后采用新语言。缺失既有凭据时明确失败，不以语言修复为由重建用户数据。

产品自有日志模板同样使用显式双语资源，在产生日志时解析当前上下文语言。保留日志级别、异常栈和原参数，`%s/%d/%r` 占位符须与双语模板一致，不把外部异常正文交给翻译器。正则字符范围、编码自检样本及源代码注释不是产品提示，不应为了消除中文字符而改写功能语义。

外部字符串查找产品枚举资源时只接受查表对象自身登记的键，不能把 Object.prototype 上的 constructor、toString 等当成合法资源项。成功响应的 schema 字段查询同样只接受自身 properties；额外字段与任意键映射按各自协议校验，不全局禁止原型同名的用户键。未知权限决定保留原值；未知目标停止原因使用明确兜底，不能显示函数或对象。

请求记录的动态角色、状态、结束原因、上下文角色、浏览器动作及项目钩子状态目录使用无原型对象并保留运行时翻译 getter；调用方对未登记值显示原文。不得用展开或 Object.assign 将这些 getter 提前解析为固定语言字符串。

统计摘要及数量提示必须以完整句子模板表达，不能按“标签＋数字＋单位”拼接翻译碎片。主/子智能体和已报告/未报告等分支各保持完整文案；原模型名和外部诊断不改写，切换语言不能重新读写。 记录身份的可选轮次/策略、估算前后值及原文空/非空范围分别覆盖真实组件分支；分页字符范围使用Unicode码点，不能按UTF-16长度统计。JSON查看器的文本切片与范围计数使用同一单位；分页回归用跨页补充平面字符核对完整拼接、页码和原文保持。

目录接口必须先有界读取再解析，不得仅限制返回条目数却无界读取正文。损坏编码、结构与合法空目录分开处理；工作线程中的产品错误按调用语言解析，不用UTF-8替换字符或静默空集合掩盖损坏。

能力目录必须区分未报告、明确不支持和明确声明支持。网络失败或字段缺失不补造默认能力；若展示本地选项，显式标明其来源而非冒充供应商逐项保证。合法空目录的未找到不能按读取失败处理。

用户定义的智能体、技能等名称作为原始身份精确解析，不能将翻译后的按钮文案或未声明别名当作控制命令。退出等动作遵循当前公开协议，覆盖别名与合法名称冲突、英中英切换及失败不改变原选择。

可见性过滤同时覆盖正常目录和错误消息中的候选列表，不能在失败分支直接枚举未过滤的内部目录。管理用存在性与当前可调用性分开核对，保留禁用条目，不靠删除数据实现隐藏。

能力探测的产品原因须返回浏览器可分发的资源身份，不把后端当时的翻译字符串保存为跨语言状态；不可用及读取失败分别覆盖菜单和既有通知的英中英切换，并断言不重复探测或触发原操作。

审批原因从权限判定的真实分支同步产生，共用操作契约校验并复制嵌套列表；重复原因、非法枚举及与自动审阅策略矛盾的说明不得广播。新说明参与原问题版本，模型提问工具不能伪造宿主审批依据。回归覆盖实际钩子改写参数后的目录外审批、PermissionRequest明确允许/拒绝/非法输出、自动审阅四种转人工路径及同作用域临时授权；原因呈现不新增准入规则。真实组件使用宿主产生的问题核对生成契约、双语切换、原始正文、键盘与一次性答案，不以资源存在性代替消费验证。

工具错误中的候选枚举列表按调用语言使用资源分隔符，不在英文提示中硬编码中文顿号。合并当前语言别名的重复命令模板时保留协议标识及参数向量，覆盖平台分支、含空格解释器路径、原始脚本字节与所属临时文件清理；不能以测试替身声称已在对应平台执行。

工具详情的耗时、退出码和图片读取摘要使用完整模板，图片正常/部分失败分别表达，不把已结束句子再拼数量。工具名、退出码、耗时值和原始输出保持；真实ToolBlock回归覆盖两种图片状态及双语主题尺寸矩阵，切换语言不触发工具或读取。

终端等待原因使用严格枚举分支，未知原因只显示通用说明，不通过普通对象索引或String强制转换解释远端值。每个原因资源包含完整等待说明及“等待结束不代表命令完成”的边界；不能把等待回执的exit_code当作单条命令退出码。数量摘要需覆盖1和多项，避免单项显示英文复数句式。

消息统计和轮次标记使用完整双语模板，当前/历史状态分别覆盖有/无轮次身份，缺失轮次不能拼成无意义标签。思考摘要和过程分组不显示字符数，原正文（含补充平面字符）保持可展开读取。真实组件回归包含原文保持、空压缩统计、非空统计、任务原文和历史标记，语言切换不修改记录或请求。

在线程中生成产品错误或提示的网络请求必须继承调用方上下文，不能用未传递ContextVar的线程池调用固定为默认语言。回归覆盖英中英及并发不同语言，保持原错误分类、请求控制和所属响应清理。

模型菜单的轮换次数、Key状态、容量和重试目标使用完整双语模板；轮换Cycle与模型轮次Turn分别表达。原始模型名和Key掩码不翻译，英中英切换只更新呈现，不重复模型或推理设置写入。

目标面板用量提示分别覆盖有/无总预算及有/无预留，未知用量与运行中/空闲编辑说明各使用完整模板，包含标点和英文空格。真实组件验证英中英切换保留编辑正文、不触发控制写入，不能用片段顺序拼出整句。

文件检查器的首次目录读取、分页和工作区登记失败都保留资源身份，语言切换不重复读取或登记。目录/提示词统计使用完整模板，提示词按Unicode码点计数；未知角色只查自身登记键，constructor等原文不得命中继承属性。

MCP自有资源标题、MIME标记、图片/音频/链接摘要和参数错误使用完整双语模板，标点由资源控制。第三方正文、工具名、MIME、URI及其中花括号保持原文；base64字符串长度标注字符数，不冒称解码后的字节数。截断只影响模型呈现，原响应display/data保持完整。

文件工具的读取总行数/加载前缀、创建/覆盖摘要和搜索跳过/部分读取警告使用完整双语模板。缺失文件候选及搜索文件列表使用当前语言分隔符；路径、文件正文与搜索命中保持原文，不为翻译重新读写文件。

命令面板文件目录的路径错配、目录不可用和传输失败保存资源身份，异常经failureText处理；语言切换只重新呈现，不重复目录读取或重置搜索词。原工作区根及effect归属检查保持，不能为翻译错误丢掉ApiFailure.copy。

网页抓取的完整/截断摘要各用完整双语模板；搜索及多提供方失败摘要的冒号、分隔符和完整错误列表均按调用语言生成。URL、来源名、网页正文及外部错误不再作模板解释；回归须覆盖全部失败和取消不回退，不能为文案清理移除来源故障恢复。

计划问题选项按显式动作ID `approve` 和 `keep-planning` 选择当前语言资源，权限选项按 `allow-once`、`allow-temporarily` 和 `deny` 识别。其他标签包括constructor、toString及__proto__保持原文，不按英文或中文标签猜测动作。实际组件须验证双语显示和提交同一问题的原始标签，不将呈现翻译写回协议答案。

团队成员的原始未知状态可以保留为证据，但图标、样式和双语标签必须先映射到已登记状态或unknown；不能直接用原始状态索引普通对象。真实团队投影回归覆盖constructor、toString、__proto__及普通未知值，验证页面不中断、统一未知呈现及原始数据保持。

上下文统计的部分缓存覆盖说明使用包含覆盖数与输入数的完整双语模板，不将两个独立句子直接相邻拼接。回归区分部分覆盖、完整覆盖、未报告和异常计量，验证折叠明细时未知用量与计量异常提示仍可见；语言切换不发请求或修改原始统计。

模型设置中的默认保存、重试设为默认、显隐开关、显隐保存中及重试显隐均使用完整双语模板，模型标签作为原文参数传入。不能将“正在/显示/该模型”或冒号前缀与模型名直接拼接。真实设置窗口回归覆盖待保存及失败回执的英中英、主题和尺寸，语言切换不重复写入。

模型按钮及菜单直接显示所选模型名称，未手选的对话显示并勾选默认模型，默认变化同步呈现。手选仅保存当前对话的具体模型，重复选择当前模型不写入。菜单不提供另一种模型配置模式；API 清空覆盖仍共用原模型保存、回执核验与只读回查通道。挂载快照不能当作请求模型证据。菜单实例按对话身份隔离，A→B→A 后旧收尾不得关闭或污染新菜单，原写入仍完成。真实菜单回归覆盖默认勾选与更新、跨账号类型选择、重复提交、组合 Enter、Tab／Escape、草稿保留、失败重试、未知写入回查与请求摘要不变。

空闲手动上下文整理须同时设置智能体语言及执行协程的current_language，并在finally恢复原上下文；不能只更新agent.language而让资源仍取调用方语言。回归使用相反的调用方与用户选择语言，覆盖成功、失败及英中英，核对原调用方上下文和活动登记收尾。

钩子阻断、失败及抛出异常的具名摘要使用完整label/reason双语模板，收尾检查失败使用包含error参数的完整模板。标点与英文空格由资源控制；钩子名、用户标签及外部诊断里的花括号保持原文。实际分发和Stop入口回归须核对状态、错误码、阻断列表与英中英，不因文案合并改变授权或执行结果。

输入区的停止请求与计划模式保存反馈保存ResourceText；API失败保留copy，ResourceError/ApiError通过failureText保留资源，外部错误仍原文。Composer用noticeText呈现，语言切换不重新提交停止或计划写入，不能只把外层状态翻译而保留内部旧错误字符串。

请求差异位置提示由完整模板渲染路径、可选文本偏移和字段顺序变化；四种组合均保留显式资源，偏移0不可按真值丢弃，路径及花括号原文保持。不能拼接冒号前缀、路径和翻译后缀。

持久终端读取的空输出说明使用调用时资源，不能把固定英文提示混入中文反馈；原始终端输出和行范围协议标记保持。回归经真实注册表核对空态及原文，不启动Shell或写入终端。

MCP服务器原始说明的新增和替换都必须关闭宿主模板插值；其中`{{language}}`、`{{cwd}}`和`{{session_id}}`等字面示例不能展开为宿主状态。宿主使用含正文参数的完整双语模板，在装配时解析语言；服务器原文不能覆盖宿主规则或用户授权，不能在标题中提升其指令优先级。清空目录时撤下原片段。回归应为这些变量提供实际值，避免未定义变量原样保留造成假通过。

MCP 传输、握手、通知和 JSON-RPC 自有错误使用完整双语模板，原始服务名、方法名、异常正文与返回数据只作参数插入。远端错误码 0 不能按真值省略；数据摘要保留现有 400 字符边界。翻译重构不改变异常类型、原因、请求次数或所属进程的清理状态，清理未确认时仍保留句柄。

终端后台作业的空输入标签使用完整资源模板，按受理该调用的语言创建；用户非空命令作为原文保留。语言切换不重放输入或创建额外作业，已有持久标签仍为创建时快照。

附件媒体子类型标签只读取映射表自有字段，constructor、toString与__proto__等未知子类型按原值生成短标签，不能将继承对象或函数交给React渲染。正常文件准入仍沿当前受支持类型校验，不因展示容错新增上传格式。

过程统计摘要使用完整计数模板，英文标签须覆盖0、1和多项，不能固定复数名词后拼数字句；字符数不参与过程摘要。流式草稿清空时保留已受理轮次身份，最终帧没有先前delta也使用当前明确轮次；未知轮次不补猜。过程分组不得隐藏带Team作者或智能体 speaker的正文/思考，作者原文及分组前后边界保持；缺陷候选须先核对当前块类型和生产入口，不能为不存在的工具作者字段添加兼容逻辑。

内置人格详情按稳定ID取当前目录的语言文案，不能一直呈现打开弹层时的对象快照；从详情自定义时也使用当前内置提示词。已编辑或恢复的用户草稿仍是用户原文，语言切换不能自动改写。推荐只保存语义code，名称/说明随当前目录呈现，不因语言切换重放推荐或应用写入。

全局内置人格选择不能将保存时的语言副本直接当作后续运行提示词；读取及实际上下文都按当前调用语言解析内置资源。用户人格、智能体配置正文和编辑草稿仍保持原文；切换语言不改写选择文件、不更新选择版本、不重放保存或应用。

连接器本地鉴权失败保存完整资源键与原始参数，目录读取按当前请求语言解析；环境变量名和连接器名原样插入，不拼接句子，不反向匹配旧语言错误。第三方原始错误另行保留。

钩子配置页的问题/规则计数、表单错误说明及运行摘要也使用完整资源；每轮超时和运行耗时的单位与分隔符由模板控制，事件、匹配表达式、命令及输出原文保持。

钩子审核状态与事件/类型/时长摘要、账户登录状态与邮箱均由完整双语模板输出；标点和单位由资源维护，第三方事件、工具、命令与账户原文不翻译。

主体标识校验保留 access/invalid-subject 机器码，产品消息使用显式双语键并按调用语言解析；拒绝非法主体不能追加授权事件，不在诊断中回显非法输入。

## 持久化与配置校验

问答链路必须使用同一规范化ID关联表单、结构化答案和给模型的最终反馈；首尾空白不能让已回答问题被渲染成未回答。回归经过真实Broker与工具流水线，覆盖选项截断、自由输入、父子对话路由及英中英，原问题和用户答案保持。

工具直接返回完整 `ToolResult` 时，注册表保留其正文、display 和 data，不执行 `describe` 或 `to_content`。删除此类闲置回调前核对全部返回分支与真实注册表调用，不能只修补不可达回调并以直接调用回调的测试证明产品修复。

执行配置的项目条目必须含非空字符串root，只接受当前声明字段；直接构造配置同样核对项目字典及字符串标识。非法输入返回双语ConfigError，不让KeyError/TypeError替代配置错误，也不补造路径或改写原文件。

凭据存储只接受登记的后端名称，拼写错误不能静默退回内存；凭据写入前核对对象类型，拒绝会导致自身读取失败的非对象正文。拒绝必须发生在写盘前，保留既有凭据原件，不自动修复或迁移。

模型路由配置中的模型名、端点必须是字符串；可以去除合法字符串的首尾空白，但不能将null、布尔值或数字强制转成有效名称。连接文件版本使用严格整数判断，不能因Python中True等于1而接受布尔版本；非法原件保留，不改用默认连接掩盖损坏。

新建模型路由可以由宿主分配模型和密钥ID；已有connection-secrets.json必须含有效的原始ID，读取时不补造。缺失或错误身份按损坏配置拒绝，保留原件，不能通过重启生成不同身份绕开原路由状态。

持久记录正文不能覆盖数据库列提供的身份、种类或版本；展开JSON前校验当前结构及保留字段。损坏记录保留原件，返回显式双语错误，不能通过覆盖顺序或默认值掩盖损坏。

图片持久记录的正文ID必须匹配数据库ID，pending与delivered分别校验其必填字段、时间和元信息结构；交付前读取损坏记录必须停止，回归需确认下载和文件写入均未发生，并保留合法图片交付路径。

幂等存储必须区分“没有原记录”和“原结果损坏”，尤其不能把已完成JSON null当作新请求。返回缓存前核对当前回执结构、请求号、对话身份和错误/终态一致性；回归直接断言执行次数、事件数及原记录保持。

持久验证命令与登记入口共用标识及参数数组契约。不得直接tuple(json.loads(...))把字符串或映射转换为命令；拒绝必须发生在启动作业前，并保留原始记录和合法参数边界。

持久保存使用独占临时文件，清理限定为本次创建的文件；不能把固定`.tmp`路径当作自己拥有的文件。验证需覆盖既有同名外部文件、写入失败、替换失败和两个保存者的临时路径隔离，并保留原件及错误可见性。

持久状态在合并前校验当前字段，不能让JSON覆盖状态仓库的动作函数。损坏原件须隔离写入，错误提示自身触发的持久保存也不能覆盖原件；内存回退不能解除对尚未重新读取的损坏磁盘记录的保护。

持久队列编辑、未确认编辑和撤回记录使用同一条目校验：kind、ID、版本、正文、附件及团队/作者字段必须有效，已携带的对话ID绑定存储作用域。未确认编辑不能引用另一条目；当前服务端附带但未被操作解释的运行元信息保留，不按多余字段误删。

一次性凭据不能凭先前SELECT快照发放新权限，必须在写入事务内检查原凭据消费是否成功。并发回归用独立数据库连接和读取屏障确认只有一个成功、胜出凭据仍有效，持久化失败回滚原凭据；数据库上下文不得改写冻结的第三方异常对象而掩盖原OAuth错误。

持久配置的JSON和UTF-8解析异常属于产品格式边界，须使用对应双语资源，保留原异常作诊断原因。回归同时执行读和写入口并检查原件字节及目录内容，确保自动播种和建立存储也不覆盖损坏文件；合法空文件、缺失文件和用户显式修复分别覆盖。

同一配置的文件加载与托管服务导入共用校验，不先强制tuple或过滤条目再验证。涉及后续写入/备份时，基于同一次读取的完整快照完成校验和构造；损坏输入须在依赖准备、下载或启动进程前拒绝。回归覆盖选定/全部项目、原始参数边界、相对路径、原件字节和读取时的语言切换。

配置路径的可空判断使用显式None，不用真值判断将0、false或空文本解释成缺失。JSON路径限定字符串，SDK路径可保留PathLike；路径类型、空白和NUL在Path操作前明确校验，并核对非法文件原件保持、有效相对路径和null的既有语义。

插件JSON读取在同一文件句柄上限制为1 MiB加1字节，超过上限明确拒绝，不以读取前stat替代有界读取。UTF-8与JSON语法错误使用产品双语资源，原文件保持；恰好上限的合法对象仍允许。

公开状态快照的嵌套可变字段须隔离，不能只复制顶层列表。回归直接修改返回模型身份和嵌套选项，再读取状态确认原目录及选择保持，不能以JSON序列化自动复制替代SDK边界的保证。

目标创建及阻塞入口在写入前核对正文类型，不将null、布尔值、数字或容器强制转换成目标，也不让strip类型异常替代双语参数错误。SDK和工具入口使用同一校验，拒绝后保持原目标修订及持久文件；合法用户正文仅按既有规则去除首尾空白。

目标默认轮次上限与当前持久格式保持同一整数范围，直接构造同样拒绝布尔值、小数及越界值。参数校验须覆盖合法上下边界的创建与重开，不能写出本进程接受而恢复时拒绝的状态。

Ralph工具入口与其当前schema一致：目标正文须为非空字符串，maxRounds只接受整数或省略，不把数字字符串/浮点数转换为有效轮次。拒绝在spawn前完成，终态轮次数和超时中断原因使用完整双语资源，用户报告原文保留。

安装与卸载的类型及作用域在共享路径规则中校验，SDK入口与工具/HTTP边界同样拒绝非法值。未知scope不能默认到user，未知kind不能默认到智能体；回归预置所有候选目录并逐次核对原文件保持，避免参数拼写错误删除有效扩展。

待办整体写入须显式提供todos及每项status，不能把缺失字段当成空清单或pending状态；显式空清单仍受当前版本保护。SDK内存清单、返回值和证据投影分别隔离，冻结事件的嵌套JSON证据解冻后可编辑，但不得修改原事件或仓库。

计划工具执行入口与schema一致，只接受字符串正文，不将容器、数字或布尔值强制转换成计划。非法输入在审批持久化前拒绝，保持计划模式与原事件；有效计划的审批、修改意见及模式切换回归保留。

read_image只使用当前schema的path参数，HTTP(S)图片地址同样通过path传入，不恢复url别名或强制转换非字符串路径。单图摘要的含尺寸/无尺寸分支各用完整双语模板，批量读取复用同一摘要，原图片data URI与文件名保持。

协作工具状态过滤的schema与执行入口共用当前AgentRun状态集合，不维护落后的独立枚举。列表limit只接受正整数或省略，不接受bool、小数、字符串或null的隐式转换；筛选前的对话可见性过滤必须保留，新增状态不能扩大跨对话可见范围。

对话事件分页和分叉的SDK游标只接受整数，不能利用Python的bool/int继承关系接受布尔值，也不能让小数或字符串进入切片运算。分页分别验证缓存与磁盘读取，分叉保留省略游标及空前缀语义；非法参数返回双语存储错误，拒绝后对话目录、原件字节和内存目录保持。

对话导入封装必须显式包含header对象及events对象数组，缺少events不能当作合法空历史；空数组仍可导入。持久导入和只读检查执行相同的封装校验，双语拒绝回归核对现有原件及目录不变，同时保留正常导出快照复用、预览不发布与导入后重开。

轮次提交与恢复共用生命周期转换校验：编号只接受正整数，新轮次须递增且没有未结束轮次，结束事件须匹配当前打开的轮次。非法事件在落盘和广播前拒绝；恢复先验证整段轮次转换，不以int转换或缺省值修复损坏身份，也不先清空现有投影。回归同时核对SDK便捷入口、直接追加、磁盘重开及只读导入，保持原件和已有内存历史。

成员派工的SDK与工具入口共用正文类型校验，prompt只接受非空字符串，description只接受字符串或工具层省略后的空字符串。非法参数在解析父上下文、调用配置派工回调及创建会话前拒绝，不用str将数字、容器或布尔值变成任务；合法原文只去除首尾空白，模型协议及正文花括号保持。

send_message与followup_task共用消息正文校验：只接受有效UTF-8的非空字符串，遵循同一字节上限，不能先str转换或strip后绕过校验。SDK在目标读取前拒绝，工具在调用管理器前拒绝；合法正文仅按既有规则去除首尾空白，回执、发送者及目标身份保持。

对话快照的助手工具调用只读取当前tool_uses字段；实时assistant/message事件继续读取tool_calls，两者按各自生产入口处理。不能在快照中优先采用旧tool_calls别名，防止覆盖当前输入身份；回归覆盖完整及窗口快照的多轮同名调用。

智能体与技能的目录安装入口共用严格请求参数解析：path仅接受非空字符串且遵循长度上限，scope只在省略时默认为user，显式值必须是user/project字符串。不能str转换JSON类型或用真值默认将无效作用域变成用户级写入；拒绝发生在对话/作用域解析及安装调用前。

WebSocket发送与引导正文只接受字符串，省略正文可供纯附件消息使用；禁止str转换null、布尔值、数字或容器。非法正文在附件物化和运行提交前返回run/invalid，保留action、request_id及submitted:false；正常原文和纯附件路径不重放。

对话查询的非有限时间值（如字符串inf、NaN或溢出的指数）须返回稳定参数错误码与当前语言说明，不能泄漏原始数值转换异常。枚举拒绝中的列表分隔符也从资源解析，原始枚举值保持。

对话血缘后代遍历只要因节点预算省略结果，就必须返回complete=false和明确的截断标志，并在模型正文使用当前语言说明上限。恰好到达上限但没有省略节点仍是完整结果；缺失祖先与权限边界保留各自含义，不能混为同一提示。

刷新现有智能体的对话配置只允许将已不存在的对话作为无操作；读取失败或损坏配置必须传播原异常，不得静默保留旧模型后报告成功。失败不改写原智能体配置，已完成的持久设置不自动重放。

当前对话查询按本次模型步骤的step/start裁掉该步骤内容；step/end记录模型响应结束，工具随后才执行，不能据此解除边界。回归须经过真实注册表并核对显式seq_to也不能越过该边界。

当前对话事件检索的current/shadowed分类同样按step/start之前的日志折叠；不能仅过滤命中事件，却用当前步骤的新替换重新分类旧事件。回归保留边界前已有替换，并区分当前对话截断与其他对话最新投影。

计划模式的HTTP和WebSocket入口均要求显式布尔active；省略、null、数字、字符串及容器不能经真值转换触发写入。拒绝使用同一双语参数文案，合法false与true各只提交一次。

问题回答的HTTP与WebSocket入口只接受非空字符串question_id，校验后仅去除首尾空白；不能str转换数字、布尔值或容器再调用问答通知。合法答案原文与通知次数保持，拒绝在触及问答服务前完成。

新对话入口区分省略项目与显式null：省略沿当前项目/对话解析，null表示未归组并使用当前默认根，不能用空值合并将null重新绑定到旧项目。回归同时核对草稿项目、媒体根与实际createSession的cwd，显式项目仍保持原身份。

新对话的创建请求身份须与初始头原子提交，初始化完成标志只能在所有创建步骤成功后持久化。丢失响应的恢复应核对该确切身份和完成状态，不能按标题/目录推断，也不能因存在空对话就重放或宣告初始化完成。

创建请求身份须在POST前实际保留于浏览器存储，内存回退不能证明刷新后可恢复。创建回查只接受同一请求的唯一完成记录及匹配详情头；未知结果再次发送只能读回。回归必须覆盖后端已受理但客户端丢失响应、刷新保留身份、一次POST及当前项目/智能体变化后的草稿隔离。

执行器检查运行作业占用时使用持久化会话原目录，不通过当前项目登记标识反查目录；撤销或更名不能改变既有进程的目录归属，同目录继续阻止写入，其他目录保持独立。

## 读取回执与未知写入

轮次分支创建的未知结果不能套用通用“重试操作”。损坏 JSON、缺少有效子对话身份、408、5xx 或网络问题先回查对话列表；原操作栏保留未确认提示并禁用再次分支，不能凭目录中相似标题确认创建。关闭原栏不取消已接受分支的收尾，迟到结果不切换当前对话。明确4xx拒绝（408除外）可由用户显式重试。该保护属于当前操作栏，不是跨页面或跨重载的幂等协议。

计划证据原文在显示前核对call_id、source_seq、工具名、请求offset及Unicode码点分页边界。损坏或错配回执只能显示错误，不能把外来正文放入当前证据；失败和语言变化不自动重复读取。

恢复审核回执须保存独立的原指令字段；生产端和浏览器按原运行、模式、来源版本、核实说明与原指令核对，不用提示词译文前缀识别。语言切换不能将相同明确指令的显式重试判为不同写入，也不能放行修改后的指令或重放已受理运行。

恢复未采用的引导正文前，回执必须匹配所选request_id、轮次和accepted_seq，且正文未截断；当前协议的对话归属由请求路径限定。错配或缺失身份不能回填草稿，语言切换不能重读或重复恢复。

环境导入确认须同时匹配工作树身份、选择指纹和终态；preparing或错配回执保留待核实标记，不解除重复导入保护。界面导入与创建后自动准备使用同一确认规则，错误保留资源身份。

文件恢复结果未知时，刷新预览和关闭重开不能清除原请求号；服务端已有unknown回执同样恢复其请求身份。核实始终读取原回执，只有明确终态后才能解除该实例的重复写入保护。

终端依赖安装的408、非法成功正文及错配安装ID都属于待核实结果；继续以原request_id观察，不重新开始安装。安装、取消及轮询回执必须匹配原安装ID，成功通知保存资源键。终端依赖安装的阶段、取消、完成和自有失败回执均保存浏览器可用资源身份，底层外部诊断保留原文；切换语言只重新呈现，不重启安装或重放取消。

请求正文、请求与工具日志、技能原文和压缩原文的文本分页统一核对请求offset、Unicode码点长度、total_chars与next_offset。非末页必须前进；末页必须结束，错配回执不得显示正文或自动重读。

对话搜索原文与完整回复复制共用消息身份及Unicode范围校验；消息序号、角色、start/end、总长或前后页游标错配时不显示或复制正文，不按片段文本猜测原消息。

队列编辑的保存和核实共用快照比较收尾，不能在比较后再无条件调用关闭编辑。回归挂起真实组件的PATCH及核实GET，分别验证替换草稿保留、原草稿正常清理和焦点归属；已有通知及完整分页模板覆盖英中英、明暗主题和窄宽屏，语言切换不得增加请求。

原位编辑在发送前从当前草稿快照取正文，成功按快照比较收尾；迟到失败只更新仍属于原草稿的实例。真实消息行回归覆盖普通发送与运行中引导、成功/拒绝/异常、替换草稿、相同消息ID切换对话，以及组合标志和键码229的Enter/Escape保护；错误提示覆盖英中英，不能为刷新语言重新提交。

目标创建成功后的草稿与输入模式结算绑定提交时快照。卸载不取消已接受创建，原草稿未替换时仍完成清理；替换草稿及其目标模式必须保留，旧组件不得借setDraft清理新实例的持久状态。迟到错误和忙碌状态只更新仍挂载且草稿匹配的实例。

对话历史分页合入前同时核对响应header.id与目标对话、游标水位及连续范围。其他对话的相同范围不能当作合法分页；拒绝后保留现有正文，使用资源错误并要求重新获取历史。异步隔离回归须包含身份错误但范围合法的响应。

请求追踪状态响应必须匹配所请求的trace ID，匹配前不能替换已加载详情。父对话合法读取后代智能体请求时，响应session_id仍是实际子对话，不能强改为父ID或一律按父ID拒绝；错误身份返回可随语言切换的协议错误，不重放请求。

对话模型保存的成功回执同时核对session.id与metadata.model，包括清空覆盖时的空字符串。错误身份或模型不匹配按未知写入只读回查；读回同样核对header.id与模型类型，其他对话不能确认或替换原选择。正常匹配回执不增加读取，不重复PATCH。

推理设置写入成功回执必须匹配原对话ID和所提交的显式强度/继承状态；错配按未知写入仅回查，不重放。读回同样核对header.id与推理字段类型，其他对话不能确认或替换当前设置；合法显式关闭及继承空态仍区分。

搜索成功回执在合入前核对归一化查询、固定水位、严格降序与before边界、总数和下一游标；不匹配使用资源错误并保留现有列表/原文，重试只重读。查询按后端Python空白规则校验，不用英文小写转换猜测Unicode命中。

搜索列表回执必须携带实际session_id，并在查询、水位及分页验证前匹配请求对话；其他对话即使查询与游标相同也不能合入。缺失身份同样拒绝，不增加旧响应兼容；失败保留现有列表与原文，显式重试只重读。

正文读取与完整回复复制的每一页同样必须匹配实际session_id，不能只验证消息序号、角色和Unicode范围；后续页错配不返回已读取的部分正文，不向剪贴板写入。错误保留资源身份，语言切换不增加请求。

插件源码保存的成功响应也须核对目录、文件、规范换行后的正文及执行权限；错配与损坏成功回执均按未知结果只读回原文件，确认前不清草稿、不显示成功、不重放 PATCH。

## 组件实例与观察归属

Composer文件补全只通过当前对话的files/search读取，技能候选直接来自技能目录。不保留永远接收空工作区参数的旧目录候选或包装类型；删除前仍须核对真实调用及动态入口。

插件目录首次读取在后续刷新或写操作开始时失效；重复挂载的旧读取同样绑定独立取消信号。即使取消后的传输仍返回内容，也不得覆盖新目录、信任状态或错误。

自动化页面的保存、启停及手动刷新共用同步操作锁；操作开始使旧目录读取失效，手动刷新只读一次。旧轮询取消后仍须按当前可见性恢复观察，不能由旧回包覆盖新目录。

共享对话的权限刷新与队列刷新同属一个只读代次，慢读取未结束时不启动同类定时轮询；不能仅用alive布尔值判断旧请求有效。回归覆盖轮询乱序、effect清理后重建、隐藏/显示和卸载，受控读取可忽略AbortSignal，仍须拒绝旧结果且保留原草稿；取消不能用于中断已接受的写入。

问题ID可与JavaScript继承属性同名，草稿读取只接受自身字段；不能将constructor、toString或__proto__误当成答案。真实问题卡片回归覆盖选项、自由输入、刷新恢复、填写进度和提交正文，切换语言不改写草稿或提交。填写进度和跳转提示各使用完整资源模板。

问题草稿必须校验完整schema、选择/正文映射、问题ID、选项唯一性及单选数量，不能过滤非法选项后当作恢复成功。损坏原件按记录隔离写入，挂载、编辑和已回答收尾均受保护；计划修改意见使用相同边界。回归同时覆盖已回答首次挂载与本次提交完成，并验证双语警告、内存新输入和正常草稿清理。

人格页面的语言切换不能关闭编辑器、重置偏好或释放保存/应用/删除锁。只读目录使用取消和代次，写入使用独立同步准入与挂载归属；读取失败与操作失败分开保存，不能重复拼接同一个旧错误。 保存、删除或选择的回执无法确认时保留资源身份与原诊断，沿原操作结束后只读回查目录和全局选择，不重发写入；保存本身未确认时保留编辑草稿，保存成功但选择未确认时分别报告两个阶段。面板卸载后已接受保存仍可完成，但不得继续发起后续选择。草稿代号校验须与当前生成的PersonalityProfile.code类型一致，不保留只接受旧字母码的校验器。

对话待回答问题的事件刷新与定时兜底共用串行读取；慢请求未结束时定时器不启动新请求或使旧结果失效。读取期间的新事件使旧快照失效并合并为一次后续读取；相同问题ID的正文变化也更新，切换对话后旧结果不能写回。

插件主目录的读取成功和失败使用同一代次，刷新/操作开始及卸载使旧读取失效并取消；严格模式effect重建也不能让旧失败覆盖新结果。操作回执保留资源键，成功后切换语言不重读目录或重复卸载。

插件目录的显式刷新只执行一次读取，不在通用操作收尾中再读一次；写操作仍在完成后刷新权威目录。回归记录读取和写入次数，避免以减少写后回查实现表面简化。

运行状态卡片的停止操作使用同步锁，不能只靠React忙碌状态阻挡同一事件内的重复调用；成功、拒绝和异常均完成所属收尾，明确拒绝后允许下一次显式操作。主轮询成功和失败都核对操作代次，旧读取失败不能覆盖已确认停止。

连接器OAuth本地镜像只读取自身名称字段，不能让constructor、toString或__proto__遮蔽后端状态。待轮询集合与行内状态使用同一读取规则；真实组件回归须验证特殊名称仍完成状态读取，语言切换不重复轮询已结束授权、不触发写入。连接器启停的无障碍名称使用包含原名称参数的完整双语模板。

连接器新增请求的表单清理绑定提交时的输入实例和编辑代次。已接受写入继续完成，但用户修改任一字段、切换传输方式或关闭后重新打开表单时，旧成功不能清空草稿或关闭当前表单；未修改的原实例仍正常清空关闭。真实组件回归需挂起POST并核对原请求正文、替换/重开保留、后续显式提交及中英文主题尺寸。

侧栏项目菜单的新建对话必须传递SidebarGroup.workspaceId，不将用于折叠/树形分组的路径key当作项目ID查找。未归组显式传null；回归经过真实菜单及键盘入口，覆盖项目分组与项目树、中英文切换和窄宽屏，核对新建调用的项目身份。

上下文设置的保存使用窗口内共享操作记录，不仅依赖React忙碌状态；同一事件内重复点击只能接受一次PATCH。设置组件卸载重开仍可观察原操作，未知时不释放写入准入，重新核实按钮不依赖首屏配置读取成功。该记录不跨浏览器刷新持久化。确认结果只更新所属且未再编辑的草稿，其他编辑继续保留。真实组件回归核对一次PATCH、原提交参数、卸载重开、通知代次及英中英切换期间的忙碌与回执，不通过语言切换重放保存。

主对话详情中的计划状态和待回答问题必须来自成功读取，不能捕获所有异常后补造inactive或空数组。读取失败保留原领域异常，合法空态仍正常返回；成员上下文与较早历史分页继续隔离主对话控制读取。回归覆盖完整/对话/首屏窗口视图及成员上下文，不以静默默认值掩盖损坏或依赖故障。

复制反馈绑定内容代次：同实例内容变化时清除原反馈和计时，旧复制成功或失败不能确认新内容；已受理剪贴板写入仍等待结束，不自动重放。延迟生成复制正文的回调须声明稳定contentIdentity，不能按每次渲染的新函数引用清掉语言切换反馈。

计划模式保存绑定当前对话缓存生命周期和本次保存对象。原对话缓存被丢弃后，旧写回执或回查不得覆盖同ID重新打开的状态，不得清除新保存记录；已接受写入仍等待收尾，丢弃不自动重放。

删除无调用的store动作前核对直接调用、getState取用、类型接口和页面实际读取入口；不得为闲置方法补一套错误状态并保留重复业务入口。待回答问题沿对话通道现有读取与实时更新路径维护。

待办条目正文允许重复，不能用正文作React key；有明确ID时沿用ID，无ID的当前列表使用位置。原始正文不承担实体身份，列表数量变化和语言切换不得复制或丢失条目。 当前待办正文统一读取content，状态读取status；消息块、对话底部清单及检查器共用该字段语义，不读取旧activeForm或priority展示别名。todo/write由内置待办工具产生，第三方工具结果不得隐式转换为该事件。

启动读取绑定发起时的语言代次，较旧的settings不能覆盖期间已更新的语言。工具、技能和模型目录文案也须在当前代次读取；重读期间语言再变则继续丢弃过期目录，不重放语言设置写入，独立的对话/项目列表读取归属保持。

重命名弹层的保存回执绑定原组件实例，卸载后不得调用旧onClose或设置旧错误，防止迟到成功关闭替换弹层。已受理保存仍在store完成并更新原实体；不因卸载取消或重放写入，当前实例的失败反馈和显式重试保持。

成员管理与创建邀请共用同步实例锁，覆盖写入及状态读回；React busy状态不能单独承担准入，也不能写回后、读回前提前释放。读写抛出异常也须完成所属锁及读取标记收尾，错误保留资源身份，未知写入只读观察不自动重放；卸载后不更新原界面。

能力设置的数字输入保留本实例草稿，保存后按权威读回更新，包括读回值与保存前相同的情况；失败保留编辑值。语言切换不得在写入期间启动竞争读取，写入与读回共用实例锁，期间语言变化只安排当前语言的只读回查。失败反馈保留资源身份，不因语言重读清除；卸载后不更新输入、权限或提示，不重放写入。

截图等待的错误回执同样绑定原按钮实例，卸载提交时同步失效；迟到失败不能给替换页面弹toast、添加附件或回调原焦点。已受理截图收尾与finish失败仍须独立处理，不因取消观察而重放截图。

权限菜单的保存回执绑定提交时的对话与菜单打开代次；关闭重开、切换对话或卸载后，旧成功不能关闭替换菜单或抢焦点。保存仍由store完成，不因菜单关闭重放或取消已受理写入；继承和显式档位共用同一呈现收尾。

输入区延迟焦点与尺寸回调由编辑器持有并统一取消，不能在组件中裸requestAnimationFrame后读取已换对话的ref。对话身份变化在store通知时即撤销旧帧，包含同事件A→B→A；卸载/禁用清理所属回调，不重放输入。

截图回执的呈现与恢复焦点绑定发起时的同步对话代次；A→B→A也失效，不能仅比较最终ID。原生/浏览器捕获与失败提示共用归属判断，过期捕获仍完成原资源收尾，不给新对话弹错误或恢复旧焦点。

队列撤回及未应用调整读取完成后的草稿恢复与焦点恢复分开确认：原草稿仍归原对话，同步对话代次变化或组件卸载后不恢复焦点，包含A→B→A。不能仅按最终activeSessionId决定迟到回执是否可抢焦点；不重放撤回请求。

能力挂载/移除的菜单、错误和焦点反馈须同时核对同步对话代次，最终ownerScope字符串相同不能证明期间未切换。已受理挂载仍更新原对话的版本状态；过期呈现不关闭替换菜单，不重放选择。

能力菜单关闭后重新打开属于新的呈现代次，即使仍是同一对话与能力类型，旧选择回执也不能关闭新菜单或恢复焦点。异步回归等待真实菜单卸载/重新出现后释放屏障，不能把未提交的React状态当作已关闭。

提交与补全钩子也只能使用编辑器持有的帧调度；跨await的动作在开始时captureFrames，回执后排帧仍校验原代次。不能到回执完成后才取当前代次，否则A→B→A会使旧操作重新获得呈现权限。原草稿清理与已受理提交结算仍按原业务身份完成。

灯箱图片切换按来源更新图片节点，load回调核对当前ref节点后才写入尺寸；旧来源即使迟到派发load也不能覆盖新图尺寸。现有缩放重置、拖动及组合输入保护保持，不能只清空natural状态却继续接受旧节点事件。

## 键盘、焦点与布局

对话历史滚动区的Home、PageUp、ArrowUp及恢复向下跟随的按键同样受输入法组合标志和键码229保护，不能只保护输入框提交。真实虚拟列表回归须核对组合按键不取消默认行为、不改变滚动位置，普通Home仍跳到顶部，并覆盖双语及窄宽屏。

输入区加号菜单、权限菜单和附件上下文菜单的导航及关闭按键同样检查isComposing与229；组合输入不得抢焦点、导航或展开/关闭菜单。普通方向键、Escape和Shift+F10继续可用，真实组件回归覆盖英中英、主题和窄宽屏，导航不触发业务写入。

截图菜单的锚点展开键及弹层Escape/Tab同样遵守组合输入保护；组合或229不展开/关闭弹层，不调用截图。普通方向键展开与Escape关闭保持，回归核对仅一次能力读取且无截图写入。

上下文菜单动作使用稳定id作为React key，不能使用翻译后的label；切换语言应保留当前动作节点和键盘焦点，不触发动作。调用方同步声明当前动作身份，标签仅供呈现。

界面字号在同一处归一化后同时写入store、根DOM和偏好；不能DOM已限幅取整而store保留原始值。非有限数使用当前默认字号，现有10至22边界与正常整数保持，偏好写入失败不阻止当前界面设置。

流式光标与加载扫光须响应prefers-reduced-motion，减少动态效果时保留静态进度标识与原文，不再闪烁或移动；偏好在页面打开期间变化也立即生效，不能通过停止流式业务实现减少动效。

模型菜单的定位宽度应测量实际w-model-menu语义样式，不能另用固定px猜测rem宽度；用户字号变化时重新定位并保持视口限幅。测量节点仅在菜单打开期间存在，关闭清理观察与节点，其他菜单的数值及锚点宽度策略保持。

原位展开的SVG与Mermaid图表共用普通Overlay的焦点、滚动锁与顶层键盘管理；展开后Tab不能进入背后弹层，Escape只退出当前图表，组合输入仍不关闭。退出恢复原展开按钮，最后一个对话框关闭后才恢复页面滚动；已处理的键盘事件不能继续关闭下层对话框。

公共Overlay遮罩拥有纵向滚动并禁止面板被flex压缩；低高度窗口、大字号及顶部留白叠加时，内容和底部操作仍可滚动到达。不能只限制面板高度却继续overflow-hidden裁掉子控件，也不按固定header像素猜测可用高度。

CSS声明规则使用解析后的属性和值核对，合法空白、注释和大小写不应绕过字号档位；例外绑定确切文件与选择器，注释中的示例不当作声明。检查模块拆分时同步桌面构建指纹，避免修改规则仍复用旧构建；扫描通过不能代替实际布局验收。

任意样式检查覆盖共享令牌的等价方向写法（px/py、gap-x/y、size、inset和translate等）及显式length字号；颜色透明度和内容属性按现有约定保留。动态CSS类使用有限枚举与已有选择器，不能靠任意值总数判断删除。静态检查不执行任意JS，也不能替代真实布局回归。

## MCP 与插件生命周期

HTTP线程任务应保存明确归属，观察者取消不取消线程Future；等待响应上下文实际退出后传播取消。取消与读取错误同时发生时保留两者，不因吞异常或自动重放让后台操作看似已结束。网络单次超时不等于总截止时间。回调授权的阻塞等待须有取消信号，返回取消前关闭所属监听端口；已开始的令牌交换只等待，不重放。回归核对真实端口关闭和未执行交换，不能只检查协程已取消。

管理器关闭不得在清空任务登记后让并发调用提前成功；关闭入口共享唯一所属任务，经共享等待器抵抗重复取消。已关闭实例拒绝新授权，失败收尾保留原异常，不重新执行授权或关闭来伪造成功。注销只撤销当前授权身份，不能同时遗失尚未结束的任务归属；关闭须等待这些任务，避免重复取消打断其清理。

绑定探测的连接和关闭共用错误收敛边界：清理失败不得吞掉后提交绑定；保留连接原因为cause，组合取消或其他错误用共享聚合。关闭任务只创建一次，重复取消不能打断所属收尾，不重放授权或连接。

OAuth 后台授权的异常边界包括声明读取、授权、凭据持久化、绑定和连接收尾。任一步失败都结束挂起状态并报告错误，取消仍向调用方传播；不能因收尾失败自动重放授权、删除已保存凭据或把部分完成写成授权成功。

OAuth 授权等待结束后、写入凭据前，重新核对原连接器声明。删除、替换或停用的声明不能被旧结果重新绑定；保留已有凭据并报告声明变化，不以相同名称借用替换后的授权目标。

环境MCP声明和直接构造使用同一字段校验，不把字符串参数、非字符串凭据值或布尔超时强制转换为有效配置。数组声明须整体校验及核对唯一服务名；损坏文件、旧封装或任一非法条目均明确拒绝，保留原件和错误的资源身份，不以跳过条目或空目录掩盖损坏。连接故障恢复与配置格式拒绝分开处理。

远端工具目录须在完整分页校验后整代发布；不能通过跳过条目、补造空schema或遇重复游标就停止来伪装成功。回归应在第二页损坏时核对原目录完整保留，同时覆盖合法空目录、可选字段省略和不透明空字符串游标。校验不翻译或改写第三方名称、说明及schema。

连接引用的释放必须以所属清理成功为前提。重连预算耗尽、替换和关闭共用同一资源归属；清理失败保留句柄、阻止替换并报告原异常。批量收尾逐项尝试后聚合错误，回归覆盖清理屏障、失败后显式重试及真实受控子进程退出。

批量连接收尾复用共享异常聚合：单异常保持原对象，多异常保留全部，包含取消时使用BaseExceptionGroup。插件停用/卸载先完成逐项断开，再更新持久状态；不能在首项错误时跳过其他句柄，也不能吞close异常后广播成功。原声明及偏好不通过清理代码隐式改写。

连接器预设首次安装技能须在同目录准备完整正文后以独占方式公开；检查不存在后仍可能有并发写入，不能普通write_text覆盖。已有用户文件及链接保持原件，失败不自动重放，临时正文收尾不影响目标。

首次动态add_skill创建目录时必须沿用初始化目录的默认启停与插件所有者过滤，不能因从None延迟创建而绕过禁用。已有智能体使用宿主skills_for_session动态查询，不为已经共享的读取路径重复维护一套注册或绑定。

账号授权JSON响应及JWT载荷须先严格解码UTF-8，不能直接将字节交给JSON解析器以隐式接受其他编码；HTTP错误正文解码失败仍保持原状态及安全双语分类，不回显授权材料或重放请求。

账号登录回调的state、code和error各自只接受单值，空值参与重复检测；歧义请求在交换授权码前拒绝，保持当前待登录身份，不能静默取首值消耗登录。正常不透明授权码按原文传递。

OAuth授权绑定发起代次，注销和管理器关闭同步使其失效；适配器即使取消后仍返回，旧任务不得写凭据、发布授权成功或重新写pending/error。当前连接器配置身份校验同时保持，不重放授权。发布授权成功前还须核对连接等待后的原声明身份，配置替换或删除不能被“未注册工具”掩盖为授权成功；原凭据写入不通过补偿代码隐式撤销。

## 工作流与语言服务

工作流后台运行开关由schema和执行入口共同约束：隐藏参数不等于禁止参数。顶层只接受当前声明字段；禁用后台或缺少作业表时，在构造guest和启动作业前明确拒绝后台请求，正常前台与显式启用后的后台路径分别保留回归。

工作流guest将VM结果转为JSON时，数组索引必须是自身字段和规范十进制下标；原型填充的稀疏项、非规范数字名称及隐藏附加字段不能静默丢弃后报告成功。真实Node回归验证拒绝与双语原因，同时保留正常数组、对象数字形键、null原型对象及用户原文。

工作流成员读取和释放共用callId正整数校验，不让Python的bool/int相等性把true映射为成员1。非法身份不能读取、释放或移除有效成员登记，合法未知正整数的释放仍幂等；回归保留实际已登记成员和正常结果读取路径。

工作流Node启动复用共享start_process接管，创建等待被取消后仍接收迟到句柄并等待所属清理；重复取消不能提前返回。启动清理失败保留句柄及原异常，不关闭未确认的传输层、不自动重放脚本；回归同时覆盖屏障、失败及真实受控子进程。

工作流成员结果等待的取消必须向调用方传播，不能返回未完成的正文。成员释放共用所属清理任务，取消等待不取消已接受的停止；仅在AgentRun.settled确认执行和交付收尾后删除登记及schema。批量收尾继续其他成员并上报全部失败，失败句柄保留，正常Node收尾与并发/重复取消均需回归。

工作流进程正常结束可先等待EOF退出，超时后停止仍必须有截止时间；不能在kill失败后无期限wait。启动取消与运行期停止复用同一接管逻辑，进程清理失败也继续收尾stderr并聚合先前成员错误，未确认的句柄保持。

工作流guest到宿主的JSON-lines消息严格核对UTF-8、JSON对象、递增正整数请求号、method及显式对象params，终态核对final/ok布尔值及result/error互斥结构。损坏消息不能跳过、强制转换身份或补空参数后执行；失败保留原因并进入所属清理。

LSP入站帧头部最多64 KiB、正文最多32 MiB；Content-Length必须是单个正十进制长度，重复或非法值在正文读取前拒绝。分片、连续帧和原始UTF-8正文仍保持，不把源文件读取上限当协议帧上限。

LSP的symbols查询只要求目标文件，不套用definition/references/hover的行号前置条件。initialize的rootUri、rootPath和workspaceFolders描述同一工作区，目标文件身份放在textDocument中；回归同时核对通知原文、正常查询和必须提供位置的拒绝路径。

LSP进程启动使用共享start_process接管迟到句柄；close使用共享所属任务并等待回收后传播重复取消。关闭失败保留进程并以ProcessCleanupError阻止继续模型循环，只有显式再次关闭才重试清理；正常查询与真实受控进程收尾需同时验证。

LSP在启动服务器前有界读取常规源码文件，完整源码上限8 MiB，拒绝非法UTF-8、超限和读取失败，不能发送替换后的正文或吞错误继续查询。可选位置预览只读取256 KiB前缀，共用源码行边界与严格前缀解码；没有可靠预览不影响原位置身份。

## 所属进程、取消与收尾

权限审阅等待在失效或取消后只向工作与观察任务投递一次取消，再通过共享等待器收敛；收集结果中的清理失败须与原异常一起传播，不能因return_exceptions吞掉，也不能把同一主异常重复聚合；重复取消不能打断工作已开始的 finally。权限版本失效仍按原合同重新判断，不能重放已受理副作用。

可撤销历史只绑定可退出的作用域。长期根服务替换不得积累旧实例；验证需用对象生命周期确认旧实例可释放，同时保留插件嵌套及异常退出的精确恢复，不把释放引用冒充底层资源已关闭。

异步创建子进程的等待本身也需要归属：创建已发生但句柄尚未返回时，取消不得直接退出。先接管迟到句柄并完成所属清理，再传播取消；临时工作目录须保持到清理结束，验证包含启动屏障及重复取消。所属原生创建线程通过保留语言上下文的执行器 Future 交接，不注册为循环关闭可整体取消的创建子任务；创建自行取消须直接传播，不能反复等待同一取消结果。匿名输入写入不能占满负责输出和停止的专属执行器，停止之后仍须取回输入与输出线程结果。

工具流水线的限制、执行前/后钩子与 guard 均保留 ProcessCleanupError，不能将未确认的进程清理转成普通工具错误后继续模型循环。回归覆盖同步和异步钩子、执行前拒绝及执行后失败，并断言不会发布普通结果。

PowerShell CLIXML只剔除完整内部脚本回显或明确的内部脚本消息前缀；用户/第三方正文中嵌入同样脚本、普通冒号和CategoryInfo仍保持。非CLIXML及未知结构保留原文，不因展示清理猜测正文来源。

bash、pwsh和run_code直接入口与公开schema共用参数边界：待执行正文必须是非空字符串且保持原始字节，超时只接受范围内有限数字，不强转布尔值或数字字符串。bash/run_code为0.001–900秒，pwsh为1–900000毫秒；不静默钳制越界值，也不将1毫秒改为100毫秒。非法参数在解释器发现和进程启动前拒绝，提示使用调用语言完整资源。bash/pwsh的run_in_background只接受布尔值；未提供作业表的实例明确拒绝后台执行，不能把字符串false当成真值或静默以前台执行代替。

前台命令创建等待与进程执行拥有同一生命周期，取消不能在句柄迟到前退出并删除临时输入。复用共享启动接管函数，并在实际启动前检查调用方取消与执行许可；已开始的创建接管后等待清理，失败保留脚本和路径诊断。回归覆盖重复取消、清理屏障/失败、尚未接受的启动以及真实受控子进程退出。

对子任务使用shield抵抗调用方取消时，必须同时检查子任务是否已自行取消；不能在同一个已取消任务上无限重试。关闭不得再次等待已取消的创建任务，也不能跳过仍可能交付句柄的创建。死循环回归使用独立解释器的外部截止时间，避免缺陷阻塞测试循环本身；迟到句柄另用屏障和真实受控子进程验收。

异步发送协程收尾按订阅实例比较归属，不能只按连接ID删除登记项。同一连接替换登记后，旧协程取消完成不得移除新订阅；服务关闭清空所有所属临时快照。失败回归自身必须持有并回收全部启动任务，不能依赖正被验证的注册表完成测试清理。

后台作业批量关闭须检查每项kill的cleanup-failed结果，不能因方法正常返回就认定进程已收敛。逐项尝试后复用共享异常聚合，包含取消时保留BaseExceptionGroup；失败作业及其句柄继续保留，不能关闭依赖存储或自动重放原命令。

PowerShell前台启动与Shell一样复用共享start_process接管创建等待；取消后仍接收迟到句柄，并通过cleanup_process等待所属清理，再传播重复取消。创建清理失败保留原ProcessCleanupError，不能继续采集或重放命令。回归使用创建和清理屏障验证边界，平台替身通过不等于原生PowerShell验收。

智能体成员批量关闭须逐项尝试并在最后聚合原始异常；首个失败不能跳过后续成员。只有成功收尾的对象可从内存及父索引移除，失败身份保留供显式重试。回归区分全局与指定父范围，核对其他分支、单项取消原对象、多项错误及重试结果；取消同样不能绕过其余成员收尾。

成员等待的零秒必须立即返回当前状态，不能用真值判断回退成默认长等待。SDK与工具入口共用有限非负数校验，拒绝bool、数字字符串和非有限值；工具保留当前最大等待截断。回归用未结束的实际任务确认零秒不停止成员，并检查非法参数在目标读取前拒绝、正常正数及默认等待仍可用。

传输响应已打开后的回调失败同样进入响应关闭收尾；重复取消须等待该次关闭结束，正文成功不能掩盖关闭失败。主异常与关闭异常按原对象聚合，不能只保留最外层错误或将关闭失败当成功。

模型流按已拥有层级逐项关闭解析器、协议包装、监控流与底层传输；某项关闭失败或取消不能跳过后续句柄。收尾后复用共享异常聚合，单项保留原异常类型与身份，多项保留全部原件。正常完成仍关闭底层一次，不因增加清理而重放模型请求。

审查异常传播时同时核对主异常、异常组和__cause__/__context__原对象，不因最外层异常变化就认定原错误丢失。未确认的流清理或追踪持久化失败不能吞掉并报告成功。原生流初始文本块和后续文本增量共同组成正文，不能仅消费delta而丢弃起始正文；模型与工具原文保持。

Web停止逐项尝试MCP、监听、事件桥和所属服务的收尾，最后聚合原始错误；取消也不能跳过其余资源。所属循环线程join超时仍存活时，保留句柄并返回双语未确认错误，不跨线程排空或关闭正在运行的循环；宿主循环所有权保持。 已被Hub或其他资源所有者取消的任务，循环排空不得再次cancel打断其finally；等待全部已有任务后仍尝试异步生成器和循环关闭，原任务收尾失败及各阶段错误聚合回传，不只记日志。

WebSocket连接收尾须覆盖快照读取、ready正文准备及首帧发送，不能只包住后续读循环。初始化失败保留原异常，并在连接所属循环撤销订阅、关闭连接及等待原生I/O；外层HTTP断开仅作最终兜底，不替代异步收尾。 Hub订阅和撤销由连接所属循环执行，HTTP线程不重复撤销异步队列。HTTP重放与事件循环快照更新、清空共用可重入锁，复制嵌套正文后再交给调用方；锁内同步操作不得等待网络I/O。

终端关闭须区分进程停止未确认与停止成功后的读取收尾失败。后者允许显式重试剩余收尾，不能因主进程已退出永久拒绝，也不能再次投递进程终止；停止未确认且主进程已退出时仍保留人工核实保护，防止向复用PID发信号。

终端输出读取异常必须保留原异常和此前输出，不能当成正常EOF或进程退出；前台与后台等待共用失败，后续输入拒绝，进程状态仍按真实句柄读取。浏览器反馈传递显式资源身份，失败流排空保留内容后停止轮询，不重放输入或自动终止。

终端同步信号入口只有系统投递成功才能返回delivered；进程消失或权限拒绝保留原异常作为原因并使用当前语言错误。POSIX管道路径回执报告实际进程组，而非假定组长等于PID；Windows平台适配的显式降级不等于可以吞掉最后投递失败。

ConPTY Ctrl+C与普通终端输入共用串行写入并等待drain，不能创建无人等待的投递任务后立即报告成功。终端等待的后台适配器通过异步stop_owned投递中断，只有投递成功才取消本次等待；失败保留原作业错误，不补发SIGKILL，也不将等待取消误称实际命令已退出。

Windows管道终端创建同样拥有不可撤销的创建等待；调用方取消后保留名称与创建归属，接收迟到句柄并登记原会话，沿既有关闭路径等待回收。重复取消不能提前释放名称或丢弃句柄；不重放创建。

前台terminal_send取消后通过服务的同一关闭入口回收，仅一次停止并等待所属收尾；重复取消不能截断回收。关闭成功才释放名称，失败保留会话和名称并传播ProcessCleanupError，不让普通取消遮住未知回收结果，不重放原输入。

start_turn提交后的运行辅助状态初始化必须进入本轮异常与取消收尾边界；初始化失败也写入唯一turn/end，不能留下open_turn阻止后续轮次。回归须确认未请求模型、原错误保持和下一次对话仍可运行，不能用重置会话掩盖未收尾轮次。

终端创建/输入/停止、作业停止及智能体停止后的审计不完整提示，按已知操作选择公开ui.audit资源；后台同源解析，浏览器保存资源身份，通知和行内错误均在呈现时翻译。切换语言不得重新创建、输入或停止，也不能将审计失败解释为操作未执行。

权限策略缓存按已提交的新事件增量核对，恢复历史后重新扫描；追加后广播等待失败或取消，也不能继续使用旧策略和旧短期授权。追加前失败则保持原版本与授权，不重放写入。策略锁同样跟踪等待者，对话删除须在任何修改前明确拒绝忙碌策略。审批审计失败不能准入实际工具，撤销的审计失败不能恢复旧授权；审计不完整警告在浏览器保存资源身份，切换语言不重新撤销。

计划状态的同步取消、遗忘和对话删除须先确认审核锁没有持有者或等待者；释放到等待者恢复之间也不能替换锁。忙碌时使用双语plan/busy明确拒绝，删除前置检查必须早于取消问题、清目标和删除存储，不把已进入持久化的切换报告为已取消。

步骤前钩子用于计划切换和团队约束等执行状态结算，不是可丢弃的观察通知。同步或异步结算失败应保留原错误并结束当前轮次，不继续后续钩子、模型请求或工具；取消继续沿既有取消收尾，不自动重放结算。

并行工具读取的批次由智能体拥有：观察者取消时只向各任务发送一次取消，并等待全部已启动任务收尾。重复取消不能再次打断工具finally；批次等待应屏蔽观察者取消后沿共享join_cleanup收敛，不重放工具。

上下文整理的跳过摘要与工具结果裁剪分支也须保留compaction_id；落盘end与实时end共用同一metrics，指向实际start序号。无需模型请求不等于可以省略结束广播或关联身份；不改写旧日志补造身份。

子智能体清理失败不应在工具配对和轮次结束之前提前逃出；先保存清理异常，完成原失败/取消/限制分支的协议收尾后传播原异常，原业务错误与清理错误同时保留。不得重放清理或把未知资源结果当成功；持久化与重复取消的组合仍需独立回归。

子任务清理的等待复用join_cleanup：重复取消不打断已拥有的回收；原失败、清理失败及后续协议提交失败应保留各原异常对象。结束提交可能已写入时只尝试一次，不因收尾失败补写或重放工具；未准入工具用现有not_executed证据配对。

共享清理等待仅观察已拥有的Future，不向它传播观察者取消；使用asyncio.wait等待后由result读取原结果，避免取消后的shield诊断制造重复失败通知。重复取消仍等待实际结束，原清理失败优先传播，多个等待者不重复执行回收。

并行读取批次的聚合Future同样有明确观察者：等待不将取消传播给聚合器，取消时仍逐个工具仅投递一次并等待收尾，随后取回原聚合终态，不能留下额外shield诊断或未取回异常。不得通过吞掉工具错误或提前返回消除诊断。收尾汇集中的非取消异常须与原批次错误或取消一起传播，保留原异常对象；同一个原始错误不重复汇入，已处于取消中的工具不再次投递取消。

截图捕获失败后的恢复也可能失败；恢复异常不得覆盖捕获原件，两者按原对象聚合。此规则同时覆盖桌面捕获和网页后端原生捕获；后端失败路径仍释放捕获锁，聚合保留捕获和窗口恢复的各自错误码及原始原因。只在同一捕获代次触发收尾，单捕获错误维持原类型/对象，不重放截图。

截图finish是有结果的单次收尾：多个出口共用同一等待，成功后才恢复焦点和释放截图准入。原生窗口恢复失败保留失败状态，重复finish不得因active=false变成成功；前端按双语资源说明未确认恢复并阻止再次捕获，显式检查窗口及重启后再用，不自动重放恢复副作用。卸载仍观察所属收尾，真实恢复失败可以全局通知，不能因原按钮消失吞掉。

## 网络、静态资源与握手

压缩协商按完整Accept-Encoding编码名及质量值解析；q=0.5不能按q=0子串判为拒绝，gzip相似名称不能误匹配。JSON与静态文件共享协商函数，显式gzip拒绝优先于通配符。

静态资源每次请求重新解析真实路径并核对构建目录边界，目录index和SPA回退首页同样检查；不得缓存一次成功的路径授权后继续读取被替换的越界符号链接。内容压缩缓存与路径授权分别处理。

网络协商中的语言也属于实际调用上下文：网页Accept-Language和默认搜索地域不能固定中文；按支持语言选择第三方协议值，原查询只编码不翻译。引擎健康状态按实际主机隔离，不将中文端点故障传播给另一英文端点。

网页和图片联网读取共用地址校验，DNS任一结果命中本地、组播或保留地址都须在HTTP前拒绝。IPv6唯一局部/站点局部地址不能落入默认放行；IPv4映射、6to4和Teredo先核对嵌入IPv4，Teredo两端都需检查。回归使用受控DNS和公网正例，不访问真实内网，不把该分类校验冒充完整DNS重绑定防护。

WebSocket握手的session、view、since查询参数出现多次时，在权限读取与升级前返回参数错误，不静默采用首值。现有Origin校验和游标上限保持，错误文案使用调用语言资源。

HTTP错误出口与成功响应共用来源校验和X-Request-ID上下文，允许来源才能读取跨域错误，拒绝来源仍不授予跨域访问。添加Vary: Origin须保留已有Accept-Encoding，压缩错误的原始正文与结构化诊断不能因响应头修复而改变。

WebSocket升级前按RFC 6455校验GET、HTTP版本、单个Host/key/version及Upgrade/Connection令牌；key必须为有效Base64且解码为16字节。Connection多行列表与大小写无关匹配仍合法，版本拒绝返回426及支持的Sec-WebSocket-Version: 13；错误使用完整双语模板，不为旧协议版本增加兼容。

静态正文读取须核对实际打开句柄的设备、inode、变化时间、大小及普通文件类型，读取前后身份不符返回现有双语错误且不缓存；编码缓存包含文件身份。重复路径解析不能替代句柄核对，解析到stat之间的边界仍需独立验证。

支持dir_fd的平台在资源元数据阶段从根目录句柄逐级以NOFOLLOW打开，再读取实际文件身份，防止resolve之后父目录替换影响正文或304。无目录句柄平台仍需单独核对对应原生路径机制，不以POSIX回归冒称Windows竞态已解决。

Windows静态资源元数据与正文均查询已打开句柄的GetFinalPathNameByHandleW结果，统一扩展路径/UNC再按路径段确认根内；查询失败或越界拒绝，不用文件名前缀猜测安全。平台无实机回归时明确保留验收限制。

## UTF-8 默认边界

默认由框架所属启动入口统一设置，不为默认行为机械改写全部调用点。运行库文件/协议边界不依赖 SDK 宿主的默认编码；命令输出复用严格增量解码器及创建时固定的 output_encoding。非法字节保留此前原文，记录通道、实际编码、字节偏移和原因，继续排空管道并完成原生命周期；不得以替换字符或候选编码猜测伪造完整结果。源码检查与全量验证见 [文本编码](text-encoding.md)。

执行器搜索除预检文件大小外，实际句柄读取也须有字节上限；检查后增长到超限的文件跳过，不得无界读入或用前缀冒充完整搜索。文件读取和搜索前缀共用严格UTF-8解码，只有因字节上限切开的末尾字符允许暂不输出；真实非法序列和文件末尾残缺字符不能替换成U+FFFD。读取明确报错，搜索计入不可读文件警告；拒绝后保留原件，不授予成功读取观察。

文件工具列举目录时，根目录或递归子目录读取失败都返回带具体目录身份的双语错误，不能吞掉异常后将空清单或部分清单冒充完整结果。合法空目录仍正常返回空清单，原操作系统错误作为诊断原因保留。

独立脚本 UTF-8 重启只替换解释器区域内精确的 utf8 开关；执行目标及其后业务参数、无关 -X/-W 选项保持原顺序与原文，不能按字符串前缀删除应用参数。

## 构建完整性与验收记录

长期有效的行为约束维护在正式文档，对应触发条件与业务断言保留在源码测试中。工具生成的临时验收回执可随时清理，不作为唯一的防回归依据。

构建缓存不能只检查index.html存在：保存并逐文件核对产物清单和内容身份，公开静态输入纳入源指纹，链接/缺失入口不得确认成功。新构建失败不得覆盖上一份成功状态；产物身份仅证明与已记录构建一致，不证明所有平台运行验收。

初次记录产物身份也要检查入口的本地资源引用；不能把一个非空index.html加空资源目录当完整构建。引用路径须位于产物根内，缺失不得记录成功缓存；外部内容不由缓存擅自下载或补造。

文件恢复标题使用含轮次参数的完整双语资源；切换语言只重新呈现，不重读预览或重放恢复写入。恢复预览的初始读取和后续分页均核对对话、执行与版本；累计条目数、总数与下一游标须一致，空的非末页不得继续翻页。同一版本的完整范围与核实要求不可漂移，待核实计数是有界安全整数，累计完整列表须与全局计数一致；条目不能重复已有的序号与调用身份组合。分页失败撤销旧确认并阻止提交旧预览，重读保留指令与核实说明，不自动恢复核实勾选。原文分页和恢复工具列表的游标规则分别按各自协议验证，不相互套用。运行历史分页按资源类型同步准入，隐藏或切换对话后旧操作的收尾不得解除新实例的准入锁；文件目录分页身份错误使用可随语言切换的资源提示，并保留已经确认的列表。

ACP 发送必须在取得写锁后重新检查连接关闭状态；排队期间关闭的连接不得继续写入。StreamReader 的行长拒绝与显式帧长度拒绝使用同一调用语言资源。浏览器合成画面的启动、取帧和关闭按页面串行管理，管理器关闭后不再创建捕获；不同页面保持独立，等待者取消不得关闭其他操作持有的画面。受控 CDP 替身与租约时钟回归不代表真实浏览器或跨平台实机验收。

对话原地恢复须先构建全部事件投影及表面，全部成功后再替换当前索引；非轮次事件和替换范围损坏同样不能留下部分恢复状态。失败保持原历史、观察证据、消息缓存版本与监听器待办，不广播新事件；成功仍绑定原对话，既有监听器正常继续。

对话监听器使用单次所属收尾任务，并发drain与重复close都等待它完成；等待方取消不撤销已经开始的工作。监听器自身取消时，尚未开始的待办保留供后续显式收尾，不重复执行已完成项。轮次操作栏和消息编辑/设目标状态绑定对话与事件身份；更换身份不得继承原分页、忙碌状态或弹出旧失败提示，已接受写入仍按原归属收尾。

主运行错误的显式资源身份必须经过历史摘要与恢复预览保留；HarnessError详情中的copy同样不能丢弃。界面语言变化只重新呈现错误，不重复查询或续跑；恢复版本基于原始已存证据，不把当前译文写回记录或纳入变化版本。

运行正文与委派摘要的JSON读取共用字段唯一性检查，嵌套成员参数同样拒绝重复字段；不能靠后一个身份或状态覆盖前值。启动恢复失败回滚同一事务内已准备的变更，原件保留，不尝试迁移或重放运行。

对话头的目录、加载及导入共用当前格式验证：版本与创建时间不接受布尔或字符串，目录身份必须与存放目录一致，可选字段与metadata容器保持明确类型。损坏尾行只提供已确认前缀，保留原日志并拒绝新写入，不隐式截断或迁移。项目注册表核对持久id与绝对路径身份，返回嵌套隔离快照；exists来自当前文件系统，读取不回写用户文件。ACP关闭各项回收分别尝试，错误原件聚合；失败任务可显式重试，成功清理的任务不重复带入旧错误。

联网工具的直接SDK调用与模型调用使用相同参数边界：query/url必须为非空字符串，数量和大小必须为正整数，raw必须为布尔值，timeout必须为有限正数；非法输入在读取提供方设置和发起网络请求前拒绝。提供方异常回执按当前结构验证并明确报错，不通过str/int强转制造合法字段。查询正文和第三方文本仍保留原文，提供方当前合法结果数量约束继续由适配器处理。

抽屉入口和恢复焦点帧共用一个所有者，新抽屉打开时取消旧恢复帧，卸载后不得恢复旧焦点；目标面板的异步打开绑定原挂载实例及新对话代次，已接受创建继续收尾但不打开新实例面板。成员执行、上下文关闭及交付连续失败时保留按发生顺序组合的诊断和结构化原因，不让末次错误覆盖前因。钩子声明、持久状态和决策JSON拒绝任意深度的重复字段；完整但无效的退出回执须明确失败，未完成JSON仍可等待写入结束。SessionStart的未知分发结果不自动重放，钩子进程清理由单次任务拥有，重复取消等待原回收后传播。

依赖探测缓存不向调用方暴露可变引用：缓存首次保存隔离生产者结果，每次读取返回独立快照；模型工具与直接SDK返回的运行时、包列表修改不得污染后续读取，也不应因快照隔离重复探测。

依赖探测的include_packages只接受布尔值，错误在启动线程前拒绝；工具取消仍等待已开始的探测线程，不重新探测。包数量统计覆盖全部有效条目，展示上限从全体条目按稳定排序选取，不能先截断系统枚举顺序再排序。工作区目录来自本次调用上下文；MCP 选择须核对项目或对话身份，多项目不自动猜测。服务解释器的包、PATH 工具及项目依赖入口分别报告，入口存在不等于可用，链接只标记、不读取目标或自动激活环境。模型正文须包含实际路径和包清单，不能仅将其保存在不进入模型上下文的 data/display 中。

Git暂存写入按仓库身份共享在途操作，受理写入与未知结果的只读回查完成前不重放；成功回执核对仓库和提交格式，post-commit 钩子移动HEAD不否定原提交。提交草稿按提交时正文及修改代次比较清理，同值重写也属于新草稿；原实例关闭不回调其目录呈现。git/commit-uncertain即便使用4xx仍属于结果未知，不能按明确拒绝处理。MCP服务状态同时提供error原文与error_copy资源身份，自有错误由浏览器按当前语言解析，外部诊断error_copy为null；源语言资源、公开协议和浏览器生成契约同步维护。使用共享HTTP传输的浏览器夹具同样提供完整当前响应；无错误状态也显式提供error_copy:null，不绕过响应校验或放宽必填字段来维持旧夹具。账号操作与模型选择共享同步准入，暂停写入期间的观察；写前目录响应不能覆盖写后的目录。模型选择的异步回归须等待原事件处理Promise完成后检查写入次数，不能以固定毫秒延迟证明操作已经结束。

本机OpenCode资料的所有读取入口须共用解析前大小限制、UTF-8与字段唯一性验证，不能只有最终加载受限而配置发现或bootstrap捕获仍无界读取。拒绝损坏资料时保留原字节，不尝试迁移或修改用户登录；第三方上下文不翻译。

模型目录条目必须具有唯一且非空的文本ID；名称出现时须为文本，不以str转换接受损坏身份。目录JSON拒绝重复字段、孤立代理码点及过深结构，错误使用实际调用语言；未报告或非法推理能力字段仍表示未知，不补造档位。直接SDK参数在启动目录读取前校验对象与provider/model文本类型，合法扩展与原文保留。

运行时版本探测使用保留首进程的独占监督进程组，stdout/stderr各限制8 KiB；完整合法的首行才可作为版本，超时/超限/非法编码为空，收尾失败必须向上传播。版本命令须以整数零退出，非零退出的stdout或stderr诊断不能作为版本号。版本命令先退出不代表其后代已结束，所有路径在返回前回收所属进程树；不得用无界capture_output或只kill已退出首进程代替。POSIX实测不代表Windows进程树已实机验收。

Key池对同一状态文件的读改写必须在稳定旁路锁内完成，不能仅靠每实例异步锁或临时文件唯一性防并发覆盖。同步与异步入口使用同一事务，取得锁后读取已确认状态再修改；锁失败不得无锁发布，保存失败的本地失败标记须在后续回查/重试时保留。锁文件释放后不删除，避免等待者锁住旧inode；它不保存凭据或改变当前状态格式。

托管MCP配置更新先在同目录创建唯一临时文件，完整写入、flush及fsync后再原子替换；发布前核对最初读取的原字节，准备期间已变化则拒绝并保留外部版本。失败只清理本次临时文件，不覆盖用户原配置；该乐观检查不保证与无锁外部编辑器之间的原子CAS。

托管MCP停止时，进程清理失败不能跳过启动线程join；全部尝试后聚合原异常。仍有启动线程或进程句柄、或本次收尾失败时保持停止中，不能发布stopped。

托管MCP隧道输出线程保存所属句柄，进程停止后有界join；未停止或join失败保留句柄及错误，不能报告已停止或启动新实例。已失败实例仍有进程或输出线程所有权时，先显式完成停止，不覆盖旧句柄。

托管MCP退出回调只随实际启动所有权注册，完整停止后撤销；重复停止不重复撤销，重启重新注册。未完成清理时保留退出兜底，不因状态失败覆盖旧资源，提示使用通用资源未释放说明而非猜测为隧道线程故障。

自动化关闭开始即停止tick、手动运行和调度启动准入，拒绝发生在租约、数据库及运行登记之前；关闭失败后的显式重试仅执行原收尾，不重新开放生产。多个调度实例仍按数据库租约保证同一到期任务只被当前所有者认领。

重新打开长对话时，消息卡片直接呈现，历史轮次摘要的懒加载在首次布局恢复期间不逐项强制贴底；摘要稳定后只恢复一次底部位置，实时新消息仍按当前跟随意图处理，避免加载过程中的连续滚动跳动。

工具输出流的output_seq、stdout_offset、stderr_offset必须是实际number类型的安全整数，不以Number强转接受布尔、文本或空值；非法帧保留此前预览，Unicode偏移、重叠拼接及乱序丢弃语义保持。

浏览器草稿持久化失败后保留内存中的最新编辑或删除意图，后续读取不能用旧磁盘值覆盖；成功读取的草稿也须缓存供读取故障时回退。每次写入和删除前重新核对当前原件，损坏时保留原字节，不能仅依赖首次加载时的校验。
