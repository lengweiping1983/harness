# 对话内可视化

Harness 支持在消息流中展示 SVG、HTML、Mermaid、ECharts、Vega、Vega-Lite、Chart.js、Plotly 基础图表以及 CSV／TSV 数据表。正文数学公式通过 KaTeX 排版。无需先生成网站或切换项目；原始代码随所属对话保存，渲染和下载复用原消息。

可视化正文及 `show_widget` 交付保持可见，不随轮次结束或后续的文字总结归入默认收起的执行过程。普通文字过程仍沿用原有折叠规则。

## 入口与载体

对话内展示需要真实的展示载荷：成功的 `show_widget` 结果，或消息正文中的完整 HTML 围栏。创建 `.html` 文件、读取截图或提供文件链接不会自动向对话发布交互预览；前端不从历史文件写入参数或截图推测并执行页面。

`harness/prompt/tool_policies.py` 在可用工具包含 `show_widget` 时装配双语 `policy.visualization`。模型请求明确优先交付小而可用的自包含预览，不为普通对话演示先写文件、启动服务器或反复截图；用户明确要求的文件、实现方式和测试仍优先。该指引进入实际模型请求，不保证每个在线模型都遵循。

`show_widget` 接收一个 JSON 对象，必填 `title` 与 `widget_code`。可选 `kind` 为 `auto`、`svg`、`html`、`echarts`、`vega`、`vega-lite`、`chartjs`、`plotly`、`csv` 或 `tsv`，`loading_messages` 提供加载提示。`widget_guidelines` 按 diagram、chart、interactive、mockup、art 返回当前语言的设计指导。

```json
{"title":"流程图","kind":"svg","widget_code":"<svg viewBox='0 0 240 80'><text x='16' y='44'>Request → Canvas</text></svg>"}
```

SVG 需要完整 XML 结构及根元素的 viewBox 或宽高；支持前置注释、XML 声明及嵌套 SVG，拒绝损坏 XML、脚本、DOCTYPE 与实体声明。前端继续清洗事件属性、危险链接、foreignObject 等内容；静态图的同名 gradient、marker 与引用按图形实例隔离。正文中的 SVG 围栏与独占一行的裸 SVG 保留渐进绘制，已经画出的节点随增量更新，不整块重建。围栏闭合后，含样式或动画的完整 SVG 转为独立图片上下文，保留 CSS 关键帧与 SMIL 动画（animate、animateTransform、animateMotion、set）及原始动画时序引用；工具卡片采用同一渲染方式。图片内部样式与宿主隔离，脚本及外部资源不能执行或加载；图形颜色和字体由 SVG 自身定义。对话中的重播按钮重新加载动画图片，下载保留动画；静态图继续沿用增量节点和描边重播。

HTML 支持片段与完整文档，包含内联 CSS、JavaScript、Canvas、SVG 和普通控件。明确标记为 `html` 的围栏闭合后默认显示沙箱预览，也可切换源码；普通 `xml` 围栏只显示源码。完整工具调用通过校验后，`ToolBlock` 从 `display.widget` 显示卡片。模型工具结果只包含简短确认，代码仍保存在调用参数与界面展示数据中，不再复制到结果正文。

## 声明式图表

标准图表可直接输出对应格式的 JSON 围栏，或以同名 `kind` 调用 `show_widget`。模型不必写 HTML、引入 CDN 或安装依赖。`auto` 只识别 SVG／HTML；JSON 必须明确选择格式，不猜测普通 JSON 代码块的用途。

| 围栏／kind | 输入 | 呈现 |
|---|---|---|
| `echarts` | ECharts option 对象，含 `series` | SVG 图表，支持原生图例、提示和数据缩放配置 |
| `vega` | Vega spec，含 `marks` | SVG 与数据流／信号交互 |
| `vega-lite` | Vega-Lite spec，含 mark、layer、concat、facet 或 repeat | 编译为 Vega，以 SVG 呈现 |
| `chartjs` | Chart.js 配置，含 `type`、`data` | Canvas 图表与原生交互 |
| `plotly` | 含 `data` 数组，可选 `layout`、`config` | Plotly basic：scatter、bar、pie；不包含 3D／地图等扩展 trace |

例如以下 `echarts` 围栏会直接绘图：

````markdown
```echarts
{"xAxis":{"type":"category","data":["A","B"]},"yAxis":{"type":"value"},"series":[{"type":"bar","data":[3,8]}]}
```
````

完整配置才校验和加载运行库，流式半成品只显示接收状态。运行库以文本分片随本地构建分发，按格式首次使用时加载；并发共享一次下载，Vega 和 Vega-Lite 共享同一运行库。下载失败或超过 10 秒显示源码和“重新加载”入口，迟到成功只更新仍所属的实例。成功加载不证明配置正确；真正绘图失败仍由沙箱报告，源码始终可取。

配置仅接受字段唯一、有限数字、大小有界、最大嵌套 48 层的 JSON 对象。保留原始 JSON，不接受 JavaScript 函数或原型保留字段。数据必须内联；`url`／`href`／`src` 外部资源入口明确拒绝。声明式图表采用独立的离线 CSP，不允许外部脚本、样式、图片、字体、fetch、WebSocket 或动态求值；Vega 使用表达式解释器而非放开 `unsafe-eval`。代码与运行库均不在宿主页面执行。库加载完成与异步图表绘制分别确认，图表未就绪时不移除初始化等待。

图表沿用卡片的源码、复制、下载与放大；复制和下载取得原始配置，文件名为 `标题.格式.json`。源码切换、主题及语言变化保持同一沙箱实例；宽度变化合并到动画帧。不同图表的视觉主题细节由各运行库和用户配置控制，不覆盖原始配置或把所有图表色强行映射为产品状态色。

## CSV／TSV 数据表与工作区文件

`csv`／`tsv` 围栏以及同名 `show_widget.kind` 直接生成数据表，不需要 HTML 或图表运行库。CSV 采用双引号包围含分隔符／换行的单元格，单元格内双引号写为两个双引号；TSV 使用相同的引号规则、Tab 分隔符。支持 LF、CRLF、CR、BOM、空单元格和多行单元格。表头默认为首行，可取消“首行为列名”。

数据表支持筛选、按列稳定排序和每页最多 50 行的分页。升序时明确的有限数字优先并按数值比较，其余值按当前语言排序；降序反转该顺序；显示和下载不改变单元格原文。源码切换、原文复制和下载共用同一输入，数值的前导零、空格及原始行尾均保留。单元格始终按文本显示，不解释 HTML、链接或公式。引号损坏、列数不一致或超限时显示明确错误和源码，不把部分数据伪装成完整表格。单表上限为 200,000 个 UTF-16 代码单元（工具端原文同样限制大小）、10,000 条记录、100 列及 50,000 个单元格；解析、筛选和排序在有界输入内完成，DOM 只挂载当前页。

工作区的 `.csv`、`.tsv` 及 `.echarts.json`、`.vega.json`、`.vega-lite.json`、`.chartjs.json`、`.plotly.json` 文件默认提供相应预览，可切换源码。普通 `.json` 不根据内容猜测用途；带行号引用仍优先源码定位。文件预览复用对话中的数据表和图表组件，使用原文件读取权限与大小边界，不启动服务器或写入文件。

文件切换按 URL／导航身份拒绝旧内容；隐藏时暂停读取与图表观察。文本读取采用严格增量 UTF-8 解码：完整文件中的非法字节或残缺码点明确失败；仅受大小限制截断的末尾码点可暂不输出。读取与清理同时失败时保留两个原因。截断文件只显示源码前缀和已有截断说明，不提供数据表或图表预览，也不宣称文件完整。

## 渲染块（type="renderer"）

模型以 ` ```html type="renderer" ` 围栏输出时，内容作为**页面本身**展示：流式未闭合先显示“正在渲染”骨架，实际围栏闭合后直接在沙箱中渲染，提供源码切换、复制、下载和放大。停止或结束时仍未闭合的块保留源码和未完成提示，不执行半成品脚本；普通 `html` 围栏也必须实际闭合才能预览。

渲染块与 HTML 卡片共用同一套沙箱、CSP、主题注入、高度回传与错误降级规则（见下文）。顶格围栏由流式分段器精确切出（未闭合不渲染半成品）；列表、引用等缩进场景及整篇文档（文件预览）由 remark 插件根据原始位置核对围栏，再将明确标记和闭合状态传过清洗器，走同一渲染组件兜底。`type` 属性按完整名称和值匹配，不接受相似名称、值前缀、重复属性或其它属性字符串内的伪标记。引用内的媒体标签保持原始 HTML。

可运行的示例为 [并发交互实验](../examples/visualizations/flow-lab.html) 与 [请求流 SVG](../examples/visualizations/request-flow.svg)。实验使用固定数据与简化公式，不代表真实硬件性能。

## 交互、状态与隔离

`show_widget` 调用在加载、成功和失败状态均作为独立对话行保留，`turnActivity.ts` 的轮次折叠与 `toolRuns.ts` 的活动分组不隐藏它。轮次完成、历史重开和收起过程后，已提交的 SVG／HTML 仍直接可见；运行中卡片的加载态不能在成功时被过程摘要替换。

可视化工具摘要的收展箭头紧跟标题文字。箭头控制工具调用详情，详情默认收起；展开后紧接摘要、位于预览上方，使用[统一工具详情卡片](project-contract.md#必须保持的业务行为)的层级，并与预览保留间距。收展详情不隐藏或重建预览，已加载的交互状态继续保留。

卡片提供源码／渲染切换、复制、下载与放大。SVG 支持保存 PNG 和复制图片；PNG 从实际图形取样颜色、字体与尺寸，避免导出工具栏图标或丢失主题颜色。源码下载仍可编辑。

HTML 在 `sandbox="allow-scripts"` 的不透明来源 iframe 中执行，不授予宿主 DOM、Cookie、存储或原生工具权限。CSP 禁止 fetch、WebSocket、表单提交、对象嵌入与 base 修改；内联代码和已列明的 jsDelivr、cdnjs、unpkg、esm.sh 依赖可加载，HTTPS 图片／字体同样允许。不是可任意联网或访问工作区的运行环境。

初始化采用文档启动握手，并在文档就绪且完成两帧绘制后移除等待遮罩。等待超过 10 秒时显示当前语言的失败提示，保留源码和手动重新运行入口；超时不撤销脚本，也不自动重放，原文档随后就绪时可正常恢复。脚本异常、Promise 拒绝和资源加载错误显示在卡片内，保留源码，用户可明确选择重新运行。报错发生在消息监听建立前时仍由握手补交，不把空白 iframe 当作成功。高度消息必须同时匹配所属窗口、实例与代码代次；其它图形、旧文档或已替换 iframe 的消息不能覆盖当前状态。

主题通过消息更新 CSS 变量与 dark 类，不重启脚本。切换源码和放大同样保留已加载的交互状态；替换代码、重新运行、关闭页面或刷新会重新初始化。嵌套 Markdown 的组件类型也保持稳定，语言切换和流式收尾不会因替换组件类型而重建已加载的 iframe。当前控件状态保存在 iframe 内存中，不作为对话持久数据保存。

页面隐藏或切换源码时，宿主主题观察与沙箱布局观察暂停；恢复时沿原文档重新握手，不重放脚本。高度回传合并到动画帧，相同高度及超出高度上限后的重复变化不重复提交；宿主也拒绝重复尺寸更新。HTML 预览期间不调度隐藏源码的语法高亮和溢出观察。沙箱内用户脚本自身创建的定时器不由宿主强制暂停。

## 参数失败与回归依据

参数为空或缺少字段时继续明确拒绝执行，不补造可视化代码。原生供应商库在 JSON 解析失败时可能同时返回空参数对象和 `argumentsError`；桥接保留该诊断及收到的原文，工具校验拒绝它，避免误报为只有必填字段缺失。截断的可视化调用必须由模型按错误重新提交，不能自动执行部分脚本。

- `tests/test_visualization_policy.py` 核对同一宿主英文→中文→英文的真实模型请求包含交付策略与当前工具说明；隔离工作区不产生文件。`toolRuns.test.ts` 与 `turnActivity.test.ts` 覆盖两层折叠、加载／成功／失败及 SVG／HTML 身份保持。
- `tests/test_chart_widgets.py` 与 `chartSpec.test.ts` 核对五类配置、双语错误、字段唯一性、有限数、资源／原型拒绝、深度及原始配置下载身份。`chartRuntime.test.ts` 核对并发下载共享与 Vega/Lite 复用。
- `tableData.test.ts`、`filePreviewText.test.ts` 与 `tests/test_chart_widgets.py` 覆盖表格引号／分隔符／行尾、原文、排序与边界，以及文件读取与清理错误；`table-preview-smoke.mjs` 覆盖实际 Markdown、工具和文件预览中的排序、分页、筛选、语言／主题／尺寸往返、下载、隐藏、文件身份、截断和编码拒绝。
- `chart-spec-smoke.mjs` 使用实际 Markdown 与工具卡片逐个绘制本地运行库，检查几何内容、无外部请求、真实点击事件中的动态求值拒绝、宿主隔离、语言／主题／宽度往返和 JSON 下载，并记录就绪耗时；还验证图例切换和 Vega／Lite 滑块对真实图形与数据可见性的影响，以及状态在主题／语言／宽度变化后保留。CSP 探针固定在沙箱可视区域内，不改变正文高度；同时核对可信点击、执行完成、`EvalError` 和强制 CSP 的 `eval` 拒绝事件，不把未触发或其他异常算作拒绝。Chart.js 分支另将实际高度更新安排在鼠标按下与松开之间，覆盖旧探针因滚动归零而松开在 Canvas、最终点击 Body 且没有结果的交错。
- `tests/test_widget_tools.py` 核对双语工具说明、完整 HTML、SVG 结构与参数边界。
- `tests/test_widget_flow.py` 经真实发行桥接、回环供应商流和工具注册入口，核对损坏参数未执行、模型纠正、SVG／HTML 展示事件及完整源码。
- `svgScope.test.ts` 核对多图 ID 和引用隔离；`streaming.test.ts` 保留分段与渐进内容边界，并核对渲染块（`type="renderer"`）的识别、分段与闭合状态。
- `svgImage.test.ts` 覆盖完整动画的数值属性、时序引用、CSS／CDATA、XML 实体、命名空间与图片专用输出边界，以及未完成／静态图分流和脚本等内容清洗；`svgImage.integration.test.tsx` 经实际 Markdown 和工具卡片核对图片载体、动画源码、重播资源变化及双语控件，`svgImageLifecycle.test.tsx` 核对同一实例英→中→英、放大、重播、流式结束及遮挡／隐藏后的最新源码恢复。触发旧问题的是 `LiveChart` 与 `WidgetCard` 的内联清洗移除了 style、animate、set 和数值动画属性，而文件图片预览保留动画；这些单测不替代真实浏览器动画播放与布局验收。
- `rendererRemark.integration.test.tsx` 使用实际 Markdown、清洗器和卡片组件，核对顶格／列表／引用／文件预览的闭合与中断、原始 HTML 保持、普通 HTML／XML／SVG 分流和双语控件；仅沙箱 DOM 边界由替身接收源码。

- `widgetDisclosure.test.tsx` 核对工具详情位于预览之前且四周边框完整、默认收起时预览仍可见，以及加载和失败时的展示边界。`visualization-conversation-smoke.mjs` 将真实工具结果交给实际 `Conversation`，覆盖加载、完成、历史重开、两层折叠及语言／主题／宽度切换后的预览与控件状态，并包含标题旁箭头、键盘收展、详情完整边框、与预览不重叠及交互状态保持的布局断言；浏览器专项须显式执行。
- `visualization-smoke.mjs` 使用上述真实工具结果渲染组件，核对交互参数变化、源码／放大状态保留、英文→中文→英文、明暗主题、窄宽屏、错误重跑、旧消息拒绝和 SVG 下载／PNG 尺寸。
- `markdown-stream-smoke.mjs` 与 `chart-focus-smoke.mjs` 保留原有 SVG／Mermaid 流式绘制和放大后的焦点、Escape、滚动归属回归。

这些是受控本机回归，不代表每个在线模型都会首次生成完整代码，也不代表全部浏览器和各平台安装包均已验收。
