# 国际化资源与语言边界

本页说明 Python、浏览器和 workflow Node 的资源所有权及语言传播。协作规则见 [代码生成与防回归](code-generation.md)，验证入口见 [开发与测试](development.md)。

主页面与语音窗口在显示启动占位前，均从 initialLocale 取得本入口语言，同时设置 HTML lang 和占位文案。此步骤不等待正文动态模块或完整语言包，模块加载超时后的失败提示保持同一语言；语音窗口后续语言切换仍沿 VoiceCapture 的存储事件与 i18n 呈现通道执行，不重新录音或转写。

技能与插件的引导创建表单按当前语言呈现标题，首次提交时解析创建任务提示词；`/skill skill-creator`、`/skill plugin-creator` 命令标识和用户需求保持原文。结果未确认时保留原提交正文及请求号，切换语言只更新表单提示，再次核查读取原回执。

上下文输入分类及原因说明按 `harness/llm/context_accounting.py` 的当前分类分别解析资源；来源标识保留原文。展开后的分类说明随语言切换更新，保留当前展开状态及已读取的上下文快照。

记忆召回预览按当前协议的召回原因、文件来源状态、派生状态及作用域选择双语资源；记录 ID、修订和诊断码保持原文。语言切换重新呈现已读取的快照，保留详情展开状态，不触发新的预览读取。

成员栏的汇总、逐成员标签和派工摘要按当前语言解析状态资源。独立智能体的 `completed` 映射到完成标签，团队的 `done`、`blocked` 保留当前语义；旧 `error` 别名及大小写变体显示未知状态，成员名称和任务正文保留原文。团队卡片按 `lead`／`member` 身份翻译角色，未知角色保留原值；共同源快照按 `pending`／`preparing`／`ready`／`failed` 分别呈现，路径、分支及树身份保持原文。

截图裁剪的六种标注工具、六种颜色和三档线宽使用当前双语资源，工具标题和无障碍名称同步更新。合成画布不可用时保留资源型错误，切换语言重新呈现错误，不重新合成或申请屏幕权限。

工作树环境预览和历史回执共用当前跳过原因资源，未知原因显示不支持说明；回执状态按 preparing／ready／failed 分别呈现。变更预览的符号链接、不支持类型、超限和二进制原因使用独立资源。语言切换保留路径、回执及文件选择，不重新读取或导入环境。

轮次时长的运行中、待同步、完成、中断、停止和其他结束状态分别使用完整资源；缺少时间依据时使用对应未知时长文案。目标轮次档位及输入补全的目录、文件、技能、对话、命令分组在呈现时解析资源，切换语言保留草稿与候选原文。

设置导航按当前语言解析入口标题及搜索关键词，命令面板按同一语言解析设置提示与共用检查器目录标签；切换语言保留当前搜索输入，并重新计算匹配结果。

原生浏览器权限请求和已有授权按桌面权限能力映射解析资源，音视频分别显示 microphone／camera 对应文案；列表连接符跟随当前语言。加载失败、崩溃、无响应和页面已关闭各有独立故障说明。语言切换只更新呈现与布局，不自动授权、重载或导航。

请求详情的输入、工具、参数和封装字节分类，以及端点、模型、工具和设置的缓存变化原因，分别按当前语言解析资源；设置字段名称保留协议原文，列表连接符随语言变化。运行页的全部／活动／需关注视图与智能体状态标签同步切换语言，筛选操作只改变当前显示。

自动化预设的名称和提示词在选择时使用当前界面语言，进入编辑后的用户修改保持原文。运行记录的 running、completed、failed、interrupted 使用对应资源，未知状态原样呈现。Web 搜索开关按服务商选择资源；切换语言保留开关状态与未提交密钥，不重新保存。

能力设置的模型、上下文窗口、最大输出及来源标签，以及七项可选限制和网络超时标签，均从当前资源映射解析。记忆面板按项目、用户或对话作用域显示对应说明；切换语言保留当前数值和作用域，读取仍遵循各自的目录刷新策略。

插件应用的可用、未连接及缺少连接器状态按目录状态字段选择资源；应用名、ID 和连接器名称保持原文。智能体技能选择器的继承、缺失、空目录、未匹配、停用和加载提示按当前语言呈现；目录随语言刷新，显式技能选择与第三方描述保持，外部执行器不读取技能目录。

智能体目录按智能体／团队类型显示空态及创建指引；搜索未命中时显示搜索说明，清空动作保留当前类型。团队引用的缺失、停用和嵌套团队原因由当前目录计算后解析资源。技能来源标签按项目、内置或共享分类，定义名称和描述保持原文。

文件预览的 HTTP 拒绝、空响应流、读取异常及图片／视频／音频加载失败保留错误资源身份；HTTP 状态和原始异常作为参数。切换语言更新已有错误，不重新读取文件或重置行号输入。

团队成员选择器按当前语言解析搜索、外部成员、已选、配置无效、人数上限和空目录提示；智能体名称、职责及 Codex／Claude Code／OpenCode 专有名保持原文。语言切换不自动添加成员。

成员详情按当前独立智能体运行状态解析标签，completed 对应完成文案；pending、running、failed、interrupted 保持各自语义。语言切换保留结果原文，不触发详情重读或停止成员。

检查器分区选择器和当前面板的无障碍名称共用 `INSPECTOR_PANELS` 的资源身份。语言切换更新选项及当前面板标签，保留所选分区和已读取的文件内容。

运行错误的实时事件与历史轮次投影均保留显式 `copy` 或 `details.copy` 中的浏览器资源键和参数；错误卡片及状态提示在呈现时解析，切换语言不重读历史或重放运行，外部诊断原文仍保留。

工具历史恢复和轮次中断收尾的兜底输出保存显式资源键，由工具卡片按当前语言呈现；真实工具结果到达后移除兜底键并保留结果原文。语言切换不重新执行工具。

## 语言选择入口

| 入口 | 语言来源与作用范围 |
|---|---|
| 普通 CLI | `--language` 优先，其次为运行根 `ui-settings.json` 中的语言设置、`HARNESS_LANGUAGE`、`auto`；解析后的上下文在 CLI 返回时恢复 |
| 热更新服务 | `scripts/dev.py` 使用相同优先级；有效语言显式传入首次启动及后续重启的后端命令，启动提示使用同一语言 |
| SDK `HarnessConfig.from_env` | 环境配置之后读取运行根保存的设置，最后应用显式 overrides；直接构造配置不等同于读取环境与保存设置 |
| 独立 MCP 执行器 | 从执行器配置的 `language` 解析，不借浏览器界面语言自动修改已启动进程 |
| 桌面准备脚本 | 显式 en／zh-CN 优先，其他值按系统地区选择；不读取浏览器语言缓存 |

`auto` 按系统地区选择：CN、HK、MO、TW 使用中文，其他地区或地区不可用时使用英文。Python 在 macOS 读取 AppleLocale、Windows 读取用户地理区域、其他平台依次读取 LC_ALL／LC_TIME／LANG。实际运行通过原生 `current_language` 上下文变量绑定语言；项目要求 Python 3.14+，临时作用域可直接使用 `with current_language.set(language)`，正常、异常或取消退出时恢复调用方状态。显式 `set`／`reset` 仍使用原生 Token；异步任务继承创建时的上下文，各任务的临时绑定相互隔离，工作线程需显式传播所属语言。浏览器的首屏缓存与异步设置规则见下文。

## 资源源与分发

唯一文案源是 `harness/i18n/locales/en.json` 和 `zh-CN.json`。`scripts/generate_i18n.py` 将 `ui.`、`settings.language.`、`files.open.`、`browser.` 前缀生成到 `web/src/i18n/locales/`；其余资源不能假定浏览器可读。生成文件不手工编辑。Python 包通过 `pyproject.toml` 分发源 JSON 和 `tools/builtin/*.mjs`。

| 消费端 | 当前实现 | 语言与失败边界 |
|---|---|---|
| Python | `harness/i18n/__init__.py` | `tr` 读取 `current_language`；缺失键抛错；传入非空参数时用 `format_map`，缺少所需参数会失败；未传参数时返回资源原文 |
| 浏览器 | `web/src/i18n/index.ts` | `setLocale` 通知订阅者；缺失键抛错，未提供的模板参数保留原占位符 |
| 桌面准备与发行 | `desktop/setup-copy.mjs` | 从源 JSON 读取；显式 en/zh-CN 优先，否则按系统地区选择；未提供参数保留占位符，外部命令输出不翻译 |
| workflow Node | `workflow_resources.mjs` | Python 启动子进程时设置有效语言，VM 外读取源 JSON；缺失语言、键或模板参数失败 |

模板占位符没有统一的跨端缺参兜底合同。调用方须提供完整参数，并通过实际消费者验证；不能把浏览器保留占位符、Python 无参返回原文或桌面替换规则当作允许遗漏参数。参数值只插入一次，用户原文中的花括号不作为第二层模板执行。

资源缓存和子进程语言不因磁盘文件变化自动刷新。前后端开发重载见开发文档；切换语言不改写用户原文、第三方正文、已写出的日志或持久历史。

主页面首屏优先使用本地缓存的有效语言（`zh-CN` 或 `en`），无有效缓存或无法读取存储时默认 `zh-CN`，并在渲染前同步 HTML 的 `lang` 属性。服务端设置异步返回后仍按其有效语言更新界面；无缓存且服务端实际为英文时，仍可能从默认中文切换为英文。共享页面继续使用其原有的缓存优先、浏览器语言兜底规则。

浏览器按有效语言动态下载完整文案，入口只内置由同一生成器输出的双语启动提示子集（`startup.generated.json`）。入口或首份语言资源等待超过10秒时显示重新加载入口，迟到入口仍可接管页面。开发和生产使用同一按需路径，首次切换到另一语言须等待资源，随后复用已加载语言表。单测与浏览器组件矩阵夹具在同步切换语言前显式预加载双语；真实页面及生产冷启动场景不使用该夹具准备。`setLocale` 返回 Promise，调用方需要等待语言就绪后再读取对应状态；已加载语言仍同步通知订阅者。目标资源加载失败或切换等待超过10秒时保留当前界面语言，显示资源读取失败，不重放已确认的设置写入；迟到下载只进入缓存，由显式重新检查设置后应用。异步接收设置先核对操作代次，再发布语言及目录刷新。

产品名称在中英文自有文案中统一写作 `Harness`；包名、命令、路径、资源键及元数据中的机器标识保持原样。

空列表与缺少内容的提示按场景说明这里展示什么，或给出可执行的下一步；中英文资源同步维护。等待加载、没有记录与操作结果未知分别表达，结果未知的警告保留核实要求，不改成普通空态。

任务队列面板中的“待执行任务队列 / Pending task queue”标题在成功读取后通过完整双语模板显示括号内的任务数量，英文按一项／多项选择单位；首次读取尚未确认时只显示标题，不补零。空队列只提示暂无待执行任务，任务历史说明保留分页上限和展开详情指引。队列内的跨次运行列表称为“任务历史 / Task history”，单次运行的查看入口与详情称为“执行任务 / Execution task”，详情关闭动作仅称“关闭 / Close”。独立模型请求、工具调用和子智能体活动面板称为“请求与工具日志 / Request and tool log”；页签、分区选择器、启动器及命令面板共用后者的资源身份，加载、空态及错误提示沿用同一功能名称。计划面板的标题、空态和执行清单说明在呈现时解析当前语言，清单说明不固定引用上方的计划版本关联。

对话页按实际发送、运行、待回答问题和生成状态选择当前语言的反馈，待审批与普通问题优先于旧生成状态；流式输出和空闲状态不显示运行反馈。空态建议在呈现和点击时使用当前语言，点击时将当前译文交给主页面的对话发送入口。

协作分享地址和邀请链接的复制操作复用公共复制组件，成功或失败反馈按当前语言呈现；邀请与成员角色控件使用各自的名称资源，成员控件名称包含目标名称；observer、collaborator、administrator 三种角色选项及已有邀请共用对应角色资源。切换语言保留待邀请角色和已有权限快照，不自动邀请、审批或修改成员。

人格推荐问卷初始不预选，四个维度均作答后才可请求推荐。四个维度标题、八个选项和用户／内置／全部来源页签在呈现时解析当前资源；选择选项或切换目录页签不自动保存人格或提交推荐，用户草稿正文保持原文。智能体与团队的创建、编辑和只读表单按当前语言呈现字段及校验提示，名称、说明和指令正文保持原文。智能体创建表单复用相同的来源页签资源，切换来源保留当前人格草稿；选择参考人格只复制提示词到当前草稿，保存仍由用户显式提交。

模型能力按模型、上下文窗口、最大输出及来源分别呈现，未确认能力的提示保留原意。调度状态、并行任务上限和最近运行范围分别呈现；后两项使用包含数值参数的完整资源模板，不依赖拼接半句及分隔符。通用设置的语言控件保留一个可访问名称，避免相邻重复标题。

上下文统计的团队总量与所选对话总量分别保留；缓存、token 构成和运行计数放在可展开明细中。未报告用量按实际统计范围提示，数量为零时不重复显示告警；计量异常提示保留在首屏。上下文预设按当前模型窗口及手工上限计算预算，容量未知时使用固定回退值；卡片上的比例、预算及容量说明均使用显式资源与当前语言数值格式。

通用设置不常驻显示当前语言及系统地区，保存中和失败时仍显示对应反馈。

用户消息与轮次记录使用同一本地日期（含年、月、日）及时分秒格式，提示和无障碍名称包含完整本地时间及事件含义。轮次记录时间沿用投影提供的时间，不因显示优化重新推断实际结束时间。侧栏的显示方式与分组标题按项目匹配语义命名；“未匹配项目”包括未匹配已登记项目目录及没有工作目录的对话，不表示注册或关联写入失败。

## 运行时资源身份

Python 后端没有原文反向查找代理。产品自有文案由调用方声明键，外部内容即使碰巧与产品原文相同也保持原样。

附件模型提示与用户原文通过后端 `original_text` 分开保存；普通对话、流式回显、历史投影和导航显示原文，不按附件说明的译文截断。引导账本内部保留供模型使用的正文，对外回执的 `text` 使用原文后再按摘要上限截断，原文也参与同一引导请求的身份核对。纯附件消息保留空正文和结构化附件引用。

计划审批选项由生产端提供 `approve`／`keep-planning` 身份与当次运行语言的标签；界面按身份呈现当前语言，答案仍提交该问题原始标签。权限审批使用 `allow-once`／`allow-temporarily`／`deny` 身份，拒绝按钮使用动作词 Deny；外部选项不按原文猜测产品资源。

恢复回执独立保存 `recovery.instruction_text`，浏览器核对原指令、模式、来源版本和核实说明，不解析已装配提示词。携带明确恢复指令的同一请求在语言切换后显式重试，服务端按这些字段与原运行身份复用回执；字段不同返回冲突。

队列正文使用结构化 `prompt_input.text` 与 `attachment_refs`，编辑、版本冲突、保存回查和撤回恢复均传递原文。后端保存编辑时保留附件 parts 并重新装配模型提示，浏览器不再解析附件尾块。草稿中的消息内容保存正文与独立附件引用，另保存编辑来源、执行模式、智能体/团队选择及待确认请求等当前操作状态；不保存附件原始文件，也不接受已退役的隐藏附件上下文字段。无效存储保留原件，不自动迁移，具体持久化范围见 [存储与恢复](storage.md#浏览器本地偏好)。以上入口不需要按译文反向识别，新功能同样须声明资源或协议身份。

工具 `ToolSchema` 的 `description_key`、`description_values`、`description_parts`、`parameter_keys` 保存宿主资源身份；`resolve_description(language)` 复制视图后仅替换声明位置。`SchemaResource` 表达嵌套产品模板参数。元数据不进入模型协议；模型请求和网页工具目录使用相同解析规则，权限指纹仍使用注册原件。工具名、参数名、枚举、默认值、示例及第三方说明不按原文猜测翻译。

人格模板的名称、说明和四轴指令按本次读取语言解析；全局内置选择只保存选择版本及快照，读取时按有效代号重建当前语言，不回写保存文件或改变版本。用户人格的名称、说明与提示词作为用户原文保留；系统标记仅在提供给模型的上下文外层装配。四项推荐必须分别属于对应轴，不接受旧字母代号。`test_personality_selection_language.py` 覆盖全部16个内置选择的英中英往返、文件字节及版本保持。

工具策略回调在注册后仍按实际装配语言解析，write/edit、grep/read 及浏览器能力分支分别取当前资源；资源不改变工具权限。重复调用提醒按同一调用链命中阈值时解析当前语言，工具名和参数原文保留，不通过译文反查资源。摘要策略身份和对话检索引导使用模块保存的资源键，由运行或提示词装配边界解析；资源键本身不是模型正文。`test_policy_resource_identity.py` 核对同一提供者和宿主实例的语言往返。

工具分类由 `CATEGORIES` 保存稳定 ID 与 `label_key`，`tool_catalog` 在读取时解析标签，不把分类加入模型工具 schema。连接器预设的说明、授权提示和配套技能由注册的资源键解析；`get_preset` 返回隔离副本，摘要可按本次语言重新解析。技能文件在显式安装时采用当次语言，已有文件或链接不覆盖，后续语言切换不改写用户技能。自定义预设未声明资源键的字段保持原文。静态模型目录同样只翻译声明的说明，模型 ID、名称和提供方标识保持原样；目录外当前模型使用独立的说明资源。

项目、用户和对话记忆分别使用 `python.memory.context`、`python.memory.user_context`、`python.memory.session_context` 包装，按本次计算语言生成有界上下文。记忆正文以转义后的 JSON 数据插入，原文花括号不再次解释，切换语言不更新记忆记录。预览说明是当前选择快照，不能据此声称模型已经消费。`test_memory_context.py` 覆盖同一三层存储的英中英包装和导出保持。

摘要普通请求以 system 消息发送当前调用语言的策略；Zen 候选在最终端点匹配后改用包含策略、原始记录及 Zen 指令的 user 消息。`test_policy_resource_identity.py` 通过离线传输核对两种真实请求正文的英中英往返，原始记录保持，不访问在线模型。外部主动整理的语言仍由 `Agent._summarize` 绑定已有轮次语言。

资源型错误在读取时解析。成员执行失败后又发生关闭或交付失败时，`run_error_copy` 从根级 `copy` 或异常 `details.copy` 取得原资源身份，按发生顺序保存在错误 `parts` 中；完整记录、归档摘要与历史列表按读取语言解析，外部诊断保留原文。归档读取不重新执行成员任务。提示词提供函数和目标续跑在实际装配时读取资源；用户控制消息和日志保留发生时语言。

浏览器逻辑层可用 `ResourceError` 携带显式 `ResourceCopy` 或 `ResourceTemplate`；其 `Error.message` 是抛出时的诊断快照。页面通过 `failureText` 保存资源身份，再由 `noticeText` 按当前语言呈现。`failureText` 只识别 `ResourceError` 和 `ApiError.failure.copy`，其余异常保持原文。错误子类的控制语义（例如队列结果未知）继续通过类型判断，不根据翻译正文判断。输入草稿和队列草稿的存储失败提示仅在内存中保存资源身份，不进入持久草稿协议。

共享 HTTP 传输通过 `collaborationErrorCopy` 按已注册产品错误码选择资源，将 `copy` 与 `code/status/details` 一起保留；未知码有有效字符串正文时保持正文，没有有效正文时保存通用 HTTP 资源和状态参数。接收端不能只保存 `message` 而丢弃 `copy`，也不能按外部正文反查产品资源。

复合提示使用 `ResourceTemplate` 保存显式外层键和资源型参数，由 `noticeText` 在呈现时递归解析。扩展未知写入和终端停止/输入反馈共用此机制，不能先把网络提示翻译为字符串后固定进 `{reason}` 参数。模板是浏览器内部数据，不扩展 HTTP 错误协议；字符串参数始终保持原文，数字参数保留数值。 嵌套模板可继续组合资源型原因，解析保留原对象；审批记录的工具名、外部决定值和审核原因保持原文。通知的标题、说明和行动按钮也可保存资源，切换语言不重置通知计时。钩子表单的结构拒绝保留 `ResourceText`，由消费者呈现；用户命令、状态文字及匹配器不翻译。

浏览器内部的 `ApiFailure.copy` 可携带平面资源或复合模板；在默认模型保存等调用中包装异常时保留该元数据，`message` 仍是发生时的诊断快照。这不向HTTP正文新增字段，也不重写服务端或第三方原文。模型、显示偏好和推理设置的保存状态及菜单反馈都在呈现时解析资源，切换语言不产生保存操作。

协作消息按 `ui.collaboration.error.<code>` 解析，未知码使用通用协作资源；共享错误投影只保留类型、错误码和当前语言消息，私有正文及 details 不向共享端转发。任务板只对已登记的 `board/` 错误选择对应资源，其余诊断作为通用模板参数保留。普通 HTTP 出口的规则不同：仅在正文恰好等于已登记机器码时转换消息，具体诊断和未知正文保持原样；不能把共享投影的隐私过滤规则推及所有 HTTP 错误。

目录读取分别选择不存在、非目录和非法路径资源；设置的整数拒绝分别选择非负、正数及可空正数说明，非法请求在配置更新前拒绝。只读工具拒绝在执行前解析当前语言，恢复只读与任务只读同时生效时使用恢复说明，不调用被拒绝工具。`test_ui_error_messages.py`、`test_collaboration_error_language.py`、`test_project_language.py` 与 `test_readonly_web_tools.py` 核对这些出口及机器身份。

项目的四项已注册工具与模型目录工具保存说明资源身份，同一注册实例分别提供给模型 schema 和 Web 工具目录，在英中英往返时重新解析，注册原件和参数结构保持。模型推理强度说明由当前能力值选择资源，模型 ID 保持原样；目录验证不执行项目写入或访问在线模型。协议说明由 `_SCHEMA_DESCRIPTION_KEYS` 声明位置，每次 OpenAPI 读取先复制 schema 再解析资源；`test_protocol_current_boundaries.py` 覆盖全部声明位置及快照隔离，`test_schema_consumers.py` 覆盖上述真实注册实例的两个消费者。

## 语言的归属

| 状态 | 语言来源 | 切换后的行为 |
|---|---|---|
| 本机浏览器界面 | 有效语言缓存及服务端设置 | 更新订阅组件的资源呈现；异步目录按代次重读 |
| 受邀浏览器界面 | 本地缓存，缺失时按浏览器语言 | 不修改工作主机的模型运行语言或权限 |
| 模型提示词与自有工具说明 | 当前调用的有效运行语言、显式 schema 资源身份 | 在本次装配中解析；用户与第三方正文保持原文 |
| 已启动独立 MCP 服务 | 创建时解析的配置语言 | 界面切换不重新配置，重启服务才采用新语言 |
| workflow 子进程 | 启动时的 HARNESS_WORKFLOW_LANGUAGE | 进程独立读取源资源，不能靠界面切换改写正在执行的脚本 |
| 持久历史与日志 | 事件产生时的文本 | 不追溯改写；可动态显示的产品提示须单独保存资源身份 |

连接器本地空令牌拒绝保存资源键和原始变量名列表，目录重读时按当前语言解析完整文案及列表分隔符。OAuth 自有错误在来源声明资源身份，后台状态读取时递归解析嵌套原因；异常诊断快照保持发生时文本，读取不重新授权。client_id 提示中的环境变量名保持原文，连接词按读取语言解析。授权后的声明变更拒绝同样保存资源身份，既有凭据写入事实不因提示切换而撤销。未声明资源身份的第三方诊断保持原文。

## 动态键的事实来源

动态调用需沿生产端验证，不能将前缀报成缺失键，或将没有完整字面量的资源直接删除。

例如 `t('ui.trace.' + kind)` 在 `kind === 'tool'` 时查询 `ui.trace.tool`，不会查询 `ui.trace.`。同样，`ui.member.status.running`、`ui.desktop.menu.view` 和 `ui.automations.weekday.mon` 都是完整资源身份；前缀本身不需要注册为资源。`Object.hasOwn` 检查拼接后的完整键，不会拒绝正常存在的动态资源。

静态分析应检查完整字符串字面量，并分别处理条件表达式的分支。拼接、模板插值和变量参数若无法解析实际值域，应记录为待分析的动态调用，不能将截取的前缀计入缺失键，也不能仅凭前缀下存在资源就认定全部动态取值安全。确认缺陷必须给出可达的具体后缀、最终完整键及其在对应语言资源中的缺失证据；缺失完整资源仍保持显式失败，不增加前缀占位文案或静默兜底。

| 桌面及网站右键菜单 | `useDesktopMenu` 枚举 `ui.desktop.menu.` 后缀并传递当前界面文本，主进程校验后供应用菜单与网站右键菜单共用；编辑操作复用同一资源，链接与检查元素有显式资源 |

请求与工具日志不能只按正常结束的请求推断状态值域：`AgentRun` 的活动态和终态经成员摘要进入投影，工具事件还会产生 unknown、running、done、error、skipped；同名请求状态与工具状态使用各自现有映射。`trace-resource-chain-smoke.mjs` 将真实请求归档、当前运行状态及工具投影送入实际面板，核对类型、行状态、智能体入口状态和 input/result 页签的英中英呈现。切换语言不重读列表或工具正文。首次展开、切换正文页签或分页，以及重新显示和状态更新时，正文读取仍按当前详情的观察条件执行。工具名、模型名、描述及正文保持原文。该回归使用隔离归档与受控API，不访问在线模型。

下载状态与星期标签的动态键值域可以由上述生产者明确枚举，不需要为前缀本身增加资源。下载文件名、用户任务名和提示词保留原文；改变语言只更新标签及每周摘要，不执行下载控制、保存自动化或重复请求调度预览。`dynamic-resource-families-smoke.mjs` 使用真实下载状态投影、后端校验后的每周计划及实际浏览器组件，覆盖英中英、明暗主题及窄宽窗口；DownloadItem事件使用替身，不等同于原生Electron实机验证。第三方下载状态的事件值域以 [Electron DownloadItem](https://www.electronjs.org/docs/latest/api/download-item) 为依据。

文件读取反馈区分已知总行数和仅加载前缀，显式结束行被截断时分别说明文件末尾或前缀边界；写入反馈区分创建与覆盖。路径、正文和搜索诊断参数只插入一次。独立搜索工作进程不读取语言资源，错误经 JSON 保留资源身份，宿主接收后才解析；通配符直接遍历也使用同一 `SearchError` 身份。`test_file_tool_language.py` 与 `test_dynamic_state_language.py` 覆盖这些分支，包含工作进程通用失败出口。

LSP 符号标签与解释器缺失提示在实际渲染或执行准入时解析，不在导入时固定语言。终端读取失败保留已有输出、运行状态和原始诊断，`terminal_read` 的自有错误说明随调用语言解析；`[lines: ...]`、`[partial line: ...]` 等既有机器输出标记保持原格式。执行器路径校验使用调用方传入的字段资源键，拒绝非法路径不创建目录或修复配置文件。相关回归使用受控进程及平台分支，不能作为 Windows/Linux 原生验收。

未知外部机器码的兜底与缺失自有资源是不同情况。新增产品状态应同步生产端、资源、消费者和业务回归，不通过静默回退隐藏遗漏。

## 独立执行器与线程/进程

执行器配置 `language` 接受 auto、en、zh-CN，创建服务时解析 auto。执行器目录的工具名、参数结构、副作用和方法身份保持稳定；`harness_exec.output_encoding` 的 `description` 在读取时解析 `encoding.parameter`。目录回归单独校验该说明的当前译文，其余机器字段仍完整比较，不将所有 description 字段一律忽略。MCP 回调与 HTTP 授权路由绑定服务语言，结束后恢复调用方上下文。CLI 和托管入口加载配置后绑定运行语言；管理端后台启动线程继承本次调用上下文，并写入子进程配置。运行期间切换界面语言不会重配已启动服务，重启才采用新语言。

workflow Node 是每次运行独立的进程，语言由宿主环境快照传入；资源读取发生在脚本 VM 外。语言传播不赋予脚本文件系统能力，也不改变成员、权限、取消或未知副作用的处理。

## 验证与清理

运行两个生成器的 `--check` 和生产构建，按实际变更选择业务专项。术语专项检查中英文一致性及明确的语境差异；推理强度和截图线宽的“中”均核对为 Medium，不保留旧误译 in 的豁免；动态与原文边界由真实消费者验证，静态无缺失不能代替业务验收。

能力目录的智能体、技能分类及请求详情整组工具定义使用智能体、Skills、Tool definitions。单项对象、问题卡片与集合标题保留符合语境的单复数，拒绝动作与状态分别使用 Deny、Denied。术语回归按具体资源键固定中文与英文对应关系；同中文组不能任意复用已允许的另一译法。分组差异数量只用于发现候选，不作为术语缺陷数量。

删除键前核对完整键、动态后缀、映射表、资源分发、生产入口及消费者。相同哈希后缀可能只是相同原文，不自动代表同一资源；未使用候选、任意样式值与缺陷数量分别记录。只清理有证据的废弃源码和资源，不清理用户数据。保留有效的生产链路与回归测试，不将历史扫描数字写成当前保证。

## 浏览器错误与界面链路

浏览器资源存在性和翻译读取只接受资源表自有键，原型键按缺失资源处理。浏览器模板参数只读取参数对象的自有属性，继承属性不参与插值；无原型对象可正常使用。参数值作为原文一次插入，不递归解析其中形似占位符的内容。`translationArguments.test.ts` 覆盖双语往返、继承值、无原型对象、零值及原文保持。

钩子活动分组和输出截断说明使用完整资源模板，计数作为数值参数；证据读取失败保留资源身份，身份失配不接受证据正文。钩子命令、stdout/stderr及原始诊断保持原文。图片操作的自有HTTP/Canvas/PNG/剪贴板异常通过 `ResourceError` 声明资源，原始浏览器异常保持其类型与正文，取消保存仍按 `AbortError` 处理。

附件准入拒绝返回显式资源身份，批量拒绝通知保留模板与原文件名；附件错误字段使用 `ResourceText`，提示由附件组件在呈现时解析。输入草稿持久化保留已有资源错误或原始诊断；仅上传中、待上传或缺少具体错误的未完成条目使用“上传未完成”资源。刷新不恢复浏览器文件对象，不自动重传。浏览器本地产生的错误及附件准入/请求校验的已登记拒绝可切换语言；附件存储完整性、引用校验及物化失败的四类固定错误共用已登记的错误码资源；其他公共错误仍需按链路核对。

后端附件产品拒绝由来源处声明 `details.copy`，其语义键使用 `ui.attachments.server.*`，与浏览器生成资源同步。领域异常保留 `copy`，API转换保留该身份，不在HTTP层按原文反查。上传客户端校验错误码与资源键及参数的对应关系；错误正文继续作为诊断保留，不能用正文内容决定翻译身份。

固定的附件存储、引用和物化错误共用 `ui.collaboration.error.attachment/*` 资源，HTTP错误和对话错误块按已登记错误码解析。WebSocket未提交错误保留 `ResourceText` 到原待恢复请求；未知来源的非空正文原样保留，空正文使用显式兜底资源。待恢复请求错误可随草稿序列化，不按发生时的语言固定提示。

对话通道中的自动化完成/失败、连接未就绪、发送未成功及运行中目标控制失败通知，在创建时保留资源身份；通知组件在显示时解析当前语言。目标控制异常通过 `failureText` 保留传输错误的copy，语言切换不重新执行发送或目标写入，原输入保持。

Web 搜索设置的密钥标签按资源格式化服务商名称；加载失败、保存失败和保存成功保留资源身份，切换语言不重新提交密钥。目标证据弹窗也保留传输错误资源，语言变化不重新读取证据。智能体选择器的目录读取按对话和语言隔离，选择写入按原对话归属；切换语言不能清除选择失败提示或使进行中的选择失去结果，目录描述仍按新语言重新加载。 智能体与技能选择器共用 `CapabilityPicker`，按能力类型选择各自的完整资源键；搜索、加载、空态及移除标签随语言更新，定义名称、描述和草稿保持原文。扩展目录的共享工具栏独立订阅语言，来源选项、计数与清除操作同步更新，保留当前搜索及来源选择。

轮次完成栏与钩子统计保留资源型错误及复制成功通知；回复分页校验使用 ResourceError，不能把校验错误固定为发生时语言。钩子累计耗时、未启用数量及分页范围使用完整模板，避免拼接词序和缺失空格。

原生浏览器面板的本地地址校验错误保留显式资源，切换语言不重放导航；原生桥接传来的外部错误正文不按原文反向翻译。BrowserPanel以对话ID为key重建原生面板，状态快照与后台错误事件均核对session_id。后台快捷键、离开页面重试、上下文菜单和弹出页创建失败保留发起对话身份；preload转发结构化错误，页面拒绝外来身份、无身份旧字符串及卸载实例的迟到回调，诊断原文不翻译。

原生浏览器的宿主关闭标签和离开页面确认使用两项完整资源，桌面桥通过 `message_copy` 保留资源身份。前端在呈现时解析，Python 弹窗投影在读取时按调用语言解析；切换语言不回应弹窗或重放导航。网页提供的弹窗只保留原始 `message`，即使正文与产品提示相同也不翻译。

原生浏览器的弹窗、标签、导航准入、控制权、查找、布局、初始化、视口测量、网站权限和下载操作等自有错误通过 `NativeBrowserError` 保留错误码与资源键。IPC 返回结构化 `failure`，前端转为 `ResourceError` 保存；后台快捷键失败事件同样保留原对话与资源身份。HTTP 桥保留错误码和 `copy`，Python 验证资源回执格式后按调用语言解析，保留原 HTTP 错误原因；已识别的自有错误不误报为连接断开。格式损坏明确报错，页面变化、初始化失败和初始化等待不再一律转换为同一句初始化提示。`browser/desktop-page` 仍用于现有有界只读状态重查。前端收到的外部异常正文保持原样；其他 HTTP 错误仍沿原连接错误路径报告并保留原因。结果未确认时禁止重复回应。

网站右键菜单使用应用菜单已同步的界面语言资源，不读取操作系统语言选择文案；文本尚未同步时不弹出菜单。切换语言只更新后续菜单文本，不执行菜单动作。恢复已关闭标签页在派发时固定所属对话，加载失败仍只归还原对话的恢复记录，不能写入期间切换到的对话。关闭该对话的浏览器或关闭运行时会作废待恢复代次；迟到失败不重新生成历史，迟到成功也不能把已关闭标签当作创建成功。页面目标和加载的异步结果都重新核对标签归属与存活状态。

加载失败页的显式重新加载只执行一次；非取消异常保留原件并保持失败状态，不吞掉异常后返回健康页面。`ERR_ABORTED` 沿现有取消语义处理，用户下一次显式重新加载仍可恢复原 URL。

网站权限回应只接受布尔值；非法值保留待处理请求，不隐式转换成拒绝。下载保留原文件名与来源，按对话及状态拒绝失效操作。预留文件名或设置保存路径失败时，下载记录保留自有资源或外部诊断；文件清理与主错误同时失败时保留两项诊断，前端在呈现时解析嵌套资源，切换语言不重新下载或取消。

下载预留从创建时的文件句柄记录设备、inode 和创建时间；失败或取消清理前核对路径仍为同一普通文件，遇到替换文件、链接或目录保留当前对象，清理失败显示诊断。该路径身份检查与不遵守锁的外部写入者之间不提供原子比较删除保证。

Xterm内部的输入textarea由终端组件在初始化和语言变化时更新无障碍名称；语言变化只修改属性，不重建终端或触发输入与流观察。异步加载完成后的名称使用当时的实际语言。

前端将仍运行的钩子标为中断时，用本地 HookActivity.reasonCopy 保存原因资源；它不扩展服务端协议。展示时优先解析该资源，服务端及外部原因仍保留字符串原文。语言切换不重新读取证据或执行钩子。

截图按钮将传输失败保留为ApiError，ScreenshotError继承资源型错误；通知标题与说明保存资源身份。切换语言只更新通知文本，不重放截图或重新申请屏幕权限，第三方错误仍保留原文。

严格团队验收的JSON示例在组装请求时解析双语资源，字段名、工具调用ID与机器枚举保持英文；检查名称、观察结果和证据占位说明随请求语言变化，不使用模块级英文示例常量。

上下文审计的快照、主/子智能体请求、供应商输入统计、已载入数量、完成分段、替换/保留节点、裁剪结果、输入估算、来源、角色数量、记录身份和原文分页范围使用完整资源模板；参数、单位和标点由资源控制，不能依赖拼接翻译碎片的空格。模型名、来源路径及原文作为参数保持不变；原文范围按Unicode码点计算，空内容显示零范围。

上下文用量显示父子合计时涵盖子智能体，明细只显示当前所选对话；标题、说明和手动整理按钮随界面语言切换。合计保留精确 token 数，同时附常用单位：千为 K、百万为 M，中文达到一亿后使用“亿”，英文达到十亿后使用 B；单次请求明细仍显示精确数量。

操作审批问题和自动审阅拒绝各使用完整模板；工具名、目录、JSON参数及审阅原始原因作为参数保留，不拼接标签与标点。自动审阅提示词按调用语言装配，审阅失败仍回退人工，翻译调整不改变批准或拒绝的执行边界。

智能体、Skill 与连接器目录的启用／停用开关共用 `ui.catalog.enableNamed`、`ui.catalog.disableNamed` 完整资源模板；对象名称作为参数传入，保持用户原文，不依赖尾空格片段拼接。

检查器与命令面板的固定面板标签由 `web/src/lib/inspectorPanels.ts` 中的显式资源身份统一提供。命令面板的文件搜索结果分类保留独立资源身份，不能因面板标签归并而删除。退役标签须核对注册表、动态构造与其他消费者后再从权威资源移除。

生成状态的网络接收、无进展时长、字符及 token 数量，与请求详情的流耗时、事件/节点计数、检查点来源、缓存前缀和工具/消息数量使用完整参数模板，资源控制词序、单位及标点。字符与 token 数量共用 ui.metrics 资源。无可展示变更的通知保存资源身份，显示期间可随语言更新；切换语言不重放操作。

生成状态中的请求参数调整原因由normalize_request返回显式资源键及参数，使用可分发的ui.generation.adjustment资源；实时状态转发原身份，GenerationDock按当前语言呈现。切换语言不重新规范化或发送模型请求。八类原因的回归直接消费Python规范化输出，覆盖英中英、主题和尺寸；模型请求正文不携带这些展示资源。

缓存比较返回endpoint/model/tools/settings变化标识及原始changed_settings参数名；界面按当前语言渲染完整模板，列表分隔符也在渲染时解析。不返回已翻译的changes正文，不在后端拼接前缀，也不改写归档请求。

MCP服务状态的`error_copy`承载自有错误的资源键与参数，`error`保留服务端诊断；第三方诊断不根据原文反向匹配。Git操作按明确机器错误码选择资源，未知提交与回查失败使用完整模板，保留草稿且不自动重放。相关浏览器回归在英中英切换中验证提示变化且操作次数不增加。
