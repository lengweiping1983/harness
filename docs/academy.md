# Harness Academy

Academy 是独立的本机学习模块。在右侧“启动器”选择“学习中心”，也可从工具详情、模型请求详情进入。学习项目、运行和恢复不使用主对话的日志或工作目录。

内置团队课程提供三条入口，均有中英文讲解、阶段目标、练习、自测反馈与渐进提示。首次进入只显示课程卡片和按需展开入口，不预先显示默认课程课文或要求填写项目名称。在“课程与项目”的课程卡片点击“开始学习”即可创建独立项目；展开“课程目录与项目设置”仍可预览课程、打开已有项目或自定义新项目名称。有学习项目时该设置默认展开，外层管理区继续默认收起；进入管理区即可使用课程目录。已有未保存源码时阻止创建另一课程项目。

团队课程已有同版本项目时，卡片显示“继续学习”和所选项目原名，优先返回当前项目，否则选择该版本中最新创建的项目。继续操作只读取已有项目的当前课次、源码和记录，不创建项目、不切换磁盘课次、不运行代码或请求模型；未保存草稿和输入法组合期间不切换。其他学习项目仍可从设置选择，要另建项目可在项目选择器选择“新建实验项目”后填写名称并显式创建。项目版本与目录版本不同不作为继续候选，已有项目不做自动迁移。

| 课程 | 学习路径 | 起点与执行方式 |
|---|---|---|
| Python：从第一行输出到独立小功能 | 看见值 → 表达选择 → 处理记录 → 组合与验证，共 12 课 | 从变量、计算与文字开始，第 4 课引入函数；代码在本地隔离环境运行 |
| 大模型：从提示到可核验回答 | 任务与证据 → 让边界可见 → 组合与比较，共 9 课 | 第 1 课阅读与自测，第 2、3 课直接运行模型提示；后续使用 Python 做上下文、证据、工具与评测实验 |
| 30 天，从零件到 Harness | 从输入输出逐步组合消息、工具、上下文、状态与最小循环，共 30 课 | 面向少量代码基础的学习者；使用固定回复或小型本地模拟 |

Python 课的阶段迁移任务包括整理问候、处理空列表、拒绝无效时长和生成学习计划摘要。大模型课的迁移任务包括区分指令与材料、同时校验结构与证据、组合可追溯回答助手。部分迁移任务的起始代码可以运行但故意不满足完整合同；学习者修改后再做独立检查。每节代码课的参考实现可在“参考代码”中按需阅读，不自动替换练习源码。

课程内容以 [Python 3.14 官方教程](https://docs.python.org/3.14/tutorial/)及 OpenAI 官方[提示](https://developers.openai.com/api/docs/guides/prompt-engineering)、[工具调用](https://developers.openai.com/api/docs/guides/function-calling)、[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)和[评测](https://developers.openai.com/api/docs/guides/evals)说明核对概念（2026-10-29）。模型课显式调用设置中的模型；提示输入框内可用 Ctrl/⌘+Enter 运行，与按钮共用同一请求入口；快捷运行在原请求回执确认、同一项目本课的该次实验记录重新读取并恢复可编辑后，归还提示输入焦点，文本未变时恢复选区和滚动位置。新的点击、转向其他控件、窗口失焦、切课、隐藏或未知回包会取消归还；手动回查不恢复旧意图，按钮运行也不移动编辑焦点。普通 Enter 换行，Shift、Alt/AltGraph、输入法组合、键码 229、长按及已有运行或待核实写入时不触发快捷运行。Python 模拟课仍为本地实验，不复现训练、分词或语义检索。结构正确、存在引用、一次检查通过分别只有其对应证据范围。AI 作业点评单独请求设置中配置的模型。

默认学习页只突出本课目标、练习代码与学习助手。展开自测或笔记后直接显示题目或输入框，不重复内层标题；完成区直接给出当前下一步和完成含义。学习说明保留可访问名称，阅读课提示用自己的例子解释，模型课提示引用实际回答并说明下一步验证，代码课保留预测、修改和验证提示；切换语言不改写已输入的说明。当前代码课与模型实验课的具体练习要求直接放在代码或提示输入区上方，说明这次需要尝试什么，不要求先展开讲解；讲解内不重复这份任务，预览与阅读课仍在展开的讲解中显示练习。课程目录、前后课浏览、阶段路线和课程说明移入“课程与项目”；代码课的小自测、笔记、详细点评及历史按需展开，阅读课直接展开活动所需的自测与笔记；模型实验课先显示任务、提示输入与模型回答，恢复课程提示、刷新实验记录、快捷键说明及本课系统指令收进默认关闭的“更多操作”；结果的模型标识、语言和原始输入统一在“本次实验使用的输入”展开查看，错误、未知状态与旧输入提示仍直接可见。模型实验课收到本项目本课同一代码指纹的已完成模型结果后再展开自测、笔记及活动完成入口。生成回答不会自动完成活动，仍须自测、解释观察并显式确认。活动区使用一个随当前进度变化的主按钮：未核对正确时显示“核对小自测”，点击展开并聚焦第一项尚未通过的题目；自测通过但没有学习说明时显示“记下我的发现”，点击展开并聚焦笔记；两者齐备后才显示“完成本课学习活动”并提交。前两步只定位，不选答案、不写入完成记录、不调用模型；组合输入期间不触发。已完成时保留完成状态，不要求重新核对。助手默认显示当前问答、提问框与发送入口；回车发送，Shift+Enter 换行，组合输入、长按与 Alt/AltGraph 不发送。提示、代码提案、运行解释、执行授权及刷新放在“更多帮助”，依据、模型信息与工具过程放在“查看依据与操作”。执行授权开启后，即使收起更多帮助，也始终显示权限状态并可关闭。详细点评收起时暂停它的目录观察，已接受模型任务继续执行，展开后再读取当前结果。

代码课的默认学习流程是“先理解 → 预测并运行 → 修改 → 说明并提交 → 阅读反馈”；阅读课使用“观察例子 → 核对自测 → 写出自己的解释 → 完成活动”。运行与检查直接显示；课程与项目管理、阶段路线、参考代码、历史和恢复通过折叠区域按需展开。“课程与项目”中的课程目录允许自由选课，上一课／下一课提供预览入口。

练习代码区将编辑器、保存、运行、检查与最近结果放在一起，运行前不必滚动越过自测和学习说明。在源码编辑器内，Ctrl/⌘+S 仅保存当前草稿，Ctrl/⌘+Enter 保存并运行，Ctrl/⌘+Shift+Enter 保存并检查；普通 Enter 仍换行。无修改时保存快捷键不发起写入。快捷键仅在源码输入框生效，输入法组合、键码 229、长按重复、Alt/AltGraph 与待核实写入期间均不执行。键盘保存或执行在对应回执已确认、同一项目本课的同一文件完成重新读取，且文件版本或运行结果匹配本次操作后，才归还编辑焦点；内容未变化时恢复原光标、选区和滚动位置。新的点击、转向其他控件、窗口失焦、切换文件或隐藏页面会取消归还。未知结果和手动回查不恢复旧焦点意图，按钮保存或运行也不移动编辑焦点。运行入口共用现有版本和项目指纹保护、单请求保存执行及回执核对，不增加独立执行通道。“更多操作”中的“执行范围与限制”展开原沙箱说明，沙箱不可用仍直接提示。

“专注学习”一键展开右侧学习面板，再次点击“退出专注”恢复面板。工作台按自身可用宽度排列：宽度达到 64rem 时实验与带练并排，较窄时按实验、带练、自测与反思顺序纵向排列，不必经过笔记、点评或历史才能找到助手；宽栏中的自测与反思接在实验下方，助手在右侧。键盘与辅助技术阅读顺序始终为实验、带练、自测与反思。字号增大时相应提高并排所需宽度。窄栏中的“问问学习助手”直接定位并聚焦提问框，讲解从“看讲解”展开。讲解正文与练习说明使用所在区域的完整可用宽度，随面板和工作台分栏伸缩，沿用统一的阅读字号、行距与自动换行。代码课和模型实验课的当前项目默认收起长讲解；课程预览与阅读课默认展开。布局变化保留编辑器和带练实例、源码、问题与预测草稿，不发起执行或模型请求。

阶段路线按课程清单中相邻的 `stage_key` 组织，显示阶段目标、课次、当前选择和学习活动完成进度，不固定阶段数。选择路线中的课次只预览；打开本课仍需显式操作，避免替换正在学习的文件。“继续学习”优先返回当前项目正在进行的一课，该课已完成阅读活动或通过代码检查时推荐最早未完成的课；先修课提供可回看的入口，不强制锁课。

本课已有有效完成证据时，结果区域提供“继续学习”按钮，点击一次即可保存当前检查点并打开最早未完成的一课。阅读与模型课需要明确的活动完成记录；代码课还须有同一项目、课号与当前代码指纹的成功检查证据，普通运行成功不能开放此入口。未保存代码或待核实写入期间不能切课。课程版本变化时不显示完成后的继续入口，原项目与草稿保留。没有剩余课次时显示课程活动完成提示，不把活动记录当作能力认证。

继续操作沿用原切课接口和请求回执，不自动请求下一课模型或运行代码。回执需要确认目标课号；回包丢失、刷新或课号错配时保留原请求号，只回查原回执，不重复切课。课程目录中的上一课、下一课和路线选课仍只预览。

学习域可加载团队设计的课程和本机作者制作的主题课程，两者共用课程包合同、实验台与反馈。课程目录以 `origin: provided | personal` 分为“团队课程”和“我的课程”。用户可在“课程与项目”中展开“学习我自己的主题”，输入主题并按需补充已有基础，生成个人课程。该区域默认收起，不读取制课记录；收起后停止观察，重新展开保留主题与基础草稿，并继续核对已接受的请求。课程就绪后点击“开始学习”创建项目，已有项目和未保存草稿仍受原有切换保护。

## 主题制课

主题和基础说明保留原文，草稿与未确认的请求号保存在当前浏览器会话。页面显示规划、编写和复核进度，仅在制课区域可见且有生成中的课程时持续观察。隐藏区域停止观察，已经接受的制课继续；未确认写入只按原请求号回查，不自动再次制课。课程就绪更新课程目录，不自动切换当前学习内容。存储损坏保留原件并显示错误。

`POST /api/v1/academy/designs` 接收 `request_id`、`topic` 和可选 `background`，保存制课意图后立即返回 `design` 回执。宿主配置的模型依次规划阶段与先修关系、编写逐课内容、复核递进和评估；每阶段只请求一次模型且不给工具权限，不新建对话、不执行生成代码。规划和复核各等待最多 60 秒，内容编写最多 120 秒。生成语言在接受时冻结，产出课程包含中英文资源。

`GET /api/v1/academy/designs` 和 `/designs/{design_id}` 只读生成记录。记录保留原主题、基础说明、阶段、模型标识、复核意见和结果；成功阶段优先保存提供方返回的模型标识，未报告时保留请求模型。`generating`、`ready`、`failed` 与 `unknown` 不互相替代。重启或请求超时后不重放模型请求。模型复核通过只代表未提出阻断意见，不证明知识事实正确或代码已经运行。

宿主校验课号、阶段顺序、先修关系、内容对应、题目身份、双语字段和 Python 语法，再按课程合同复核完整包。目录和文件由宿主分配并独占创建，全部内容就绪后才公开 `course.json` 供目录发现；不覆盖同名目录。复核拒绝时不发布课程。发布中途结果不确定时保留记录及已写内容，不自动清理或重发。

当前主题制课规划支持 `python` 与 `study`，不自动生成需要模型调用的实验课；本机课程作者可按课程包合同显式声明 `model` 课型。

## Harness 课程内容

| 天数 | 每天的核心概念 |
|---|---|
| 1–5 | 输入输出、任务目标、模型边界、消息角色、消息历史 |
| 6–10 | 函数工具、工具描述、工具分发、观察结果、最小循环 |
| 11–15 | 步数预算、上下文窗口、上下文预算、摘要、记忆 |
| 16–20 | 运行状态、小计划、人工确认、目录边界、诚实报告错误 |
| 21–25 | 请求回执、检查点恢复、事件轨迹、用量成本、按需加载技能 |
| 26–30 | MCP 消息、任务委派、回归检查、比较评测、组合最小 Harness |

时间是学习顺序提示；每课可以重复学习。课程的目标是理解并实践核心机制，离线的教学例子不能代替生产系统的权限、存储、传输和恢复保证。

## 学习操作

选择课程后创建或打开学习项目。切换到另一课并执行前，需要显式打开本课；该操作先保存当前文件检查点，再加载目标课的起始文件。先修课只是提示，不强制锁课。

练习代码区支持文件选择、编辑和新建 UTF-8 辅助文件。代码保留真实行结构，长行在输入框内横向滚动，行号跟随纵向滚动并使用相同字号与行高；行号仅供视觉定位，不进入复制、源码或屏幕阅读器内容。编辑仍使用原生输入框，Tab 可移出编辑区，撤销与输入法不增加自定义处理。未保存草稿阻止切换项目和文件；草稿按项目和文件保存在当前浏览器，隐藏面板及刷新后可继续编辑。保存使用文件版本及完整项目指纹，冲突不会覆盖磁盘内容。

普通保存和新建辅助文件同样冻结提交路径、正文及原版本；回执中的路径或正文不匹配时保留原请求号，只回查原回执。确认保存后重新核对本键原字节，仅删除仍与本次提交正文及版本完全一致的浏览器草稿；确认时已与提交不同的草稿保留原字节。新草稿若仍基于旧磁盘版本，再次保存会返回版本冲突，不自动重置版本或覆盖已保存内容。

“运行代码”和“检查练习”会在需要时自动保存当前文件，再执行本课入口或固定检查。两步共用一个持久请求号；保存前同时核对原文件版本、项目指纹、课程与当前课次，运行证据记录保存后的实际输入指纹。冲突时不执行；保存后无法确认执行状态或回执丢失时保留原请求号和浏览器草稿，只回查原回执，不重放保存或运行。代码报错但执行已明确结束时，正常展示失败输出并确认保存。确认回执必须匹配原课次、运行类型和保存正文；收尾只删除仍与本次提交相同的草稿，另一窗口后来写入的新草稿继续保留。“更多操作”中的“保存修改”仍可只保存。

可以展开“记下我的发现”写一句预测，再运行代码。“运行代码”执行课程声明的入口，“检查练习”执行课程包中的固定检查文件，不采用学生自行编辑的检查副本。通过状态来自检查退出码及检查文件中的业务断言；这不是防作弊考试系统。运行历史保留项目、课号、请求号、输入指纹和输出。当前结果只取本项目、本课的运行；编辑草稿或保存后指纹改变时，旧运行显示为此前结果，不代表当前代码已通过。检查期间输入变化时，历史运行仍保留，但不能作为当前代码通过证据。

模型实验与学习助手的失败、中断、超时或结果未确认说明，放在返回的正文与代码提案之前；长回复不会把结果边界压到末尾。已返回的原文与提案继续保留，状态说明不替代它们，也不把未完成内容标为完成。

## 原生智能体带练

带练进行时用一行状态说明当前动作，只根据读取到的 `running` 工具记录显示读取代码、运行代码、检查练习或准备小改动；工具结束后回到一般等待状态，不把一次工具结束显示成整次回答完成。记录中有 `unknown` 动作时直接提示结果未知，不随工具详情折叠隐藏，也不显示继续执行的转圈动画。状态更新保留提问草稿和输入焦点，不额外发起模型或执行请求。

核心循环的当前请求正文增量通过现有记录观察逐步显示，并标为“回答生成中”，不公开思考内容，也不作为完成答案或执行证据。`partial_response` 是只读临时投影，每次带练最多暂存 16000 个字符，不逐字写盘；开始下一次模型请求、转入工具调用或完成收尾时清除。最终正文仍由完整循环结果写入 `response`。关闭页面只停止读取，已接受带练继续；取消、失败或进程重启不会恢复这份内存草稿，也不会因此重放模型或工具。生成期间切换语言只更新界面标签，正文保持提供方原文。

当前带练运行时，发送位置改为“停止”。点击后通过 `POST /api/v1/academy/projects/{project_id}/tutor-turns/{turn_id}/stop` 提交独立 `request_id`，只取消目标项目的所属调度；带练原请求号不变。停止受理与实际收尾分开，`stopping` 只读投影表示正在等待已受理操作结束，期间不再显示生成草稿，也不允许重复点击停止。已接受的运行可能继续完成并保留证据，停止不撤销文件或已完成副作用。停止回包未知、课次或带练身份错配时保留原停止请求号，只回查回执；刷新不会重发停止、模型请求或运行。源码和提问草稿均保留，停止不触发保存。最终中断沿用 `unknown` 与 `tutor-interrupted`，不是成功完成。

打开学习项目后，学习工作台提供“学习助手”。默认直接提问；展开“更多帮助”可选择“给个提示”，或在代码课选择“运行并解释”。助手自动取得本课内容、文件名和近期证据，不需要手动复制代码或主对话上下文。上下文从最近 40 条运行中取当前项目本课最多两条，从最近 20 次项目带练中取本课最多四次已完成问答；不代表完整历史。模型实验课还会在提问受理时冻结当前项目、本课最近完成的模型实验，包含原提示、系统指令、回答、模型、语言和输入指纹；按持久记录顺序选择，不依据时间戳，也不采用失败、未结束或其他课次的记录。之后编辑提示或产生新结果不会改写已接受问答的快照，旧指纹不冒充当前文件。上下文仍受 96 KiB 总大小限制，超限明确拒绝，不截断证据。回答旁的“帮我理解这个结果”以 `model_run_id` 明确绑定当前选中的已完成模型实验，直接发送一次分析请求并保留原问题草稿。服务端直接有界读取该记录，核对项目、本课、模型课模式与完成状态，冻结原提示和回答；不依赖近期窗口。该入口不提供执行工具、不保存源码、不重跑实验；不能与代码运行证据或提案范围混合。请求、回执及冻结快照核对相同实验 ID，切换历史选择不改变已接受分析；依据中可查看该 ID。普通自由提问仍自动采用最近完成的实验。自由提问默认不允许执行，勾选“允许运行本课代码”才提供执行工具；“给个提示”始终不提供执行工具。

自测核对后仍答错时，当前项目的反馈区提供“和助手一起想一想”，课程预览不显示此入口。点击后通过 `knowledge_check` 携带题目与选项 ID，服务端从当前项目本课解析并冻结题目、所选选项及其反馈，不采用页面拼接的题干，不自动选择、核对或提交答案。上下文不添加正确答案 ID 或完整选项列表；助手按提示尝试给一个小提示或例子，再用一个聚焦问题帮助重试，这不是已验证的教学效果保证。该范围只读，不与运行证据、模型结果选择、提案或执行授权混用；未保存代码草稿不随此操作写入。原问题草稿保留，输入法组合和重复点击不重复提交，接受回执按题目和选项共同匹配；回包未知或错配时只回查原请求。之后换选项、切换界面语言不改写已接受问答的冻结内容，静态自测结果与课程进度仍由原核对和完成流程决定。

普通追问会为最近一条已完成问答保留当时讨论的冻结材料：所选运行及其对照、模型实验或自测选择。历史材料从所属问答的私有快照取得，不用现在的实验记录替换当时内容，也不重放工具；当前实验仍按原读取规则提供。历史仍最多四条，只有最近一条携带一层材料，连续追问复制这一层，不递归嵌套整个历史。新显式选择开始讨论新的材料；与当前输入中完全相同的实验或运行只发送一次。历史材料不代表当前文件、检查通过或新的执行授权。总快照仍受 96 KiB 限制，超限明确拒绝，不静默丢弃证据；损坏或跨项目、本课身份不符的历史材料明确报错。

有更早的同课、同类运行时，结果区域提供“对照之前的运行”。默认与上一条同类记录比较，可选择最近十条较早记录；普通运行和本课检查不混为一组，其他项目与课号不进入候选。页面分别显示 stdout、stderr、结束状态、退出码及可展开的运行 ID 与项目文件指纹，按完整字符串核对已捕获输出是否相同。项目文件指纹相同不代表其他输入相同，项目文件变化也不能单独证明结果变化的原因；任一记录截断时明确只比较已捕获部分。打开与选择对照不发起执行或模型请求。

对照区域的“和智能体一起分析变化”将当前运行作为 `evidence_run_id`，所选较早记录作为 `comparison_run_id`，沿同一原生带练入口提交。服务端直接有界读取两条记录，核对项目、课号、运行类型与持久先后顺序，再冻结证据；不依赖时间戳或全局近期窗口。请求与回执同时绑定两个 ID，用户之后改选对照项不改变已接受的问题。此交互不提供执行或提案工具、不保存源码；未保存修改期间先保存再使用。助手取得真实输出、退出状态、截断信息与各自输入指纹，同时区分当前源码与运行时的历史版本，页面标明两条证据 ID。模型的原因解释仍属于待验证假设，不能替代下一步实验。

失败的 Python 输出若含可识别的标准文件帧与异常尾行，页面先显示异常原文与项目内源码位置，运行前已产生的标准输出仍直接可见。完整 stdout/stderr 可在“完整输出与错误堆栈”展开，未识别的诊断直接按原文显示。源码定位只接受当前项目文件清单内的帧，结果指纹须与当前代码一致且无未保存修改；点击后打开对应实验文件并选中错误行。切换项目、课号、文件、隐藏页面或用户转向其他控件会取消未完成的定位，不能抢占另一个编辑器。该投影不会修改或重跑代码，路径与第三方错误不翻译。

运行结果区域提供“帮我理解这个结果”。点击后只请求模型分析该次记录，按 `evidence_run_id` 直接有界读取并冻结选中运行，不会被其他项目的新运行挤出近期窗口；记录必须属于当前项目和本课。界面显示所讨论的运行 ID，模型同时取得原运行指纹和当前文件指纹，旧结果不冒充当前代码的执行。该入口不提供执行工具、不重跑、不修改文件；未保存代码期间先保存后使用。原问题草稿保留，输入法组合期间不触发请求。请求号、回执和选中运行 ID 一起核对，断线只回查原请求。

“运行并解释”同时声明必须运行：核心循环会提示模型取得真实 `run_example` 证据，最多仍受本次步数约束。只有模型声称已运行、工具不可用或没有取得持久运行 ID 时，带练不会作为完成记录，页面说明运行尚未确认。正常提问允许助手根据已有材料直接答复。模型是否正确解释代码与能否促进独立学习，仍需要在线模型及真实学习者验收。

“建议一处小改动”针对当前实验文件请求一份可审阅的代码提案；已有未保存修改时，在同一个持久请求中先保存。请求以 `proposal_path` 显式开放该文件的 `propose_edit`，不同时开放执行工具。原文必须在冻结文件中恰好出现一次，原文与替换各不超过 4000 字符、20 行，文件及候选正文各不超过 64 KiB；每次带练最多生成一份完成提案。失败的无副作用提案可在本次工具预算内纠正，完成后重复调用返回同一份提案。展示差异从精确的前后正文生成，读取记录时重新核对差异与原文版本。仅有模型声称准备好修改而没有有效提案时，交互显示未完成。

页面先显示差异及学习问题。点击“放进实验台试试”只建立可编辑源码草稿，不写项目文件、不运行；用户可继续修改，再使用现有保存、运行或检查入口。操作核对项目、课号、完成状态、整项目指纹和目标文件版本，有任何已有草稿时保留原稿并拒绝覆盖。之后的保存仍沿用文件版本、项目指纹和持久回执规则。模型是否能给出合适的小改动及有效学习问题，尚需在线模型与学习者验证。

带练复用 `harness.core.agent.AgentLoop` 与现有模型适配器，没有另一套模型工具循环。它使用独立内存会话，持久事实属于 Academy 项目，不出现在主对话列表和日志。工具注册表只包含 `inspect_file`、本次显式选中文件的 `propose_edit`，以及被本次明确允许的 `run_example`、`check_lesson`；不继承主对话工具、插件、Shell、文件编辑或网络权限。阅读与模型课没有 Python 执行工具。

`inspect_file` 读取接受时冻结的项目文件；执行工具只调用本课登记的沙箱入口或固定检查，执行前重新核对课程、项目、课号和代码指纹。期间代码或当前课变化时拒绝执行，不能把新版本代码当作原请求的输入。每次带练中的每种执行工具最多实际执行一次，重复调用返回原证据。任何执行结果未知后，停止新的执行，不按模型请求重放。成功的示例运行不更改本课检查进度；实际固定检查通过仍沿原有进度语义记录。

存在未保存代码时，提问操作会在同一个持久请求中先保存当前文件，再冻结带练输入。保存沿用文件版本和项目指纹保护；确认回执核对问题原文、执行开关、课号及保存正文。断线、隐藏和刷新不会重发带练，只回查原请求号。收尾仅删除仍与提交一致的代码草稿，后来替换的草稿保留。问题草稿按项目和课号保存在当前浏览器会话；语言切换只更新控件，已有问题和回复保留原文。

页面显示本课最近回复，“此前对话”展开较早的问答，“智能体做了什么”展开真实工具活动及输出。目录读取按项目限定最近 20 条记录，单条先有界读取再解析；超限、重复字段或损坏记录保留原件并明确失败。模型请求与操作意图持久化后由宿主调度；重启后的未结束记录显示未确认，不恢复模型循环。隐藏面板取消观察，已接受带练及其进程收尾继续完成；连续取消不会遗落已接受的沙箱运行。

## 模型实验

模型课提供可编辑的课程提示，点击“运行提示”使用已配置模型发送一次请求，可能产生提供方费用。每次只发送接受时冻结的本课系统指令与用户提示，不携带主对话、文件、其他实验历史或工具权限，也不执行回答中的代码。“本课系统指令”可展开核对。一次请求最多等待 60 秒，输出预算为 4000 token，完整文本最多 64 KiB；空回答、超限回答或工具调用不作为可用结果。

模型明确报告达到输出上限时，保留已返回的文本并标明回答未完成，不作为 `completed` 实验或活动完成证据；不自动追加请求续写。阶段路线中模型课与阅读课均显示活动完成，只有 Python 固定检查通过才显示代码检查通过。接口自有错误按机器码保留语言资源身份，切换语言只重新呈现错误，不重放模型请求。

提示词草稿按项目、课次保存在当前浏览器页签，刷新可恢复。未编辑的课程提示随课程语言更新；已编辑提示和已有回答保持原文。“恢复课程提示”只重置输入，不发请求。模型实验保留每次实际系统指令、用户提示、完整回答、语言及模型标识，可通过实验历史逐次比较；收到可用回答后优先保存提供方返回的模型标识，未报告时保留请求模型。历史输入展开后显示当次冻结的系统指令，不能用当前课程译文代替。刷新实验结果只读取，不重发提示。隐藏学习面板停止观察，已受理请求继续，恢复显示后读取原状态。

当前选中的已完成实验有更早的同项目、本课完成记录时，提供默认收起的“对照之前的实验”。展开后并排显示两次原始提示和回答，可从最近十条较早完成记录中改选；顺序依据持久记录，不依据时间戳。页面分别说明回答是否完全相同，以及已记录的提示、系统指令、模型和语言是否相同；未记录的生成条件仍可能不同，不能据此证明因果。展开、改选和阅读不发起模型调用。

“和智能体一起分析变化”以 `model_run_id` 和 `comparison_model_run_id` 绑定当前与较早实验，沿原生学习助手入口请求一次分析，可能产生提供方费用。服务端直接有界读取两条已完成记录，核对项目、本课与持久先后顺序，冻结两次输入和回答；不重跑实验、不提供执行或提案工具。待确认请求及回执同时核对两个 ID，之后改选不改变已接受的分析。普通追问继续保留这对冻结材料，快照仍受 96 KiB 总大小限制；助手的原因解释属于待验证假设。

草稿写入或重置失败时，当前窗口保留最新输入或删除意图，隐藏重开实验台不能用旧存储覆盖。读取故障时使用窗口内最后确认的草稿。存储恢复后可显式“重试保存草稿”，只重试本地持久化，不调用模型；损坏原件保留并阻止覆盖。窗口内回退不能保证未保存内容在整页刷新或关闭后恢复。

请求号与意图在调用前持久化，重复请求号必须匹配原项目和输入，不重复调用模型。同一学习服务内，同一项目同时只接受一个运行中的实验，服务最多同时接受两个。接受回执表示实验已登记，`running`、`completed`、`failed` 与 `unknown` 分别呈现；超时或服务中断使用未确认状态，不自动请求第二次。供应商错误不向浏览器泄漏原始请求或凭据。请求与终态证据的存储失败保持未知，不能以刷新或重启重放。

宿主关闭或调度器拒绝任务时，撤销未交付的内存运行登记，保留原持久意图并投影为未确认，不留下“生成中”的假状态。领域错误 `academy/outcome-unknown` 即使使用 HTTP 409，浏览器也保留原请求号，只回查原回执。

收到回答不会自动完成本课。完成活动需要本课、同一项目指纹下至少一次 `completed` 实验、全部正确自测与非空反思；活动证据关联实际实验身份。它不创建代码检查或能力认证。提交 AI 点评时，快照纳入同一项目、本课、同一指纹下最近一次完成实验的系统指令、用户提示、回答、模型和语言。各项保留为独立原文来源，回答中的引号、换行和代码片段可按原文校验引用；后续实验不改写已提交证据。

## 课内自测与提示

课程作者可在关键概念后安排选择题自测。内置课程在第一课和每个阶段的末课提供自测：先选择再核对，反馈解释所选答案对应的概念或误解，提示逐级展开；学习者可修改答案再练习。核对答案本身不运行代码、不请求模型、不改变后端进度，不把答对一道题当作整课掌握。答案与已展开提示仅保留在当前打开的课内，语言切换保持选择并更新课程文案；切换课次、项目或重新加载后重新作答。

阅读课显示练习要求和学习说明，不显示代码编辑器或运行按钮。填写反思并核对全部自测后，可显式“完成本课学习活动”；服务重新验证答案及项目指纹，记录 `completed`。代码课的固定检查通过记录为 `passed`，两种证据分别显示。阅读课也可主动提交说明获取五维反馈；点评不代替完成操作。

交互取舍参考公开教学方式：Brilliant 的[逐步反馈与针对性练习](https://brilliant.org/help/schools-and-educators/differentiation-guide/)、Khan Academy 的[技能与课程掌握路径](https://support.khanacademy.org/hc/en-us/articles/360007253831-What-is-self-paced-Mastery)、CMU OLI 的[目标驱动、带提示的练习与自评](https://oli.cmu.edu/courses/introduction-to-psychology/)（核对日期：2026-10-29）。本模块采用短练习、错因反馈、渐进提示及阶段路线；这些产品的组织方式不能直接证明本课程的学习效果，不采用竞品宣传中的效果倍数或市场排名作为验收。

恢复先显示逐文件差异，用户确认后先保存当前内容，再替换目标检查点中的文件；过程中失败可能保留部分写入及备份，不能声称事务回滚完成。检查点不包含虚拟环境和临时目录。恢复后撤销对应课的通过标记，需要重新检查。

## 提交与五维反馈

“提交并获取点评”冻结当前课所有已保存的文本文件、学习说明、课程目标及量规，并选取同一代码指纹的最近运行证据。未保存草稿先保存；语法错误、未完成代码和伪代码均可提交。提交不执行学生代码，不修改课程检查的通过状态。单次代码、说明及运行证据的 JSON 大小上限为 48 KiB，学习说明上限为 4000 字符；超限明确报错，不静默截断代码。

快照发送给宿主设置中配置的 AI 模型，不新建对话，也不给模型工具权限。提交立即返回回执，后台模型请求最多等待 60 秒；页面显示点评状态，只在学习面板可见且存在进行中的点评时继续观察。关闭面板取消观察，已接受的点评继续。每次提交保存生成语言和请求模型；点评完成后优先保存提供方返回的模型标识，未报告时保留请求模型。页面切换语言不会翻译或重写既有反馈。

评价使用五维雷达图，同时显示每维准确分数、引用、原因及下一步。通用量规在提交前公开，本课还可通过课程包声明自己的评分关注点。

| 维度 | 观察内容 |
|---|---|
| 概念理解 | 能否用代码或自己的话说明本课概念 |
| 任务实现 | 代码或伪代码是否表达练习目标 |
| 逻辑推理 | 能否解释输入、步骤与输出的关系 |
| 验证意识 | 是否有与本课对应的预测、核对或检查 |
| 表达反思 | 是否说明修改原因、疑问或改进方向 |

每项 0–5 星：0 表示有证据与概念矛盾，1 开始尝试，2 理解局部，3 达成本课目标，4 能独立迁移，5 能解释取舍。证据不足使用 null，界面显示“未观察到”，雷达图不将其绘制成零分，也不计算总分。不会要求尚未教授的复杂机制；运行成功不能替代所有维度的理解证据。这套量规是产品的形成性反馈设计，不是标准化能力认证。

模型必须返回完整五维结果；非空分数必须附上快照中的实际引文。服务验证字段、分值、维度唯一性、引用来源和原文子串，不符合要求时保留提交并显示点评失败，不展示未经核实的分数。引用存在只能证明材料来源，不能保证模型的语义判断完全正确，学生仍可结合代码和运行事实核对建议。

每次点评只归属自己的项目、课号和代码指纹，之后编辑代码不改变历史点评。模型失败、超时或服务中断不自动重新请求；重启后没有确认结束的点评显示“结果未确认”。回查提交和回执都是读取，不重新扣费调用模型。学生主动再次提交才会形成新快照。提交快照和点评保存在独立 Academy 存储中。

## 课程包合同

框架按数据读取课程，不固定课程数量、课数、课号或入口文件名。内置课程位于包内 harness/academy/content/；本机作者可将课程目录放入 <Harness home>/academy/courses/。目录在读取时发现，无需修改 Python、React 或全局语言资源，也不需要重建 Web。不同来源使用相同课程 ID 时明确报错，不隐式覆盖。

课程包是本机用户明确安装的可信代码；框架不自动下载、安装、更新或执行远端课程。目录组织示例：

    <course-id>/
      course.json
      locales/en.json
      locales/zh-CN.json
      lessons/<lesson-id>/starter/
      lessons/<lesson-id>/check.py

起始目录和检查文件路径由清单指定。schema 当前为整数 1。课程 ID、课号使用字母数字、下划线和连字符，最长 64 字符。order 是从 1 开始的连续阅读顺序，不要求固定日期或课号。清单示例：

    {
      "schema": 1,
      "id": "my-course",
      "version": "1.0.0",
      "source_revision": "the-source-revision",
      "title_key": "course.title",
      "description_key": "course.description",
      "references": ["https://example.org/guide"],
      "lessons": [{
        "id": "first_loop",
        "order": 1,
        "milestone": true,
        "title_key": "loop.title",
        "goal_key": "loop.goal",
        "reading_key": "loop.reading",
        "starter": "lessons/first_loop/starter",
        "check": "lessons/first_loop/check.py",
        "run_command": ["python", "exercise.py"],
        "source_manifest": [{"path": "exercise.py", "symbol": "run"}],
        "references": [{"path": "reference/runtime.py", "symbol": "Runner"}],
        "prerequisites": []
      }]
    }

双语 JSON 以显式资源键保存标题、目标和 Markdown 正文，两种语言必须拥有相同键。课程资源在实际读取时按当前语言解析，用户代码和第三方诊断保持原文。新增课程不要求修改全局 harness/i18n。可选 stage_key、exercise_key、rubric_key 分别声明阶段、练习要求和评分关注点的本地化资源键，duration_minutes 声明 1–180 分钟的参考时长；这些字段均为通用内容元数据。可选 trace_labels 将模拟事件名映射为课程包内的资源键，事件讲解同样由课程作者维护；省略时保留事件原名。

课型 `mode` 省略时为 `python`，保留上述代码入口及独立检查要求；`study` 用于阅读、自测和反思，必须声明自测，不接受 `starter`、`check`、`run_command` 或 `source_manifest`。公开课次响应始终提供 `mode`，阅读课的运行命令和源码清单为空数组。可选 `assumptions_key` 提供课程起点假设，`stage_goal_key` 提供本课所属阶段的出口能力。

模型实验运行时，“运行提示”原位变为“停止”，只停止当前项目正在运行的模型实验。`POST /api/v1/academy/projects/{project_id}/model-runs/{run_id}/stop` 使用独立请求号；原实验请求号不变。停止受理后以 `stopping` 投影显示正在收尾，隐藏临时正文并禁用重复停止；已认领任务保持项目占用，直到提供方等待与持久收尾结束，认领线程尚未返回时也先收回所属结果再释放。最终沿用 `unknown` 与 `model-interrupted`，不冒充完成回答；停止不撤销已经发生的提供方调用。错配或丢失停止回包保留原请求号，只回查原回执，不重发停止或模型调用；提示草稿、历史结果与文件保持原样。

模型实验运行时通过同一记录读取接口投影 `partial_response`，只显示正文增量并标为“回答生成中”；状态仍是 `running`，不能解释为完整回答或活动完成依据。临时正文按所属调用在内存中最多保留 16000 个字符，不逐字写入数据库、不显示思考内容；最终 `response` 仍取适配器完整返回值，失败、取消、收尾和重启不恢复这份草稿，也不会重放模型请求。临时正文不进入带练或作业点评的完成证据。

`model` 用于显式模型实验，与阅读课一样必须提供自测且不接受代码入口字段；还须声明 `model_prompt_key` 与 `model_system_key`，分别引用本包双语资源中的初始提示与系统指令。两项均为非空、最多 8000 字符的文本，其他课型不接受这两个字段。公开课次提供 `model_prompt` 与 `model_system`；运行命令和源码清单为空数组。`POST /api/v1/academy/projects/{project_id}/model-runs` 接收请求号、课号、项目指纹与非空提示（最多 8000 字符），`GET` 同一路径读取当前项目的实验历史。

阅读课与模型课通过 `POST /api/v1/academy/projects/{project_id}/complete` 提交原请求号、课号、项目指纹、非空反思和完整自测答案；服务核对每题身份及正确选项，模型课另核对已完成实验后记录 `completed`，保留本次学习证据。它不执行代码、不生成 `passed` 代码检查状态，也不构成掌握认证；代码课仍通过运行检查取得 `passed`。

每课可选 `knowledge_checks` 声明 1–8 项形成性自测。每项包含唯一 `id`、`prompt_key`、`options`、`answer_id` 和 `hint_keys`。`options` 有 2–6 个选项，每项包含本题内唯一 `id`、`label_key`、`feedback_key`；`answer_id` 必须指向其中一个选项。`hint_keys` 按揭示顺序声明 0–3 项提示。题目及选项 ID 使用课程课号相同的字符规则，所有文案键须在双语资源中存在且非空；身份错配、重复选项或缺失资源会拒绝课程包。答案随课程数据下发，适用于公开练习，不是保密考试。

    "knowledge_checks": [{
      "id": "predict-output",
      "prompt_key": "loop.question",
      "options": [
        {"id": "observe", "label_key": "loop.observe", "feedback_key": "loop.observe.feedback"},
        {"id": "guess", "label_key": "loop.guess", "feedback_key": "loop.guess.feedback"}
      ],
      "answer_id": "observe",
      "hint_keys": ["loop.hint.direction", "loop.hint.step"]
    }]

起始目录只包含学生可以修改的文件；固定检查文件位于该目录之外，通过项目的 Python 环境执行。当前运行器支持 Python 文件及参数数组，不提供 Shell、任意解释器或在线依赖安装。检查脚本应包含正确结果、拒绝输入和停止条件等业务断言。课程可以使用多个源码文件或不同 Python 入口，不需要改框架。新语言或新的系统执行能力属于运行器扩展，不能仅靠课程正文开启。

references 中的 harness/ 路径读取当前安装包的生产源码；其他路径读取课程包内只读参考文件。source_revision 是作者声明的参考版本，不证明当前安装版本逐字一致。引用路径必须在本课清单中声明。

项目创建时绑定课程版本及整个课程包内容指纹。更改讲解、源码或检查后，已有项目保留学生代码和检查点，但拒绝使用变更后的课程继续执行；用户可创建新版项目。界面发现课程版本号变化时提供新建项目入口，旧项目仍保留。没有隐式迁移和覆盖旧练习的更新机制。

## 执行边界

每个项目使用独立目录和无 pip 的虚拟环境。虚拟环境本身不构成安全沙箱：

- macOS 使用系统 sandbox-exec，限制可读目录、仅允许写课程项目，拒绝网络与派生子进程。
- Linux 需要已安装的 bubblewrap，使用文件、网络及进程命名空间；未进行 Linux 实机验收。
- Windows 当前拒绝课程执行，仍可阅读和编辑；没有降级到不隔离宿主执行的选项。

每次执行最长 15 秒，CPU 最长 10 秒，单个写出文件最多 8 MiB，标准输出和错误各保留前 32768 字节并持续排空。Linux 使用 512 MiB 地址空间上限；macOS 通过系统 `libproc.proc_pid_rusage` 每 50 毫秒采样驻留内存，按 KiB 核对 512 MiB 阈值，不启动 `ps`；采样间隔内可能短暂超出，不宣称硬内存配额。原生观察被拒时保留错误并先完成所属进程及输出读取器收尾，不能将失败读数视为零内存。运行环境只传递必要变量，不继承宿主凭据。退出后回收进程和输出读取；清理未确认时返回明确错误。

可编辑项目最多 128 个文件、总计 4 MiB，单个文本文件最多 256 KiB，目录深度最多 16。拒绝符号链接、目录穿越及 .venv、.tmp、.git 等保留目录。文件指纹检查不构成跨进程文件系统事务；外部程序同时改动课程目录不属于受支持编辑流程。

## 回执与数据

课程监督器在子进程创建后接管启动登记、输出线程及收尾。登记回调或任一输出线程准备失败也先回收所属进程、等待已启动读取器并关闭未接管的管道，再传播原异常。stdout／stderr 读取失败不能变成空输出成功；同一管道读取与关闭连续失败时，两项原异常分别汇入异常组，不仅依赖关闭错误的异常上下文。单异常保持原对象，多项主错误、读取及清理错误分别保留。信号、等待和各读取器收尾逐项尝试，等待及读取器 join 有界；资源未确认释放时不得返回业务成功。执行已受理后的读取或清理异常仍保留 unknown 回执，不写入成功运行或进度，重开及同请求再次调用均不得重放。`tests/test_academy_runtime_lifecycle.py` 以隔离真实进程覆盖失败边界，另经实际课程沙箱核对原文、截断和超时；`test_output_reader_failure_preserves_unknown_receipt_and_never_replays` 核对持久未知回执、原异常与进度原件。受控进程回归不冒充系统沙箱权限验收。

所有写操作带 request_id。执行意图在副作用之前保存，相同请求号只认可同一操作、作用域和输入；已完成回执可重读。未完成意图保持 unknown，重启、超时或断线不会重放操作。浏览器按页签在 sessionStorage 保存请求号（刷新保留，不与其他窗口争用），响应丢失时只回查 /api/v1/academy/receipts/{request_id}。

数据保存在 <Harness home>/academy/ 的独立 SQLite 与项目目录中。数据库包含课程项目、进度、代码检查点、运行证据、提交快照、AI 点评和操作回执。内容损坏保留原件并报错，不自动修复、迁移或清理。浏览器保存的选择、草稿和待确认请求号不是后端业务事实。

接口只向本机完整宿主开放，受邀对话和远程地址没有 Academy 文件或执行权限。`run` 与 `check` 请求可选 `source` 对象，包含当前已有文件的 `path`、`content` 与 `expected_version`；未提供时只执行已保存代码，提供时先保存再执行，不用于新建文件。公开字段与输入限制见生成的 [OpenAPI](openapi-v1.json)。
