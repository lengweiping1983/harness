# 课程设计协作

“课程设计协作”用于把一个主题讨论成可执行、可评估、能在 Harness 内学习的课程蓝图。它默认检查“入门 → 进阶 → 精进”三级路径，但会依据学习者基础、目标能力和内容依赖合并、拆分或增加桥接阶段。

团队不直接创建课程包，也不执行课程代码。它会规划学习目标、逐课内容、呈现方式、练习、评估、市场基准和 Harness 环境边界，并给出首课的完整可学样例；实际课程建设仍按 [Harness Academy 课程包合同](../../../docs/academy.md#课程包合同)另行进行。

支持团队预先设计课程和用户自选主题两类规划。只给主题时，先交付带有明确起点假设的最短学习路径，不要求用户先填问卷；起点可以再通过诊断练习调整。每课标明新增概念、复用概念、预测、运行、单点修改、独立练习和评估证据，阶段出口使用迁移任务。关键节点的自测包含合理误解、逐项反馈和分级提示，对应 Academy 的 `knowledge_checks`；自测答对、代码检查通过和 AI 点评各自表达其证据范围。

负责人维护一份主蓝图，按具体需要选择成员，不让各成员重复生成整门课程；复核围绕目标、先修、运行限制和具体矛盾展开。团队模板变化不会覆盖已经安装或被用户编辑的定义，同名冲突仍需按安装器的明确错误处理。

## 安装与使用

在仓库根目录先预览，再显式安装：

```sh
.venv/bin/python scripts/install_example_teams.py --scenario learning-design-lab
.venv/bin/python scripts/install_example_teams.py --scenario learning-design-lab --apply
```

安装完成后，在 Agent／团队选择器选择“课程设计协作”。安装只注册定义，不启动模型、任务或外部连接；已有同名不同定义时会停止并保留原配置。

## 示例任务

> 为“Python 入门基础学习”设计课程蓝图。学习者只有少量编程经验，课程必须在 Harness 内完成。请默认检查入门、进阶、精进三级结构，列出每个系列的目标、逐课内容、练习、评估和环境边界；必要时参考公开课程，但区分观察、推断和未知，不创建课程文件。

也可以替换为“大模型学习”或“Harness 学习”。涉及在线模型、外部依赖或当前 Academy 尚未支持的能力时，团队必须标出本地模拟、受控传输、未来扩展和不能验证的边界。

市场基准用于帮助取舍，不等于学习效果认证或市场排名。公开资料不可访问时，团队应保留未知并说明最小补证步骤。
